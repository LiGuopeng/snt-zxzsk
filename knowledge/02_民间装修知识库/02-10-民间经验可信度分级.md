# 民间经验可信度分级

## 一、概述

民间装修经验最大的价值是真实，但最大的风险是不一定准确。很多说法来自业主个人经历、师傅经验、短视频观点或评论区总结，其中有些非常有参考价值，有些只适合特定场景，有些则容易误导。

因此，民间知识库必须建立可信度分级机制。每条经验都要判断它能不能直接采用、是否需要条件说明、是否必须专业校正、是否存在安全风险。

## 二、适用范围

本文适用于 `02_民间装修知识库` 中所有民间经验、师傅说法、用户案例、网红设计评价、材料口碑和售后维权经验。

## 三、分级总表

| 等级 | 名称 | 含义 | 使用方式 |
|---|---|---|---|
| A | 高可信 | 与标准知识一致，可直接采用 | 可作为明确建议 |
| B | 条件可信 | 大多数场景适用，但需要看现场 | 必须说明适用条件 |
| C | 参考可信 | 有参考价值，但不能绝对化 | 必须给判断方法 |
| D | 低可信 | 容易误导，需要明显校正 | 必须指出误区 |
| E | 不可信或高风险 | 明显错误或存在安全风险 | 不建议采用 |

## 四、A 级：高可信经验

### 1. 定义

A 级经验是指与标准知识库一致、工程逻辑清楚、风险较低、适用范围较明确的经验。

### 2. 判断标准

符合以下多数条件：

1. 与 `01_标准知识库` 一致。
2. 有明确适用场景。
3. 不会造成安全隐患。
4. 多数装修场景都适用。
5. 可以转化为验收动作或避坑清单。

### 3. 示例

```text
民间经验：装修合同里材料不能只写品牌，还要写型号、规格和数量。
评级：A
原因：与合同审核标准一致，适用范围广，风险提醒明确。
```

### 4. AI 输出方式

```text
这个经验是比较可靠的，建议你采用。重点是……
```

## 五、B 级：条件可信经验

### 1. 定义

B 级经验通常是正确的，但必须结合现场条件，不适合直接绝对化。

### 2. 判断标准

符合以下情况：

1. 大多数情况下有道理。
2. 但受户型、预算、材料、施工条件影响。
3. 需要提醒用户适用边界。
4. 不说明条件容易被误用。

### 3. 示例

```text
民间经验：厨房插座越多越好。
评级：B
专业校正：插座数量要充足，但位置、回路、功率和使用场景比单纯数量更重要。
```

### 4. AI 输出方式

```text
这个说法大方向有道理，但不能只看数量，还要看……
```

## 六、C 级：参考可信经验

### 1. 定义

C 级经验有参考价值，但不能直接作为判断结论，必须结合具体情况分析。

### 2. 判断标准

符合以下情况：

1. 来自真实经验，但样本有限。
2. 有一定道理，但不具备普遍性。
3. 容易被用户理解成绝对结论。
4. 需要给用户判断路径。

### 3. 示例

```text
民间经验：瓷砖空鼓一点没事。
评级：C
专业校正：边角小面积空鼓风险较低，但大面积、高处墙砖、打孔区域空鼓不能忽视。
```

### 4. AI 输出方式

```text
这个说法只能作为参考，要看位置、面积和后续是否打孔。你可以这样判断……
```

## 七、D 级：低可信经验

### 1. 定义

D 级经验容易误导用户，可能来自片面经验、销售话术或不完整理解，必须明显校正。

### 2. 判断标准

符合以下情况：

1. 说法过于绝对。
2. 与标准知识存在冲突。
3. 忽略重要前提。
4. 可能导致返工、增项或质量问题。
5. 不一定立刻危险，但容易造成错误决策。

### 3. 示例

```text
民间经验：防水刷得越厚越好。
评级：D
专业校正：防水不是越厚越好，应按材料说明控制厚度和遍数。过厚可能开裂、起皮。
```

### 4. AI 输出方式

```text
这个说法不准确，容易误导。正确理解应该是……
```

## 八、E 级：不可信或高风险经验

### 1. 定义

E 级经验明显错误，或可能带来安全风险、结构风险、漏电漏水风险、燃气风险、法律风险。

### 2. 判断标准

符合以下任一情况：

1. 鼓励拆承重墙。
2. 鼓励私改燃气。
3. 鼓励带电维修。
4. 鼓励跳过闭水、打压等关键验收。
5. 鼓励忽视明显漏水漏电风险。
6. 与安全规范明显冲突。

### 3. 示例

```text
民间经验：老房承重墙只拆一点没事。
评级：E
专业校正：承重墙不得私自拆改，涉及结构安全和法律责任。
```

### 4. AI 输出方式

```text
这个做法不建议采用，存在安全风险。建议你不要自行处理，应先……
```

## 九、评级维度

给民间经验评级时，必须至少从以下维度判断：

| 维度 | 判断问题 |
|---|---|
| 标准一致性 | 是否符合标准知识库 |
| 场景适用性 | 是否有明确适用条件 |
| 风险等级 | 是否涉及漏水、漏电、结构、燃气 |
| 样本可靠性 | 是否来自多个案例或单一经验 |
| 表述绝对性 | 是否用了“一定、必须、绝对、都可以” |
| 成本影响 | 是否可能导致高额增项或返工 |
| 售后影响 | 是否可能造成责任不清 |
| 可验证性 | 是否能通过验收或检测验证 |

## 十、评级流程

```text
1. 提取民间原始说法
2. 判断来源类型
3. 找到适用场景
4. 回连标准知识库
5. 判断是否有安全风险
6. 判断是否过度绝对化
7. 给出 A-E 评级
8. 写专业校正
9. 写 AI 输出模板
```

## 十一、常见评级示例

| 民间说法 | 建议评级 | 校正方向 |
|---|---|---|
| 合同材料要写型号 | A | 可直接采用 |
| 厨房插座越多越好 | B | 数量重要，但位置和回路更重要 |
| 瓷砖空鼓一点没事 | C | 看位置、面积、是否打孔 |
| 防水越厚越好 | D | 应按产品说明控制厚度 |
| 承重墙拆一点没事 | E | 不建议，结构高风险 |
| 无主灯都是智商税 | C | 取决于层高、设计、预算和施工 |
| 全屋定制投影面积都是坑 | C | 报价方式不是问题，包含项才关键 |
| 乳胶漆深色一定翻车 | C | 深色更难修补，但不是一定翻车 |
| 窗帘只看每米单价 | D | 辅料、轨道、加工、安装才决定总价 |
| 售后只打电话就行 | D | 必须保留文字和证据 |

## 十三、用户输出规则

不同评级对应不同输出方式：

| 评级 | 用户输出方式 |
|---|---|
| A | “这个经验比较可靠，可以作为参考。” |
| B | “大方向对，但要结合你的现场条件。” |
| C | “有参考价值，但不能直接照搬。” |
| D | “这个说法不准确，容易误导。” |
| E | “不建议这样做，存在明显风险。” |
