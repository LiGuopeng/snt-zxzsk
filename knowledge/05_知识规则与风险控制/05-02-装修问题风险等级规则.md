# 装修问题风险等级规则

## 一、适用场景

适用于所有用户问题的初步风险分级，尤其是“严重吗”“怎么办”“要不要停工”“要不要返工”。

## 二、风险等级规则

| 风险等级 | 典型问题 | 输出要求 |
|---|---|---|
| 低 | 轻微色差、轻微划痕、局部美观问题 | 给观察和协商建议 |
| 中 | 小面积空鼓、墙面细裂、局部安装偏差 | 给复核、整改和留证建议 |
| 高 | 漏水、隐蔽工程缺陷、大面积空鼓、材料不符、大额尾款争议 | 提醒暂停、核验、留证 |
| 紧急 | 冒火花、焦味、承重墙、燃气、持续漏水 | 先止损，建议专业处理 |

## 三、风险升级条件

以下情况应提高风险等级：

1. 问题会被下一道工序覆盖。
2. 问题涉及防水、强电、燃气、结构。
3. 问题持续扩大。
4. 问题影响楼下或邻居。
5. 问题发生在老人、儿童、孕妇居住环境。
6. 用户已接近付款或签字验收。

## 四、AI 输出要求

低风险：

```text
可以先记录并观察，同时和施工方协商处理。
```

中风险：

```text
建议先复核现场，并在付款或进入下一道工序前处理。
```

高风险：

```text
建议暂缓付款或暂停下一道工序，先做检测、复验和证据留存。
```

紧急风险：

```text
先停止使用或施工，必要时断电、止水、联系物业或专业人员。
```

## 五、禁止表达

1. 没事。
2. 问题不大。
3. 先用着看看。
4. 直接拆了重做。

## 六、示例

用户问：

```text
卫生间门口地板发黑，是不是漏水？
```

风险判断：

```text
高风险。需要排查门口防水、明水外溢、楼下水印、管道渗漏，不建议只换地板。
```

## 七、RAG 拆分建议

1. 风险等级总表。
2. 风险升级条件。
3. 高风险输出口径。

## 八、关键词

风险等级、装修风险、紧急风险、漏水、用电安全、承重墙、隐蔽工程
