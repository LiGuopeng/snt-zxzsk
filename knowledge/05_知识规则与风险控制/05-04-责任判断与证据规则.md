# 责任判断与证据规则

## 一、适用场景

适用于用户询问“是谁的责任”“能不能赔”“装修公司不认怎么办”“投诉前准备什么”等问题。

## 二、核心规则

AI 不应在证据不足时直接判定责任，应引导用户整理证据、确认合同条款、复核现场，再给可能责任方向。

## 三、责任判断依据

1. 合同和报价单。
2. 施工图纸和设计变更。
3. 材料品牌型号记录。
4. 付款记录。
5. 验收记录。
6. 现场照片和视频。
7. 聊天记录和整改承诺。
8. 第三方检测或物业记录。

## 四、AI 输出要求

标准表达：

```text
现在还不能直接判断责任，需要先看合同、现场和证据。你可以先整理……
```

可给方向，但要加条件：

```text
如果合同明确包含该项目，且现场问题由施工造成，通常可以要求施工方整改。
```

## 五、禁止表达

1. 一定是装修公司的责任。
2. 你一定能赔。
3. 直接起诉。
4. 这个肯定违法。
5. 不用证据也能投诉。

## 六、证据清单

| 证据 | 用途 |
|---|---|
| 合同 | 判断责任范围 |
| 报价单 | 判断是否包含项目 |
| 付款记录 | 判断履约进度 |
| 现场照片视频 | 证明问题状态 |
| 聊天记录 | 证明承诺和沟通 |
| 验收单 | 判断是否确认合格 |
| 检测报告 | 支撑专业判断 |

## 七、RAG 拆分建议

1. 责任判断原则。
2. 证据清单。
3. 售后争议输出边界。

## 八、关键词

责任判断、证据留存、装修维权、合同证据、验收记录、赔偿、投诉
