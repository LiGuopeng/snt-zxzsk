# 施工验收风险识别规则

## 一、适用场景

适用于拆改、水电、防水、瓦工、木工、油工、安装和竣工验收阶段的风险识别。

## 二、高风险施工问题

| 阶段 | 高风险问题 | AI 行为 |
|---|---|---|
| 拆改 | 疑似承重墙、梁柱开槽、楼板开洞 | 建议停工并专业确认 |
| 水电 | 未打压、漏电、跳闸、强弱电混管 | 建议测试和复验 |
| 防水 | 未闭水、楼下渗水、门口受潮 | 建议闭水和排查 |
| 瓦工 | 大面积空鼓、高处墙砖空鼓、地漏倒坡 | 建议整改或复验 |
| 木工 | 吊顶开裂、龙骨不牢、检修口缺失 | 建议复核结构 |
| 油工 | 大面积开裂、返碱发霉 | 先排查渗水和基层 |
| 安装 | 插座发热、洁具漏水、门窗松动 | 建议暂停使用和检查 |

## 三、风险升级条件

1. 问题属于隐蔽工程，后续会被覆盖。
2. 问题涉及水、电、防水、结构。
3. 问题影响下一道工序。
4. 施工方要求先付款再处理。
5. 用户没有验收记录。

## 四、AI 输出要求

必须输出：

1. 当前风险点。
2. 需要核查的项目。
3. 是否建议暂停下一道工序。
4. 是否建议保留证据。
5. 是否建议第三方复验。

## 五、禁止表达

1. 看着差不多就行。
2. 师傅说没事就没事。
3. 封起来后再说。
4. 先付款再慢慢修。

## 六、示例

用户问：

```text
水电看着挺整齐，是不是可以付款？
```

规则输出：

```text
不能只看整齐。应核对点位、回路、线径、强弱电间距、给水打压、排水测试和照片留档，确认后再付款。
```

## 七、RAG 拆分建议

1. 各施工阶段高风险表。
2. 隐蔽工程风险升级规则。
3. 验收付款边界规则。
