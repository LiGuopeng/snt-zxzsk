# RAG召回与引用规则

## 一、适用场景

适用于装修 AI 在回答用户问题时，如何召回标准知识、民间经验、决策案例、问答模板和风险规则。

## 二、召回优先级

推荐顺序：

```text
1. 识别用户意图和风险等级
2. 召回 01 标准知识库
3. 召回 03 决策案例库
4. 召回 02 民间经验库
5. 召回 05 规则库
6. 调用 04 模板库组织表达
```

如果用户问题明显是“网上说/师傅说/是不是坑”，可提前召回 `02`，但最终仍要用 `01` 和 `05` 校正。

## 三、必须召回规则

| 用户问题 | 必须召回 |
|---|---|
| 涉及安全 | 05-02、05-03、05-08 |
| 涉及责任 | 05-04、05-07 |
| 涉及报价合同 | 05-05 |
| 涉及施工验收 | 05-06 |
| 涉及民间说法 | 05-01 |
| 信息不足 | 04-10、05-02 |

## 四、引用边界

1. 不应只引用民间经验回答专业问题。
2. 不应只用模板回答事实问题。
3. 高风险问题必须引用规则库。
4. 责任争议必须引用证据规则。
5. 标准库、案例库和规则库结论不一致时，以规则库安全边界优先。

## 五、输出引用方式

对用户不需要暴露内部文件名，但回答应体现来源层次：

```text
按施工和验收标准看……
结合常见现场经验……
这个情况风险偏高……
建议你先做以下检查……
```

## 六、示例

用户问：

```text
我家瓷砖空鼓，师傅说一点没事，怎么办？
```

召回：

```text
01_标准知识库/05_瓦工工程/05-06
02_民间装修知识库/02-09
03_装修决策案例库/03-05
04_AI问答模板库/04-03、04-04、04-10
05_知识规则与风险控制/05-01、05-02、05-06
```

## 七、RAG 拆分建议

1. 召回优先级规则。
2. 必须召回规则表。
3. 引用边界规则。
4. 典型召回示例。

## 八、关键词

RAG召回、知识库引用、装修AI检索、标准库、民间库、案例库、规则库、模板库
