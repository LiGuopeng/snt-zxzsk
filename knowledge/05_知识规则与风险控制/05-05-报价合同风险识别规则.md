# 报价合同风险识别规则

## 一、适用场景

适用于报价偏低、合同模糊、付款过早、增项争议、材料型号不清、限时优惠催签等问题。

## 二、高风险信号

1. 总价明显低于其他报价，但明细不完整。
2. 材料只写品牌，不写型号、规格、等级。
3. 水电、拆改、找平等只写预估价。
4. 增项单价和确认流程不清。
5. 付款比例前置，验收约束弱。
6. 口头承诺不写入合同。
7. 工期、延期责任和保修条款模糊。
8. 销售以“今天不签就没优惠”催促。

## 三、AI 输出要求

不能直接说“被骗”，应输出：

```text
这个报价/合同存在高风险信号，建议先核对以下明细……
```

必须提醒用户：

1. 暂缓签约或付款。
2. 要求补齐报价明细。
3. 重要承诺书面化。
4. 增项必须事前确认。

## 四、禁止表达

1. 低价一定是坑。
2. 你直接拒付。
3. 这家公司肯定有问题。
4. 合同不用看那么细。

## 五、示例

用户问：

```text
报价比别人低三万，今天签约才有优惠，能签吗？
```

规则输出：

```text
不建议因限时优惠仓促签。应先核对报价完整性、材料型号、工程量、水电计价、增项确认和付款节点。
```

## 六、RAG 拆分建议

1. 报价低风险信号。
2. 合同模糊风险信号。
3. 付款前置风险信号。

## 七、关键词

报价风险、合同风险、低价套餐、付款节点、增项、口头承诺、催签合同
