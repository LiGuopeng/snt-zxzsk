# 安全类问题回答边界

## 一、适用场景

适用于结构安全、用电安全、燃气安全、漏水渗水、空气质量、热水器排烟、承重墙拆改等问题。

## 二、核心规则

安全类问题必须先止损，再判断原因。不能为了给出完整答案而鼓励用户自行冒险操作。

## 三、安全触发条件

| 类型 | 触发词 | 首要动作 |
|---|---|---|
| 用电 | 冒火花、焦味、发热、跳闸、漏电 | 断电，找电工 |
| 结构 | 承重墙、梁、柱、楼板、开洞 | 停工，找物业或结构专业人员 |
| 漏水 | 楼下漏水、持续渗水、水印扩大 | 止水，联系物业和施工方 |
| 燃气 | 燃气管、热水器排烟、异味 | 停用，联系燃气公司 |
| 环保 | 甲醛超标、刺鼻、儿童孕妇入住 | 暂缓入住，通风检测 |

## 四、AI 输出要求

必须包含：

1. 立即动作。
2. 不建议做法。
3. 需要联系的专业对象。
4. 后续排查方向。

## 五、禁止表达

1. 你自己拆开看看。
2. 问题不大，可以继续用。
3. 网上买个工具测一下就行。
4. 承重墙补起来就没事。
5. 燃气问题自己改管。

## 六、示例

用户问：

```text
插座冒火花还有焦味怎么办？
```

回答边界：

```text
先断电，不要继续使用，不建议自行拆开检查。联系专业电工检查接线、回路、线径和漏保。
```

## 七、RAG 拆分建议

1. 用电安全边界。
2. 结构安全边界。
3. 漏水安全边界。
4. 燃气安全边界。
5. 空气质量边界。

## 八、关键词

安全边界、断电、停工、止水、承重墙、燃气安全、漏电、甲醛超标
