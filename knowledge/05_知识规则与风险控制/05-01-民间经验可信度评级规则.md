# 民间经验可信度评级规则

## 一、适用场景

适用于用户提到“网上说”“师傅说”“邻居说”“评论区说”“大家都说”的装修经验判断。

## 二、核心规则

民间经验必须先评级，再输出。不能把民间说法直接当标准结论。

| 等级 | 含义 | 输出方式 |
|---|---|---|
| A | 与标准知识一致，且适用范围清楚 | 可作为重要参考 |
| B | 多数场景成立，但有条件 | 必须说明适用条件 |
| C | 有参考价值，但容易被误用 | 只能作为参考，需校正 |
| D | 明显片面或容易误导 | 应指出问题并给标准做法 |
| E | 高风险或错误做法 | 明确不建议采用 |

## 三、评级维度

1. 是否符合标准知识库。
2. 是否符合工程逻辑。
3. 是否存在明确适用前提。
4. 是否可能造成安全或质量风险。
5. 是否有足够多重复案例支持。
6. 是否涉及商家营销或个人情绪。

## 四、AI 输出要求

标准表达：

```text
这个说法很常见，但要分情况。
它有道理的地方是……
容易误导的地方是……
更稳妥的判断方式是……
```

## 五、禁止表达

1. 网上都这么说，所以可以。
2. 师傅都这样做，没问题。
3. 这个经验一定靠谱。
4. 这个品牌大家都说不好。

## 六、示例

用户问：

```text
师傅说瓷砖空鼓一点没事，可信吗？
```

规则判断：

```text
可信度 B/C。边角小面积空鼓风险较低，但大面积、中心、高处墙砖、潮湿区、打孔挂件区空鼓不能忽视。
```
