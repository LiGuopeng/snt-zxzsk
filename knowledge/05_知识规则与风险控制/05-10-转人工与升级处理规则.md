# 转人工与升级处理规则

## 一、适用场景

适用于 AI 不应继续独立判断，需要建议用户联系专业人员、物业、检测机构、平台客服、监管部门或法律专业人士的场景。

## 二、必须升级场景

| 场景 | 升级对象 |
|---|---|
| 疑似承重墙、梁柱楼板改动 | 物业、结构工程师、检测机构 |
| 插座冒火花、焦味、漏电 | 专业电工 |
| 燃气管改动、燃气异味 | 燃气公司 |
| 楼下持续漏水 | 物业、施工方、防水检测 |
| 甲醛明显超标且有敏感人群 | 检测机构、医生建议 |
| 大额合同纠纷 | 消协、市场监管、律师 |
| 施工方拒不整改且证据明确 | 平台、监管渠道、法律咨询 |

## 三、建议升级场景

1. 现场条件复杂，用户无法描述清楚。
2. 已经多次维修仍复发。
3. 涉及多人责任主体。
4. 争议金额较大。
5. 用户准备签署重要文件或支付大额尾款。

## 四、AI 输出要求

推荐表达：

```text
这个问题已经超出单纯线上判断范围，建议你先……
```

同时仍应给用户准备事项：

1. 带哪些资料。
2. 先拍哪些照片。
3. 向谁说明什么问题。
4. 不要先做哪些破坏现场的动作。

## 五、禁止表达

1. 我可以直接判断责任。
2. 不用找专业人员。
3. 你直接照我说的做就行。
4. 不用留现场。

## 六、示例

用户问：

```text
工人可能拆了承重墙，但他说没事。
```

应答：

```text
先停工。疑似承重墙不能只靠施工方口头判断，建议联系物业查看结构图，必要时找结构专业人员现场确认。已经拆动的位置不要自行遮盖，先保留现场和照片。
```

## 七、RAG 拆分建议

1. 必须升级场景表。
2. 建议升级场景表。
3. 升级处理输出模板。

## 八、关键词

转人工、升级处理、专业人员、物业、检测机构、律师、消协、市场监管、装修高风险
