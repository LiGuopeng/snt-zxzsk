# 决策案例库调用接口索引

## 一、文档目的

本文用于定义 `03_装修决策案例库` 如何被 RAG 和 AI 问答系统调用。

决策案例库的核心价值是把用户问题转化为判断路径。它不负责提供全部专业标准，也不负责收集全部民间经验，而是负责组织“当前这个问题怎么判断、怎么排查、怎么处理”。

## 三、调用原则

1. 用户问“怎么办”，优先判断是否需要调用案例库。
2. 用户描述具体现象，优先调用对应案例。
3. 用户要求判断对错，案例库应联动标准库。
4. 用户提到“师傅说、网上说、别人说”，案例库应联动民间库。
5. 用户问题涉及安全、结构、漏水、用电，应联动规则库并提高风险等级。

## 五、RAG 召回顺序

建议召回顺序：

```text
第一步：识别用户问题类型
第二步：召回 03 对应决策案例
第三步：召回 01 标准知识库
第四步：召回 02 民间经验库
第五步：召回 05 风险控制规则
第六步：套用 04 AI 问答模板
```

示例：

```text
用户问：我家瓷砖空鼓，师傅说一点没事，怎么办？

召回：
03-05 墙地面问题决策案例
01_标准知识库/05_瓦工工程/05-06 瓷砖空鼓处理
01_标准知识库/09_验收标准/09-05 瓦工工程验收标准
02_民间装修知识库/02-09 师傅工长经验说法
05_知识规则与风险控制/施工验收风险识别规则
```

## 六、最终输出结构

案例库参与回答时，建议输出为：

```text
1. 先给初步判断
2. 说明可能原因
3. 给判断路径
4. 给现在先做什么
5. 说明哪些情况风险高
6. 给下一步处理建议
7. 必要时追问关键信息
```

## 七、风险控制接口

以下情况应提高风险等级：

1. 涉及承重墙、梁、柱、楼板。
2. 涉及插座冒火花、焦味、频繁跳闸。
3. 涉及楼下漏水、持续渗水。
4. 涉及燃气、热水器排烟、用电安全。
5. 涉及大额尾款、合同纠纷、材料明显不符。
6. 涉及儿童、老人、孕妇居住安全。

高风险回答不应只给经验建议，应提示停止使用、暂停施工、保留证据或联系专业人员。
