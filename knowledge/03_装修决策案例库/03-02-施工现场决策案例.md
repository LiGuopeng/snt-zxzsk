# 施工现场决策案例

## 一、概述

施工现场类问题的核心是“现场看到一个问题，用户不知道是否严重”。这类问题必须先判断是否涉及结构、安全、隐蔽工程、防水、用电，再决定是观察、整改、暂停施工还是请第三方复验。

## 案例编号：03-02-001

### 1. 用户问题

师傅说水电横平竖直才规范，但我听说这样会多收费，到底怎么判断？

### 2. 现场条件

1. 用户处于水电施工阶段。
2. 现场线路可能横平竖直，也可能点对点。
3. 用户担心绕线增加费用。
4. 报价可能按米数计算。

### 3. 可能原因

1. 横平竖直便于后期定位和美观。
2. 过度横平竖直可能增加线管长度和费用。
3. 不规范点对点可能影响后期维修和打孔安全。
4. 施工方可能利用走线方式制造增项。

### 4. 判断路径

1. 先看合同计价方式是包干还是按米。
2. 再看线路是否有明显绕远。
3. 再看墙面、地面是否便于后期拍照留档。
4. 再看强弱电是否分管、间距是否合理。
5. 再看转弯是否过多、是否影响穿线维修。

### 5. 优先处理动作

1. 要求施工方现场说明走线原则。
2. 拍照保存每面墙、每个地面的管线位置。
3. 对明显绕线要求调整或说明。
4. 对新增米数要求提前确认。

### 6. 推荐方案

横平竖直不是唯一标准，关键是安全、可维护、可定位、少绕线。合理横平竖直可以接受，明显为了增加米数而绕线不建议接受。

### 7. 不建议做法

1. 只按好不好看判断。
2. 只听“行业都这样”。
3. 不拍照留底。
4. 不核对米数就付款。

### 8. 风险等级

中。

### 9. 需要补充询问的问题

1. 水电是否按米计价。
2. 是否有点位图。
3. 是否已经验收。
4. 强弱电是否分开。
5. 是否有打压测试和绝缘测试记录。

### 10. 关联专业知识

1. 01_标准知识库/03_水电工程/03-03 强电施工标准。
2. 01_标准知识库/03_水电工程/03-04 弱电施工标准。
3. 01_标准知识库/03_水电工程/03-12 水电验收标准。

### 11. 关联民间经验

1. 02_民间装修知识库/02-03 施工现场真实问题。
2. 02_民间装修知识库/02-09 师傅工长经验说法。

### 12. AI 回复模板

水电不是越横平竖直越好，也不是点对点就一定不规范。你要看有没有明显绕线、强弱电是否分管、转弯是否过多、后期是否方便定位维修，以及水电是否按米收费。如果按米收费，更要核对实际米数和走线路径。

### 13. RAG 拆分建议

本案例可拆分为“水电横平竖直判断”知识块。

## 案例编号：03-02-002

### 1. 用户问题

防水刚刷完，师傅说干了就能贴砖，不用等太久，可以吗？

### 2. 现场条件

1. 防水施工刚完成。
2. 用户不确定是否完成闭水试验。
3. 工期可能比较紧。
4. 施工方希望尽快进入瓦工阶段。

### 3. 可能原因

1. 工期安排紧。
2. 防水涂膜未完全固化。
3. 闭水试验未做或时间不足。
4. 墙地面基层含水率、阴角、管根处理未检查。

### 4. 判断路径

1. 确认防水是否按区域和高度完成。
2. 确认涂刷遍数和方向。
3. 确认管根、地漏、阴阳角是否加强。
4. 确认是否达到闭水试验条件。
5. 确认闭水时间、楼下检查和水位记录。

### 5. 优先处理动作

1. 未闭水前不要贴地砖。
2. 要求做闭水试验并拍照记录。
3. 通知楼下或物业检查顶面。
4. 闭水无异常后再进入下一步。

### 6. 推荐方案

防水不是刷完就算完成，必须经过固化、闭水和验收。尤其卫生间地面、淋浴区、管根、门槛石区域不能省略闭水。

### 7. 不建议做法

1. 为赶工跳过闭水。
2. 只看表面干就贴砖。
3. 闭水时间太短。
4. 不通知楼下检查。

### 8. 风险等级

高。

### 9. 需要补充询问的问题

1. 是卫生间、厨房还是阳台。
2. 是否做过闭水。
3. 闭水多长时间。
4. 楼下是否检查。
5. 门口是否做挡水处理。

### 10. 关联专业知识

1. 01_标准知识库/04_防水工程/04-02 卫生间防水标准。
2. 01_标准知识库/04_防水工程/04-05 闭水试验。
3. 01_标准知识库/04_防水工程/04-08 防水验收标准。

### 11. 关联民间经验

1. 02_民间装修知识库/02-03 施工现场真实问题。
2. 02_民间装修知识库/02-09 师傅工长经验说法。

### 12. AI 回复模板

不建议防水刚刷完就直接贴砖。防水要看基层、涂刷、管根阴角加强、固化时间和闭水结果。卫生间地面尤其要做闭水试验，确认楼下无渗漏后再贴砖。赶工省掉这一步，后期漏水维修成本会很高。

### 13. RAG 拆分建议

本案例可拆分为“防水未闭水是否能贴砖”知识块。
