# 预算合同决策案例

## 一、概述

预算合同类问题通常发生在签约前、开工前、施工中增项、付款节点和竣工结算阶段。用户最需要判断的是：这份报价能不能签、这个增项合不合理、这笔钱该不该付、合同哪里有风险。

## 案例编号：03-01-001

### 1. 用户问题

有一家装修公司报价比其他公司低三万，销售说今天签约才有优惠，我能不能签？

### 2. 现场条件

1. 用户处于签约前。
2. 已拿到初步报价，但报价项目可能不完整。
3. 对方以限时优惠推动成交。
4. 用户还没有核对材料型号、工程量、付款节点和增项规则。

### 3. 可能原因

1. 正常促销。
2. 报价漏项。
3. 主材或辅材配置较低。
4. 水电、拆改、找平、搬运、垃圾清运等后期按实结算。
5. 用低价吸引签约，后续通过增项补回利润。

### 4. 判断路径

1. 看报价是否有完整工程项目。
2. 看材料是否写明品牌、型号、规格、等级。
3. 看工程量计算方式是否清楚。
4. 看水电、拆改、找平、瓷砖铺贴是否有单价和上限。
5. 看付款节点是否与验收绑定。
6. 看合同是否写明延期、保修、变更、增项确认流程。

### 5. 优先处理动作

1. 不要当天直接签约。
2. 要求对方提供完整报价明细。
3. 把“优惠价包含什么、不包含什么”写清楚。
4. 要求所有口头承诺进入合同或补充协议。
5. 至少和其他报价逐项对比，而不是只比总价。

### 6. 推荐方案

可以继续谈，但应把低价报价拆成明细核对。如果对方愿意补齐项目、写清材料、确认增项单价和付款节点，风险可控；如果对方只强调优惠、不愿明细化，属于高风险签约。

### 7. 不建议做法

1. 因为便宜直接签。
2. 只看效果图和销售承诺。
3. 接受“后面都好说”。
4. 在合同不清楚时支付大额定金。

### 8. 风险等级

高。

### 9. 需要补充询问的问题

1. 报价是否包含拆改、水电、防水、找平、垃圾清运。
2. 水电是包死价还是按实结算。
3. 材料是否写了具体型号。
4. 付款比例是多少。
5. 增项是否需要用户书面确认。

### 10. 关联专业知识

1. 01_标准知识库/01_装修准备/01-02 装修预算制定。
2. 01_标准知识库/01_装修准备/01-03 装修合同签订。
3. 01_标准知识库/01_装修准备/01-06 装修报价单审核。
4. 01_标准知识库/01_装修准备/01-07 装修付款方式。

### 11. 关联民间经验

1. 02_民间装修知识库/02-01 装修公司与合同套路。
2. 02_民间装修知识库/02-02 预算增项与报价避坑。

### 12. AI 回复模板

不建议因为“今天签才有优惠”马上签。报价低不一定是坑，但必须先核对明细：施工项目是否完整、材料型号是否清楚、工程量怎么算、水电和拆改是否按实结算、增项单价是否提前约定、付款是否和验收绑定。如果这些不清楚，后期增项风险会比较高。

## 案例编号：03-01-002

### 1. 用户问题

施工中水电突然增项一万多，装修公司说按实际发生算，这合理吗？

### 2. 现场条件

1. 用户已开工。
2. 水电改造正在施工或刚完成。
3. 原报价可能只写预估金额。
4. 用户没有提前确认点位、米数、单价和上限。

### 3. 可能原因

1. 用户实际增加点位。
2. 原报价故意低估。
3. 水电按米计价，绕线、开槽、回路增加导致费用上升。
4. 未提前确认强弱电、给排水、开关插座数量。
5. 施工方未在施工前做变更确认。

### 4. 判断路径

1. 核对合同中水电计价方式。
2. 核对原始点位图和实际点位图。
3. 核对实际米数、单价、回路、管线数量。
4. 判断是否有用户主动增加项目。
5. 判断施工方是否提前告知并获得确认。
6. 判断增项是否超出合理范围。

### 5. 优先处理动作

1. 要求出具水电增项明细。
2. 暂缓支付争议款项。
3. 拍摄现场线路和点位。
4. 对照合同、报价、点位图逐项核对。
5. 对未确认增项要求重新协商。

### 6. 推荐方案

如果增项来自用户明确新增点位，且单价与合同一致，一般属于合理增项；如果原报价明显漏项、施工前未确认、施工后才告知大额增加，则存在较高争议，应要求施工方提供明细并协商处理。

### 7. 不建议做法

1. 不看明细直接付款。
2. 只听口头解释。
3. 让施工方先继续做完再说。
4. 不保留现场照片和沟通记录。

### 8. 风险等级

高。

### 9. 需要补充询问的问题

1. 合同水电是包干还是按实结算。
2. 增项前是否让用户签字确认。
3. 是否有点位图。
4. 增加的是强电、弱电、给水还是排水。
5. 单价是否与报价单一致。

### 10. 关联专业知识

1. 01_标准知识库/03_水电工程/03-02 水电点位规划。
2. 01_标准知识库/03_水电工程/03-11 水电报价审核。
3. 01_标准知识库/03_水电工程/03-13 水电增项风险。

### 11. 关联民间经验

1. 02_民间装修知识库/02-02 预算增项与报价避坑。
2. 02_民间装修知识库/02-03 施工现场真实问题。

### 12. AI 回复模板

先不要只听“按实际发生”这句话。你需要让对方列出增项明细：新增点位、实际米数、单价、回路、材料、施工位置，并对照原合同和点位图。用户主动新增且提前确认的部分通常较合理；如果施工前没确认、完工后才报大额增项，就应重点核对并协商。
