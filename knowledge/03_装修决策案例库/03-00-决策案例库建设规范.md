# 决策案例库建设规范

## 一、概述

决策案例库是装修 AI 知识库的第三层，负责把标准知识和民间经验转化为“遇到具体问题时怎么判断、怎么处理、先做什么、后做什么”。

标准知识库回答“正确做法是什么”，民间知识库回答“真实世界有哪些坑”，决策案例库回答“用户现在这个情况应该怎么判断”。

典型用户问题包括：

1. 我家瓷砖空鼓，怎么办。
2. 卫生间门口地板发黑，是不是漏水。
3. 装修公司报价低很多，能不能签。
4. 全屋定制说要加钱，合理吗。
5. 墙面开裂，算质量问题吗。
6. 装修公司不维修，我该怎么沟通。

## 四、风险等级

| 等级 | 含义 | 处理原则 |
|---|---|---|
| 低 | 主要影响美观、便利或局部使用 | 可记录、观察、协商优化 |
| 中 | 可能影响后期使用、维修成本或局部质量 | 建议复核、整改或保留证据 |
| 高 | 涉及漏水、用电、结构、隐蔽工程、重大费用 | 暂停付款或施工，优先核验 |
| 紧急 | 可能造成人身安全、财产损失、楼下损害 | 先止损，再追责 |

## 五、判断原则

1. 不武断下结论，先确认现场条件。
2. 先排除安全风险，再讨论美观和费用。
3. 先判断是否影响隐蔽工程、防水、用电、结构。
4. 先看合同、报价、图纸、验收记录，再判断责任。
5. 民间经验只能辅助判断，不能替代标准和证据。
6. 高风险问题应建议用户找专业人员现场复核。

## 六、RAG 拆分规则

案例库适合按“一个场景一个 chunk”拆分。

建议元数据：

```yaml
layer: decision_case
case_id: 03-05-001
scene: 瓷砖空鼓判断
risk_level: 中
user_stage: 瓦工验收
related_standard_docs:
  - 01_标准知识库/05_瓦工工程/05-06
related_folk_docs:
  - 02_民间装修知识库/02-09
output_type:
  - 判断路径
  - 处理建议
  - 追问问题
```
