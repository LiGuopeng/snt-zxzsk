# 标准知识库接口索引

## 一、文档目的

本文用于整理 `00_知识库总控` 与 `01_标准知识库` 的边界，以及标准知识库如何向后续的民间知识库、决策案例库、问答模板库和 RAG 系统提供调用接口。

这里的“接口”不是程序 API，而是知识系统中的统一入口，包括：

1. 模块边界。
2. 主题能力。
3. 检索标签。
4. 适用问题。
5. 可关联模块。
6. 对外调用方式。

后续建设 `02_民间装修知识库`、`03_装修决策案例库`、`04_AI问答模板库`、`05_知识规则与风险控制` 时，都应优先引用本索引中的标准库接口。

`01_标准知识库` 内部已补充 `01-00-标准知识库调用接口索引.md`，用于作为标准库自身的 RAG 召回入口；同时补充 `01-01-标准知识库专项补充规划.md`，用于管理后续跨模块专项标准文档。

```text

02 = 民间经验库
03 = 决策案例库
04 = 问答模板库
05 = 规则库
```

## 三、标准知识库总接口

标准知识库对外提供六类能力：

| 能力 | 说明 | 主要模块 |
|---|---|---|
| 流程接口 | 回答装修顺序、节点、阶段 | 01、09 |
| 决策接口 | 回答预算、合同、公司选择、方案审核 | 01 |
| 施工接口 | 回答各工种怎么施工 | 02-08 |
| 验收接口 | 回答怎么判断合格 | 09、各模块验收文档 |
| 软装接口 | 回答入住前家具软装配置 | 10 |
| 售后接口 | 回答入住后问题处理和维权 | 11 |

标准库的核心调用原则：

1. 问“该不该做”，先调用 `01` 和相关专业模块。
2. 问“怎么施工”，调用 `02-08`。
3. 问“怎么验收”，调用 `09` 和对应工程验收文档。
4. 问“入住后怎么办”，调用 `11`。
5. 问“家具软装怎么选”，调用 `10`。
6. 问“网上说法对不对”，调用 `02_民间装修知识库` 后必须回连 `01_标准知识库/01-11` 做校正。

## 八、标准库调用优先级

当用户问题涉及多个模块时，建议按以下优先级调用：

1. 安全和应急优先：漏水、漏电、燃气、承重、坠落风险。
2. 阶段优先：用户处于准备、施工、验收、入住还是售后。
3. 专业模块优先：问题属于哪个工种或品类。
4. 验收标准补充：需要判断合格与否时调用 `09`。
5. 售后责任补充：涉及责任和维权时调用 `11`。
6. 民间经验校正：涉及网上说法、师傅说法、业主经验时调用 `02_民间装修知识库` 并回连标准库。

## 九、典型调用示例

### 示例 1：用户问“水电增项是不是被坑了”

调用顺序：

```text
01-02 装修预算制定
01-06 装修报价单审核
03-11 水电报价审核
03-13 水电增项风险
09-03 水电工程验收标准
11-07 售后证据留存与责任判断
```

判断重点：

1. 原报价是否漏项。
2. 点位是否变更。
3. 增项单价是否提前约定。
4. 是否有现场确认。
5. 是否有水电图和照片。

### 示例 2：用户问“卫生间门口地板发黑是不是漏水”

调用顺序：

```text
04-09 漏水原因分析
09-04 防水工程验收标准
11-03 漏水渗水售后处理
11-07 售后证据留存与责任判断
```

判断重点：

1. 是否长期积水外溢。
2. 门槛石和门套底部是否潮湿。
3. 防水门口止水是否失效。
4. 地板是否受潮变形。
5. 是否需要含水率检测或闭水复验。

### 示例 3：用户问“无主灯是不是智商税”

调用顺序：

```text
06-02 吊顶施工标准
08-03 灯具安装
10-04 软装灯光与氛围营造
09-08 安装工程验收标准
```

判断重点：

1. 层高是否适合吊顶。
2. 灯位是否经过设计。
3. 是否存在眩光、暗区、色温混乱。
4. 预算和维护是否能接受。
