# 意图召回链路表

## 一、文档定位

本文用于把标准意图映射为稳定的知识库召回链路。

它解决的问题是：

```text
用户问题已经识别出来后，应该调用哪些知识库、哪些规则、哪个模板。
```

本文不是知识正文，而是后期 RAG、客服机器人、监理助手和评测系统的召回策略蓝本。

## 二、链路字段

每条意图召回链路建议包含：

| 字段 | 说明 |
|---|---|
| 意图编号 | 唯一编号，例如 INTENT-001 |
| 标准意图 | 归一后的用户问题 |
| 问题类型 | 预算、合同、施工、验收、售后、风险等 |
| 适用阶段 | 设计前、施工中、验收前、尾款前、入住后、维权中 |
| 风险等级 | 低、中、高、紧急 |
| 必召回标准库 | 必须调用的标准知识文档 |
| 必召回案例库 | 推荐调用的决策案例 |
| 必召回民间库 | 涉及经验、套路、后悔时调用 |
| 必召回规则库 | 风险、责任、边界、可信度规则 |
| 输出模板 | 对应问答模板 |
| 必问信息 | 回答前或回答末尾应追问的关键信息 |
| 输出要求 | 必须出现或禁止出现的表达 |

## 三、召回优先级

默认顺序：

```text
1. 识别标准意图
2. 判断阶段和风险等级
3. 召回标准知识库
4. 召回决策案例库
5. 召回民间经验库
6. 召回规则库
7. 调用问答模板库组织表达
8. 输出前做风险边界校正
```

特殊情况：

```text
涉及安全：规则库提前
涉及民间说法：民间库提前，但必须被标准库和规则库校正
涉及责任赔偿：证据规则提前
信息不足：追问模板提前
```

#### INTENT-032 重点打标：后期优化

1. 用户明确问“具体怎么做”“一步一步”“详细步骤”“签约当天检查什么”时，不受短回答模板限制，应输出可照着执行的操作清单。

3. 后期可把本意图拆成三个子意图：签前审核、签约当天核对、已签后漏项补救。

## 六、维护规则

1. 新增用户问法时，必须映射到已有意图或新增意图编号。
2. 新增意图时，必须指定标准库、规则库和输出模板。
3. 涉及安全、责任、赔偿、合同的问题，必须指定规则库。
4. 涉及民间经验的问题，必须指定可信度评级规则。
5. 召回链路变化后，应同步更新用户真实问法映射表。
6. 后期进入系统后，本文可作为召回策略配置的初始版本。
