# 售后保修基础知识

## 一、概述

售后保修是装修竣工交付后的质量保障和问题处理机制，覆盖施工质量、主材安装、定制家具、家电设备、软装家具和日常维护。它不是单纯“坏了找人修”，而是包括保修范围、保修期限、责任主体、报修流程、证据留存、维修复验和质保期管理。

装修售后最容易出现的问题是责任边界不清：装修公司认为是主材问题，主材商认为是施工基础问题，安装方认为是使用不当，业主缺少证据。解决这一类问题，核心是交付时资料齐全、问题发生时证据完整、沟通时诉求明确、维修后复验闭环。

## 二、适用范围

本文适用于住宅装修竣工后出现的漏水、渗水、开裂、空鼓、脱落、松动、异响、跳闸、家电故障、家具变形、主材损坏、安装缺陷和质保争议处理。

| 软装家具 | 沙发、床垫、餐桌、窗帘 |

| 问题原因 | 需要先定位原因再归责 |
| 时间节点 | 是否在质保期内 |

## 六、服务流程

1. 竣工交付时建立售后资料包。
2. 按项目整理联系人和质保期限。
3. 入住后发现问题先止损。
4. 拍照录像记录问题。
5. 对照合同、订单和保修卡确定责任方。
6. 联系责任方上门检查。
7. 维修前确认方案和影响范围。
8. 维修后复验并记录。
9. 对重复问题升级沟通。

## 七、关键标准

| 标准 | 说明 |
|---|---|
| 资料完整 | 合同、订单、保修卡齐全 |
| 响应及时 | 安全和漏水问题优先处理 |
| 原因清楚 | 不盲目维修表面 |
| 责任明确 | 装修、主材、家电、物业边界清楚 |
| 维修有效 | 解决根因而非临时遮盖 |
| 复验闭环 | 修完后测试并记录 |

| 检查项 | 合格表现 |
|---|---|
| 售后资料 | 每项产品和工程有对应凭证 |

## 九、常见问题

### 1. 装修保修是不是所有问题都免费修？

不是。要看是否属于保修范围、是否在保修期内、是否由施工或产品质量导致。人为损坏、使用不当、自然损耗通常不一定免费。

### 2. 找不到责任方怎么办？

先根据问题来源分类：墙内水电找装修方，产品本体找商家或品牌，公共管道或外墙找物业或开发商。证据不足时，建议先请专业人员定位原因。

### 3. 维修后还要验收吗？

必须验收。维修完成后要重新做试水、试电、开合、观察等测试，并拍照记录结果。

## 十、避坑提醒

1. 竣工时不要只收钥匙，要收保修资料。
2. 发现漏水漏电先止损再争责任。
3. 售后沟通不要只电话，文字记录更可靠。
4. 重复维修无效要要求查根因。
5. 不要让维修破坏其他成品后无人负责。
6. 质保期快到时要做一次全屋检查。
7. 家电和主材保修不一定归装修公司。
8. 维修后必须复验。

## 十一、案例分析

### 案例 1：渗水责任不清

卫生间门口地板发黑，装修方说是使用积水，木门方说是防水问题，业主没有闭水记录和维修照片。

经验：售后问题要先定位原因，交付资料越完整，责任越容易判断。

### 案例 2：维修后没有复验

厨房水槽下水漏水，维修师傅拧紧接口后离开，业主未做满水排水测试，几天后再次漏水泡柜。

经验：维修后必须现场复验。

## 十二、法规依据

售后保修可参考住宅室内装饰装修管理相关规定、建设工程质量保修相关规定、消费者权益保护相关规定、产品质量相关规定，以及装修合同、产品保修卡和品牌售后政策。

## 十三、用户咨询与AI回复模板

用户问：装修入住后发现问题，第一步该做什么？

AI 回复：先判断是否有安全和损失扩大风险。如果是漏水，先关角阀或总阀；如果是电路异常，先断电停用。然后拍远景、近景和视频，记录时间、位置和现象。再对照合同、订单和保修卡判断找装修公司、主材商、品牌售后还是物业。维修后一定要复验，不要只听对方说修好了。
