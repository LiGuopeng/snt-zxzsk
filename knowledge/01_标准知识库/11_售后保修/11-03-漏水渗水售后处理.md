# 漏水渗水售后处理

## 一、概述

漏水渗水是装修售后中最紧急、损失最大、责任最复杂的问题之一。它可能来自给水管、排水管、防水层、洁具接口、地漏管根、窗框外墙、阳台、屋顶、公共管道、空调冷凝水等多个来源。

漏水处理的第一原则是先止损，再定位原因，最后谈责任和维修。若不及时止损，可能造成柜体泡水、地板发黑、墙面发霉、楼下损失、邻里纠纷和赔偿扩大。

## 二、适用范围

本文适用于卫生间、厨房、阳台、窗边、屋顶、墙面、地板、柜体、楼下顶面、空调冷凝水等位置的漏水渗水售后处理。

### 2. 漏水紧急程度

| 等级 | 表现 | 动作 |
|---|---|---|
| 紧急 | 明水持续流、楼下滴水、电器附近漏水 | 立即关水断电 |

| 中 | 局部水印、发霉 | 记录并排查 |
| 低 | 偶发冷凝水或轻微返潮 | 观察并优化通风 |

## 六、处理流程

1. 立即关闭相关角阀或总阀。
2. 电器、插座附近漏水时先断电。
3. 拍摄漏水位置、范围和动态视频。
4. 清理积水，防止扩大损失。
5. 标记水印边界和时间。
6. 分区试水或停水观察，初步判断来源。
7. 联系装修公司、物业、主材商或品牌售后。
8. 现场排查并确认维修方案。
9. 维修完成后做试水或观察。
10. 对受损成品评估修复或赔偿。

## 七、关键标准

| 标准 | 说明 |
|---|---|
| 止损及时 | 先关水断电 |
| 定位准确 | 分清给水、排水、防水、外墙 |
| 责任清楚 | 不盲目归责 |
| 维修彻底 | 处理根因 |
| 复验充分 | 试水、闭水或雨后观察 |
| 损失记录 | 受损家具地板墙面拍照 |

## 八、验收标准

| 维修对象 | 复验方法 | 合格表现 |
|---|---|---|
| 给水管 | 打压或通水观察 | 无渗漏 |
| 排水管 | 大量排水测试 | 接口不漏，排水顺畅 |
| 防水层 | 闭水或持续用水观察 | 楼下和门口无渗 |
| 水槽下水 | 满水排水 | 接口干燥 |
| 马桶 | 多次冲水 | 底部无渗 |
| 窗边 | 雨后或淋水测试 | 不再渗水 |
| 空调 | 连续运行 | 冷凝水排放正常 |

## 九、常见问题

### 1. 楼下说漏水，一定是我家防水问题吗？

不一定。可能是防水层，也可能是给水管、排水管、管根、公共管道或楼上其他位置。应先停水、分区用水、现场排查。

### 2. 卫生间门口地板发黑是什么原因？

常见原因有卫生间门口防水收口差、门槛石渗水、长期积水外溢、门套受潮或地板防潮不足。需要查门口含水和用水路径。

### 3. 漏水修好了，受损地板和柜子谁赔？

要看漏水责任。若是施工或安装质量导致，应协商修复或赔偿受损成品；若是使用不当，则可能由使用方承担。证据越完整越容易判断。

## 十、避坑提醒

1. 漏水先关水断电，不要先争吵。
2. 不要没拍照就拆砖拆柜。
3. 不要只用防水胶表面糊住。
4. 水印要标记时间，看是否扩大。
5. 楼下漏水要共同现场确认。
6. 卫生间渗水不一定都是防水问题。
7. 雨后渗水要联系物业或外窗责任方。
8. 修完必须试水或观察一段时间。

## 十一、案例分析

### 案例 1：水槽慢漏泡坏橱柜

水槽下水接口轻微渗水，业主没有及时发现，几周后水槽柜底板鼓包发霉。

经验：入住后应定期检查水槽、台盆和洗衣机接口。

### 案例 2：窗边下雨渗水

业主以为是墙面乳胶漆问题，反复补漆仍返潮。最终发现窗框外侧密封失效。

经验：雨后渗水要排查外窗和外墙，不只看室内墙面。

## 十二、法规依据

漏水渗水处理涉及装修合同、防水保修、给排水工程质量、产品质量、物业公共维修、相邻关系和损害赔偿等相关规定。具体责任应结合合同、检测、现场原因和证据判断。

## 十三、用户咨询与AI回复模板

用户问：家里漏水了怎么办？

AI 回复：先止损。如果是水管或洁具附近漏水，先关角阀或总阀；如果靠近插座电器，先断电。然后拍远景、近景和视频，记录漏水时间和范围。接着通过停水、分区用水、雨后观察等方式初步判断来源，再联系装修公司、物业或品牌售后。维修后要做试水或观察，确认不再漏。
