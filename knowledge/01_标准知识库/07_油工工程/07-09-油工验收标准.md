# 油工验收标准

## 一、概述

油工验收是对墙面基层、腻子、打磨、底漆、面漆、色漆、阴阳角、开裂、返碱、成品保护和安装后修补进行系统检查的工程节点。油工验收是硬装观感验收中最直观的一环，也是后期入住投诉率较高的部分。

油工验收不能只在白天随便看一眼，也不能只看大面积墙面是否“白”。合格的油工验收应在自然光、灯光、侧光和不同距离下检查，同时关注门套边、柜体边、踢脚线、开关面板、吊顶转角、窗边、阴阳角等细节位置。

## 二、适用范围

本文适用于：

1. 新房装修油工完工验收。
2. 二手房翻新墙面验收。
3. 腻子、底漆、乳胶漆验收。
4. 色漆、背景墙、局部修补验收。
5. 安装前和安装后墙面复验。
6. AI 客服回答“油工怎么验收”等问题。

## 七、关键标准

1. 油工验收要分阶段，不只看最终面漆。
2. 基层、腻子、底漆、面漆都要有记录。
3. 自然光、灯光和侧光都要看。
4. 色漆必须核对色号和试色记录。
5. 安装后修补要统一复验。
6. 开裂、返碱、起皮等问题必须查原因。
7. 验收问题应形成清单并闭环。

## 八、验收标准

### 1. 合格标准总表

| 项目 | 合格表现 |
|---|---|
| 基层 | 牢固、干燥、无明显问题 |
| 腻子 | 平整、细腻、角线顺直 |
| 底漆 | 无明显漏刷记录 |
| 面漆 | 均匀、无明显瑕疵 |
| 色漆 | 色号一致、发花可控 |
| 节点 | 门窗柜边收口整齐 |
| 修补 | 修补痕不明显 |
| 成品 | 无明显污染和破坏 |

### 2. 不合格表现总表

1. 墙面起皮、掉粉。
2. 裂缝明显且未处理原因。
3. 返碱、发霉直接覆盖。
4. 大面积色差、发花。
5. 刷痕、流坠、漏刷明显。
6. 阴阳角歪斜。
7. 安装后破损未修复。
8. 深色漆修补痕严重。

### 3. 整改复验标准

| 问题 | 复验方式 |
|---|---|
| 开裂 | 检查基层处理和表面效果 |
| 色差 | 整面观察，避免局部补丁 |
| 流坠 | 打磨修补后复刷 |
| 返碱 | 观察水源和干燥情况 |
| 修补痕 | 自然光和灯光复查 |
| 污染 | 清理或修复后检查 |

## 九、常见问题

### 1. 油工验收要不要晚上看？

建议看。晚上开灯后，尤其是射灯、洗墙灯、侧光会放大墙面波浪、刷痕和修补痕。

### 2. 墙面小瑕疵是不是都要返工？

不一定。要看位置、面积、是否明显和是否影响整体。严重色差、开裂、起皮要处理；极小且不明显的问题可协商。

### 3. 深色漆修补痕明显怎么办？

深色漆局部修补容易明显，严重时可能需要扩大修补范围甚至整面重刷。施工前应减少后期破坏并留同批次漆。

### 4. 油工验收后还会被安装破坏吗？

会。门套、柜体、踢脚线、灯具和开关安装都可能磕碰墙面，所以安装后还要统一修补和复验。

## 十、避坑提醒

1. 不要只在弱光下验收。
2. 不要面漆完成后才发现基层问题。
3. 不要没有色号记录就做色漆。
4. 不要安装后零散修补不复验。
5. 不要把返碱和发霉当普通瑕疵。
6. 不要只听“正常现象”不看整改方案。
7. 不要问题没闭环就付尾款。

## 十一、案例分析

### 案例一：白天看不出，晚上灯光下波浪明显

用户白天验收墙面觉得还可以，入住后开射灯发现电视墙波浪明显。  

分析：油工验收应结合侧光和实际灯光。

### 案例二：安装后墙面多处破损

柜体、门套、开关安装后墙面多处磕碰，施工方认为油工已验收。  

分析：油工应设置安装后统一修补和复验。

### 案例三：返碱墙面直接补漆

窗边返碱位置直接补漆，雨季后再次起皮。  

分析：返碱验收必须看水源和基层，不是表面颜色一致就合格。

## 十二、法规依据

油工验收应参考建筑装饰装修、涂饰工程、室内墙面基层处理、涂料产品施工说明和住宅装饰装修质量验收相关要求。实际项目应以合同约定、材料说明、施工记录和现场验收记录为准。

## 十三、用户咨询与AI回复模板

### 咨询一：油工验收怎么验？

先看材料和施工记录，再看墙面平整、阴阳角、色差、刷痕、流坠、漏刷、开裂、返碱和修补痕。白天自然光看一次，晚上开灯和侧光再看一次，问题拍照标记后统一整改复验。

### 咨询二：乳胶漆墙面有小瑕疵正常吗？

轻微小瑕疵可能存在，但明显色差、开裂、起皮、流坠、漏刷、刷痕和大面积发花不应直接接受。要看瑕疵位置、面积和是否影响整体效果。

### 咨询三：油工尾款什么时候付比较稳？

建议在面漆验收、安装后修补和复验完成后再结清。至少要把问题清单、整改方案和复验结果确认清楚。
