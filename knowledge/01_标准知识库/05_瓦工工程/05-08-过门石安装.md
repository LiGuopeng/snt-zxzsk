# 过门石安装

## 一、概述

过门石是门口区域用于衔接不同空间、不同地面材料和不同高度的节点材料，常见于卫生间门口、厨房门口、阳台门口、卧室与客厅交界处。它既有装饰和收口作用，也承担挡水、防潮、过渡高低差、保护门套和分隔空间的功能。

过门石安装看似简单，但它和防水、瓦工、木地板、门套、门槛、地漏坡度、卫生间门口止水都有关系。安装不当会出现门口渗水、木地板受潮、过门石空鼓断裂、门套底部发霉、地面高低差难看、收口缝隙大等问题。

## 二、适用范围

本文适用于：

1. 卫生间门口过门石安装。
2. 厨房门口过门石安装。
3. 阳台门口过门石安装。
4. 客厅与卧室、走廊与房间之间的地面收口。
5. 瓷砖与木地板之间的高低差处理。
6. 用户审核过门石报价、安装和验收。
7. AI 客服回答“过门石要不要装、怎么验收”等问题。

## 三、基础知识

### 1. 过门石的作用

| 作用 | 说明 |
|---|---|
| 收口 | 衔接瓷砖、木地板、地砖等不同材料 |
| 过渡 | 处理两个空间地面高低差 |
| 挡水 | 卫生间、阳台门口阻挡水外溢 |
| 防潮 | 减少潮气向木地板、门套扩散 |
| 分区 | 在视觉上划分空间 |
| 保护 | 保护门口边缘瓷砖和地板 |

### 2. 常见过门石材料

| 材料 | 特点 | 常见用途 | 注意事项 |
|---|---|---|---|
| 天然石材 | 质感自然，硬度较高 | 卫生间、阳台、厨房门口 | 注意色差、裂纹、渗色 |
| 人造石 | 颜色稳定，价格可控 | 多数门口收口 | 注意耐磨和质感 |
| 瓷砖加工条 | 与地砖统一 | 极简风、瓷砖通铺 | 加工和收口要求高 |
| 金属压条 | 薄、现代 | 木地板与瓷砖衔接 | 挡水能力有限 |
| 木质压条 | 与木地板匹配 | 卧室门口 | 潮湿区域慎用 |

### 3. 哪些地方需要过门石

| 位置 | 是否建议 | 原因 |
|---|---|---|
| 卫生间门口 | 通常建议 | 挡水、防潮、保护门套 |
| 阳台门口 | 视情况建议 | 防雨水、洗衣水外溢 |
| 厨房门口 | 视设计和地面材料 | 收口和防潮 |
| 卧室门口 | 视材料衔接 | 瓷砖和木地板过渡 |
| 全屋通铺区域 | 可弱化或取消 | 需提前设计收口方案 |

## 四、专业知识

### 1. 过门石安装核心指标

| 指标 | 要求 | 不合格风险 |
|---|---|---|
| 尺寸 | 与门洞宽度和地面材料匹配 | 缝隙大、收口难看 |
| 高度 | 与两侧完成面合理衔接 | 绊脚、积水、门打不开 |
| 坡向 | 有水区域应向湿区内侧或排水方向 | 水外溢 |
| 空鼓 | 粘结密实 | 断裂、松动 |
| 防水 | 卫生间门口应做好止水 | 门口渗水 |
| 收边 | 与门套、墙砖、地砖衔接整齐 | 观感差 |
| 材料 | 无裂纹、崩边、明显色差 | 后期断裂或不美观 |

### 2. 卫生间过门石特别标准

卫生间过门石不仅是装饰材料，更是防水门口节点的一部分。

| 项目 | 要求 |
|---|---|
| 防水上返 | 门口防水应有翻边或止水处理 |
| 高度控制 | 应防止卫生间水外溢 |
| 坡向 | 不应向干区倒坡 |
| 门套保护 | 门套底部避免长期受潮 |
| 接缝密封 | 与墙砖、地砖、门套交接处密封 |
| 闭水关系 | 过门石区域不应成为渗水薄弱点 |

### 3. 过门石与木地板衔接

| 衔接项 | 控制重点 | 风险 |
|---|---|---|
| 高度 | 过门石、木地板、地砖完成面协调 | 绊脚或压条突兀 |
| 防潮 | 卫生间门口保护木地板 | 木地板发黑起拱 |
| 伸缩缝 | 木地板需要伸缩空间 | 地板起拱 |
| 收口条 | 是否需要金属或木质压条 | 缝隙难看 |
| 门扇高度 | 门扇开启不受影响 | 门蹭地 |

### 4. 过门石与瓷砖通铺

现在很多用户喜欢全屋瓷砖通铺或弱化过门石，但湿区门口仍需要考虑挡水、防潮和高低差。

| 做法 | 优点 | 风险 |
|---|---|---|
| 传统过门石 | 挡水和收口明确 | 视觉分割明显 |
| 瓷砖加工过门条 | 视觉统一 | 防水和收口要求高 |
| 不装过门石 | 极简通铺 | 卫生间门口防水风险增加 |
| 金属压条收口 | 轻薄美观 | 挡水能力有限 |

### 5. 过门石安装常见错误

| 错误 | 后果 |
|---|---|
| 卫生间过门石倒坡 | 水流向干区 |
| 过门石空鼓 | 后期断裂、松动 |
| 门口防水未加强 | 门套、木地板受潮 |
| 高度未统筹 | 门口高低差明显 |
| 尺寸测量不准 | 两侧缝隙大 |
| 石材未检查裂纹 | 使用后开裂 |
| 与门套安装顺序冲突 | 收口不顺 |

| 4 | 加工过门石 | 尺寸、倒角、磨边 |

### 2. 业主监督流程

1. 确认哪些门口需要过门石。
2. 卫生间门口重点确认挡水和防水做法。
3. 铺贴前确认两侧完成面高度。
4. 安装时检查过门石是否空鼓。
5. 验收时倒少量水检查是否向干区流。
6. 拍摄门口防水、安装和收口照片。

## 七、关键标准

1. 过门石尺寸应与门洞和两侧地面材料匹配。
2. 卫生间门口过门石应兼顾挡水和防潮。
3. 过门石不得明显空鼓、松动。
4. 有水区域过门石不应向干区倒坡。
5. 与木地板衔接时应预留合理伸缩和收口。
6. 门口高度不得影响门扇开启。
7. 边缘收口应平整、密封、无明显缝隙。

## 八、验收标准

### 1. 合格标准

| 验收项 | 合格表现 |
|---|---|
| 尺寸 | 与门洞吻合 |
| 高度 | 两侧过渡合理 |
| 坡向 | 不向干区倒坡 |
| 空鼓 | 敲击无明显空鼓 |
| 表面 | 无裂纹、崩边、明显色差 |
| 收口 | 与瓷砖、地板、门套衔接整齐 |
| 密封 | 潮湿区域边缘密封良好 |

### 2. 不合格表现

1. 卫生间门口水向外流。
2. 过门石明显松动或空鼓。
3. 过门石开裂、崩边。
4. 与木地板衔接高低差过大。
5. 门扇开启受影响。
6. 门套底部容易接触积水。
7. 收口缝隙大且未密封。

## 九、常见问题

### 1. 卫生间一定要装过门石吗？

通常建议装或采用等效挡水收口方案。卫生间门口是防水高风险位置，过门石可以帮助挡水、防潮和保护门套。如果不装，需要有明确的防水和收口替代方案。

### 2. 过门石可以和地砖一样吗？

可以使用瓷砖加工做过门条，让视觉更统一。但要关注强度、切割、收口、防水和门口高低差，不能只看美观。

### 3. 过门石空鼓要不要处理？

建议处理。过门石处于门口频繁踩踏位置，空鼓可能导致开裂、松动和边缘破损，卫生间门口还可能影响防水节点。

### 4. 木地板和瓷砖高低差怎么处理？

应提前核算两侧材料厚度和完成面高度。轻微高低差可用压条过渡，明显高低差应在找平和铺贴阶段调整。

## 十、避坑提醒

1. 不要卫生间门口不做挡水方案。
2. 不要过门石倒坡向干区。
3. 不要过门石空鼓后继续装门套和地板。
4. 不要只看石材颜色，忽略裂纹和崩边。
5. 不要门口高度没算清就找平铺砖。
6. 不要忽略木地板伸缩缝。
7. 不要把过门石安装和防水完全割裂。

## 十一、案例分析

### 案例一：卫生间过门石倒坡

用户卫生间洗澡后门口木地板发黑。检查发现过门石和卫生间门口地面向外倒坡，水汽和少量明水长期流向干区。  

分析：卫生间过门石必须关注坡向和挡水，不能只做平。

### 案例二：过门石空鼓断裂

卧室门口过门石安装后未检查空鼓，入住几个月后中间开裂。  

分析：过门石承受频繁踩踏，粘结层必须饱满密实。

### 案例三：取消过门石但没有替代方案

用户追求通铺效果取消卫生间过门石，门口防水和止水未加强。入住后门套底部受潮发霉。  

分析：可以弱化过门石，但不能弱化门口防水和挡水逻辑。

## 十二、法规依据

过门石安装应结合住宅装饰装修、建筑地面工程、防水工程、木地板铺装和门窗安装相关要求执行。实际项目应以合同约定、设计方案、材料说明和现场验收记录为准。

## 十三、用户咨询与AI回复模板

### 咨询一：卫生间过门石怎么验收？

主要看是否有挡水作用，水不能向干区倒流；过门石本身不能空鼓、松动、开裂；与瓷砖、门套、木地板交接处要收口整齐并做好密封。

### 咨询二：现在流行通铺，可以不要过门石吗？

可以考虑，但卫生间、阳台等有水区域必须有替代挡水和防潮方案，比如门口防水加强、止水处理、合理高低差和密封收口，不能只是为了好看直接取消。

### 咨询三：过门石空鼓怎么办？

过门石在门口受力频繁，空鼓不建议忽略。应标记位置，检查粘结层是否饱满，必要时拆除重装，并确认门口防水和收口没有被破坏。
