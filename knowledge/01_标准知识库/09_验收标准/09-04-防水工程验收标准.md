# 防水工程验收标准

## 一、概述

防水工程验收是住宅装修中关系渗漏风险和邻里纠纷的关键验收。卫生间、厨房、阳台、露台、飘窗、地暖回填区等都可能涉及防水。防水验收不是只看“刷没刷”，而是要看基层、节点、涂刷范围、厚度、闭水试验、排水坡度、门口止水和后续保护。

防水一旦失败，后期往往需要拆砖维修，成本高、周期长、责任复杂。因此防水必须在贴砖前完成验收。

## 二、适用范围

本文适用于住宅装修中的卫生间防水、厨房局部防水、阳台防水、露台防水、管根防水、门口止水、墙地面防水和闭水验收。

## 三、基础知识

### 1. 防水验收包括什么

| 内容 | 重点 |
|---|---|
| 基层 | 平整、坚实、无起砂、无积水 |
| 阴阳角 | 圆弧或加强处理 |
| 管根 | 堵漏和附加层 |
| 墙面 | 涂刷高度符合空间需求 |
| 地面 | 涂刷均匀、无漏刷 |
| 门口 | 止水和外溢控制 |
| 闭水 | 时间和水位满足要求 |
| 保护 | 贴砖前不得破坏防水层 |

### 2. 防水高风险位置

| 位置 | 风险 |
|---|---|
| 地漏周边 | 管根渗漏 |
| 马桶排污管 | 管壁和楼板交界渗漏 |
| 淋浴区墙角 | 长期受水 |
| 门槛石两侧 | 水外渗到客厅卧室 |
| 管道井 | 管根复杂 |
| 阳台外墙 | 雨水倒灌 |
| 飘窗 | 外墙渗水 |

## 四、专业知识

### 1. 基层验收

| 检查项 | 合格表现 |
|---|---|
| 平整 | 不明显坑洼 |
| 坚实 | 不起砂、不空鼓 |
| 清洁 | 无浮灰油污 |
| 含水 | 符合材料施工要求 |
| 坡度 | 地面排水方向合理 |

### 2. 涂刷验收

| 检查项 | 合格表现 |
|---|---|
| 范围 | 淋浴区、干区、门口按要求覆盖 |
| 高度 | 淋浴墙面高度重点满足需求 |
| 厚度 | 符合材料说明，不露底 |
| 遍数 | 按产品要求涂刷 |
| 方向 | 多遍交叉更均匀 |
| 表面 | 无开裂、针孔、起皮、漏刷 |

### 3. 闭水试验

| 项目 | 要点 |
|---|---|
| 时间 | 按合同、规范或当地要求执行，常见不少于 24 小时 |
| 水位 | 能覆盖地面并观察变化 |
| 楼下检查 | 看顶面、管根、墙角是否渗漏 |
| 门口检查 | 看是否外溢或渗到外侧 |
| 记录 | 拍照记录开始和结束状态 |

## 六、验收流程

1. 防水施工前验收基层。
2. 检查管根、阴阳角、门口是否加强。
3. 第一遍涂刷后检查是否漏刷。
4. 多遍完成后检查厚度和表面状态。
5. 防水干燥固化后做闭水试验。
6. 到楼下或相邻空间检查渗漏。
7. 闭水合格后拍照记录。
8. 贴砖前做防水层保护，避免踩踏破坏。

## 七、关键标准

| 项目 | 标准 |
|---|---|
| 基层 | 平整坚实干净 |
| 节点 | 管根、阴角、门口加强 |
| 涂刷 | 范围够、厚度够、无漏刷 |
| 闭水 | 无渗漏、无异常水位下降 |
| 排水 | 坡向地漏，不积水 |
| 保护 | 后续施工不破坏防水 |

## 八、验收标准

| 区域 | 必查动作 | 不合格表现 |
|---|---|---|
| 卫生间地面 | 闭水 | 楼下渗水、墙角潮湿 |
| 淋浴墙面 | 测高度和观察涂层 | 高度不足、漏刷 |
| 管根 | 近距离检查 | 开裂、翘边、未加强 |
| 门口 | 闭水时观察外侧 | 门外渗水 |
| 阳台 | 倒水和排水观察 | 积水、倒坡 |
| 厨房 | 水槽和地面风险区 | 管根未处理 |

## 九、常见问题

### 1. 防水刷了就一定不会漏吗？

不一定。防水效果取决于基层、材料、节点、厚度、闭水和后续保护。只刷一遍或节点没处理，仍可能漏。

### 2. 闭水不漏就万事大吉吗？

闭水合格是重要条件，但贴砖、打孔、安装洁具时如果破坏防水，后期仍可能漏。因此后续施工也要保护。

### 3. 厨房一定要做防水吗？

要看设计和当地做法。厨房有水槽、洗碗机、净水器等水点，至少管根和局部防水要重视；是否全做应结合合同和现场风险。

## 十、避坑提醒

1. 防水前基层不合格不要急着刷。
2. 管根、阴阳角、门口是重点，不要只看大面。
3. 闭水期间不要随意放水。
4. 楼下检查必须做。
5. 防水层未干不要贴砖。
6. 贴砖和安装阶段不要随意打孔破坏。
7. 卫生间门口渗水比地面漏水更隐蔽。
8. 防水验收要拍开始和结束照片。

## 十一、案例分析

### 案例 1：门口返潮

卫生间闭水时只看楼下不漏，未检查门槛外侧。入住后卧室地板门口发黑。

经验：防水验收要检查门口止水和外侧渗水。

### 案例 2：管根渗漏

防水大面刷得很好，但地漏管根未加强，闭水后楼下管根周边出现水印。

经验：防水成败常在节点，不在大面。

## 十三、用户咨询与AI回复模板

用户问：卫生间防水怎么验收？

AI 回复：先看基层是否平整坚实，再看管根、阴阳角、门口有没有加强；防水涂层要范围够、无漏刷、无开裂。最关键是做闭水试验，闭水期间到楼下看顶面和管根是否渗漏，同时检查卫生间门口外侧是否返潮。闭水合格后拍照记录，再允许贴砖。
