# 水电工程验收标准

## 一、概述

水电工程验收是装修验收中风险最高、返工成本最高的节点之一。水电关系到漏水、漏电、跳闸、用电容量、设备使用、后期检修和入住安全。水电验收必须在封槽、回填、贴砖、吊顶封板、柜体安装前完成。

水电验收不能只看“横平竖直”，更要看点位是否合理、回路是否清晰、线径是否匹配、管路是否固定、接口是否可靠、水管是否打压、电路是否绝缘、照片是否留档。

## 二、适用范围

本文适用于住宅装修中的强电、弱电、给水、排水、地漏、角阀、热水循环、净水、地暖和设备预留水电验收。

## 四、专业知识

### 1. 电路验收

| 检查项 | 重点 |
|---|---|
| 线径 | 与回路负载匹配 |
| 回路 | 厨房、卫生间、空调等宜独立规划 |
| 穿管 | 电线应穿管保护 |
| 接头 | 不宜在线管内随意接线 |
| 底盒 | 固定牢、位置正、深度合理 |
| 强弱电 | 保持合理间距，交叉处做保护 |
| 接地 | 厨卫、大功率插座重点检查 |
| 漏保 | 湿区和大功率回路要重视 |

### 2. 水路验收

| 检查项 | 重点 |
|---|---|
| 管材 | 品牌、规格与合同一致 |
| 走向 | 清晰可拍照记录 |
| 固定 | 管卡牢固，不晃动 |
| 冷热水 | 间距和方向正确 |
| 接口 | 熔接或连接规范，无渗漏 |
| 打压 | 达到约定测试要求 |
| 保温 | 热水管、冷凝风险区域按需处理 |
| 出水口 | 高度、间距、水平满足洁具 |

### 3. 排水验收

| 检查项 | 重点 |
|---|---|
| 坡度 | 排水顺畅 |
| 管径 | 满足设备排水量 |
| 防臭 | 地漏、台盆、洗衣机排水防臭 |
| 检修 | 存水弯和检修口可达 |
| 固定 | 排水管不松动 |
| 保护 | 管口封堵，防止建筑垃圾进入 |

## 六、验收流程

1. 对照水电图逐个核对点位。
2. 核对电线、水管、底盒、线管材料。
3. 检查强电回路和弱电走线。
4. 检查给水管固定、冷热水方向、出水口高度。
5. 做水管打压测试并记录。
6. 做电路绝缘、通断和回路检查。
7. 检查排水坡度、管口保护和防臭条件。
8. 全屋拍照留档并标注尺寸。
9. 整改后复验，合格再封槽。

## 七、关键标准

| 项目 | 标准 |
|---|---|
| 点位 | 与图纸和使用需求一致 |
| 材料 | 与合同一致，无偷换 |
| 电路 | 回路清晰，线径匹配，接地可靠 |
| 水路 | 打压合格，无渗漏 |
| 排水 | 坡度合理，排水顺畅 |
| 固定 | 管线和底盒牢固 |
| 安全 | 强弱电、水电交叉处理合理 |
| 留档 | 管线照片完整 |

## 八、验收标准

| 分项 | 必查动作 | 不合格表现 |
|---|---|---|
| 插座点位 | 对照图纸 | 少点、错位、被柜体挡 |
| 照明回路 | 开关控制核对 | 双控错、回路混乱 |
| 厨房电路 | 核对大功率设备 | 共用过多、容量不足 |
| 卫生间电路 | 接地和防溅 | 无接地、防护不足 |
| 水管打压 | 观察压力变化 | 压力下降、接口渗水 |
| 冷热水口 | 测水平和间距 | 花洒、龙头装不上 |
| 排水口 | 倒水检查 | 排水慢、返水、反味 |
| 弱电 | 测通断和位置 | 网线不通、位置不合理 |

## 九、常见问题

### 1. 水电横平竖直就是好吗？

横平竖直便于后期识别，但不是唯一标准。更重要的是回路合理、线径匹配、管线固定、接头可靠、测试合格和照片留档。

### 2. 水管打压必须做吗？

必须做。打压是发现接口渗漏和管路问题的重要手段。未打压就封槽，后期漏水维修成本高且难定责。

### 3. 插座多装会不会影响安全？

插座数量本身不是问题，关键是回路和线径是否匹配。厨房、卫生间、空调、烘干机、蒸烤箱等大功率设备要重点规划。

## 十、避坑提醒

1. 家电型号不明确时，水电点位容易错。
2. 插座不要被柜体、床头、门套、家电挡住。
3. 强弱电不要随意同管。
4. 水管未打压不要封槽。
5. 排水口施工期间必须封堵。
6. 厨房卫生间要重视接地和漏保。
7. 水电照片必须按房间保存。
8. 后期改动点位要同步更新图纸。

## 十一、案例分析

### 案例 1：蒸烤箱跳闸

厨房多个大功率家电共用一个回路，入住后蒸烤箱和电饭煲同时使用跳闸。

经验：水电验收要看回路规划，不只是看插座有没有电。

### 案例 2：花洒装不上

冷热水口间距不准且不水平，贴砖后安装花洒困难。

经验：水口位置必须在贴砖前复核。

## 十三、用户咨询与AI回复模板

用户问：水电验收重点看什么？

AI 回复：水电验收重点看点位、材料、回路、打压、绝缘和照片。电路要确认线径和回路能承载家电，水路要打压无渗漏，排水要顺畅防臭。验收后要把每个房间的水电走向拍照保存，合格后再封槽。
