# 木工工程验收标准

## 一、概述

木工工程验收主要检查吊顶、隔墙、背景墙、窗帘盒、门套基层、柜体基层、木饰面基层和现场木作的结构、尺寸、牢固度、平整度、防潮防火和收口条件。木工工程承上启下，前面连接水电、空调、新风，后面影响油工、安装、定制和灯具。

木工验收不能只看造型是否好看，更要看基层是否可靠、吊顶是否牢固、检修口是否保留、灯槽是否顺直、柜体尺寸是否准确、材料是否符合环保和防潮要求。

## 二、适用范围

本文适用于住宅装修中的轻钢龙骨石膏板吊顶、局部吊顶、窗帘盒、背景墙、木基层、隔墙、现场柜体、门套基层、设备检修口和相关木作验收。

### 1. 吊顶验收

| 检查项 | 合格表现 |
|---|---|
| 吊杆 | 固定牢固，间距合理 |
| 龙骨 | 顺直、牢固、防锈 |

| 接缝 | 留缝和防裂处理合理 |
| 转角 | 不宜简单直缝拼接 |

### 2. 窗帘盒验收

| 检查项 | 要点 |

| 宽度 | 满足单轨、双轨或电动轨 |

| 承重 | 基层能固定轨道 |
| 电源 | 电动窗帘预留插座 |
| 收口 | 油工后边缘自然 |

## 六、验收流程

1. 核对板材、龙骨、辅材品牌和规格。
2. 封板前检查吊杆、龙骨、空调新风管线和检修口。
3. 检查窗帘盒、电动窗帘电源和轨道空间。
4. 检查柜体、门套、背景墙基层尺寸。
5. 封板后检查平整度、接缝、转角和灯槽。
6. 油工前检查防裂处理和钉眼。
7. 记录问题，整改复验。

## 七、关键标准

| 项目 | 标准 |
|---|---|
| 结构 | 吊顶、柜体、基层牢固 |
| 尺寸 | 与设计图一致 |
| 平整 | 无明显起伏 |
| 顺直 | 灯槽、窗帘盒、阴阳角顺直 |
| 防裂 | 接缝、转角处理合理 |
| 检修 | 设备检修口可用 |
| 材料 | 环保、防潮、防火按需满足 |

## 八、验收标准

| 检查项 | 合格表现 | 不合格表现 |
|---|---|---|
| 吊顶 | 不晃、不裂、顺直 | 龙骨松、封板不平 |
| 检修口 | 能打开检修 | 被封死或太小 |
| 窗帘盒 | 轨道空间足 | 后期装不了轨道 |
| 柜体基层 | 方正牢固 | 门板难装、缝隙大 |
| 背景墙 | 平整稳定 | 起伏、开裂 |
| 门套基层 | 垂直牢固 | 木门安装后门缝不均 |

## 九、常见问题

### 1. 吊顶封板后还能看龙骨吗？

基本看不到，所以封板前必须验收并拍照。封板后只能通过平整、开裂、检修口等间接判断。

### 2. 窗帘盒多宽合适？

要看轨道数量、窗帘层数和是否电动。验收时不能只看外观，要确认轨道能安装、窗帘能顺畅拉动。

### 3. 木工柜体和定制柜哪个好？

不是验收标准问题。现场木作更依赖工人手艺和封边细节，定制柜更依赖工厂加工和安装。无论哪种，都要看尺寸、环保、封边、牢固和五金配合。

## 十、避坑提醒

1. 吊顶封板前必须验收龙骨。
2. 中央空调、新风检修口不要为美观取消。
3. 重型灯具位置要提前加固。
4. 窗帘盒要提前确认电动轨道需求。
5. 卫生间、阳台附近木基层要防潮。
6. 板材环保等级要核对，不要只听口头说。
7. 木工尺寸错误会连锁影响安装。

## 十一、案例分析

### 案例 1：电动窗帘装不了

窗帘盒宽度不足，且未预留电源，后期只能明线改造。

经验：木工验收要联动后期安装设备。

### 案例 2：吊顶检修口被封死

中央空调出现排水问题，发现检修口位置太小且被柜体挡住。

经验：检修口是功能需求，不是可有可无的装饰细节。
