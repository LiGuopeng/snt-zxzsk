# 安装工程验收标准

## 一、概述

安装工程验收是装修收尾阶段的集中验收，覆盖开关插座、灯具、洁具、五金、木门、橱柜、地板、家电和智能设备。安装工程直接决定入住后的使用体验，也最容易出现多方责任交叉：装修方说是主材问题，主材方说是水电问题，家电方说是柜体预留问题。

安装验收的核心是“装得对、装得牢、能使用、能检修、不破坏、不漏水、不漏电”。不能只看外观是否装好，必须做通水、通电、开合、承重、排水、排烟和试运行。

## 二、适用范围

本文适用于住宅装修后期所有安装项目的综合验收，包括电气面板、照明、卫浴、厨房、门类、地面、柜体、家电、收纳五金和智能设备。

## 三、基础知识

### 1. 安装验收分类

| 类别 | 内容 | 风险 |
|---|---|---|
| 电气安装 | 开关插座、灯具、浴霸 | 漏电、松动、控制错误 |
| 水路安装 | 龙头、花洒、马桶、水槽 | 漏水、反味、排水慢 |
| 木作安装 | 木门、柜体、踢脚线 | 变形、卡顿、收口差 |
| 定制安装 | 橱柜、衣柜、台面 | 尺寸错误、五金不顺 |
| 地面安装 | 地板、压条 | 起拱、异响、绊脚 |
| 家电安装 | 烟机、灶具、洗碗机、空调 | 装不上、散热差、排水差 |
| 五金安装 | 毛巾架、挂件、门吸 | 松动、打孔破坏 |

### 2. 安装验收的特殊性

| 特殊性 | 说明 |
|---|---|
| 责任多方 | 装修、主材、定制、售后都可能参与 |
| 问题高频 | 入住后每天使用，缺陷容易放大 |
| 破坏风险 | 打孔可能打穿水电、防水、瓷砖 |
| 联动强 | 家电、柜体、水电、墙地面互相影响 |
| 需要试运行 | 很多问题只靠目测发现不了 |

## 六、验收流程

1. 核对产品型号、颜色、数量和位置。
2. 检查外观破损、污染、划痕。
3. 对电气项目逐个通电测试。
4. 对水路项目逐个通水排水测试。
5. 对门、柜、抽屉、五金做开合拉拽测试。
6. 对家电做试运行。
7. 检查安装造成的墙地面破坏。
8. 检查插座、阀门、滤芯、检修口是否可操作。
9. 编号记录问题，约定整改和复验。

## 七、关键标准

| 标准 | 说明 |
|---|---|
| 装对 | 型号、方向、位置正确 |
| 装牢 | 无松动、晃动、脱落风险 |
| 能用 | 功能完整，操作顺畅 |
| 不漏 | 水、气、烟、冷凝水不漏 |
| 安全 | 电气、燃气、承重安全 |
| 可修 | 插座、阀门、检修口可达 |
| 美观 | 收口干净，无明显破坏 |

## 八、验收标准

| 项目 | 必查动作 | 不合格表现 |
|---|---|---|
| 开关插座 | 通电和接线测试 | 无电、接错、松动 |
| 灯具 | 全开全关 | 闪烁、不亮、控制错 |
| 马桶 | 多次冲水 | 渗漏、晃动、反味 |

## 九、常见问题

### 1. 安装验收能不能只看外观？

不能。安装工程最重要的是功能和安全。有水要试水，有电要测试，有门柜要开合，有家电要试运行。

### 2. 安装造成墙面破坏怎么办？

先拍照记录破坏位置和安装项目，再确认是正常修补范围还是打错孔、崩瓷、污染等安装责任。责任明确后再安排修补。

### 3. 家电装不上是谁的问题？

要看设计尺寸、家电型号、柜体预留、水电点位和安装说明。不能简单归责，应对照图纸和订单判断。

## 十、避坑提醒

1. 安装单不要未试机就签。
2. 水槽、马桶、洗衣机、洗碗机必须试水。
3. 插座测试不能省。
4. 门、柜、抽屉要反复开合。
5. 重型灯具、吊柜、热水器要重视承重。
6. 家电插座和阀门不能封死。
7. 打孔前要查水电照片。
8. 发现破坏立刻记录。

## 十一、案例分析

### 案例 1：洗碗机未试水

安装后直接签字，三天后发现进水接口慢漏，橱柜泡水。

经验：有水设备必须试运行并用纸巾检查接口。

### 案例 2：吊柜松动

入住后吊柜放重物下坠，检查发现固定点不足。

经验：安装验收不仅看柜门好不好看，也要看固定和承重。

## 十三、用户咨询与AI回复模板

用户问：安装工程验收重点是什么？

AI 回复：安装验收重点是“通水、通电、开合、承重、试运行”。插座要测试零火地，灯具要全开，洁具和水槽要试水，木门和柜门要反复开合，地板要走一遍听异响，家电要按说明试运行。发现问题拍照编号，不要未测试就签安装单。
