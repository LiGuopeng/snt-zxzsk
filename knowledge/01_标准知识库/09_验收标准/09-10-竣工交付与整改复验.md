# 竣工交付与整改复验

## 一、概述

竣工交付是装修项目从施工阶段进入使用阶段的最终确认，整改复验则是确保问题真正闭环的关键动作。很多装修项目不是没有验收，而是“验收发现问题后没有闭环”，导致入住后反复维修、责任不清、尾款争议和质保扯皮。

竣工交付不等于打扫干净，也不等于拍几张完工照。完整交付应包括全屋质量验收、功能测试、问题清单、整改复验、资料移交、保修确认、尾款支付和钥匙交接。

## 二、适用范围

本文适用于住宅装修竣工阶段，包括整装、半包、全包、局部改造、精装房升级和旧房翻新项目的最终验收与交付。

### 1. 竣工交付包括什么

| 内容 | 说明 |
|---|---|
| 工程质量 | 各工种施工质量 |

| 费用结算 | 尾款、增减项、扣款 |

### 2. 整改复验是什么

整改复验是对验收中发现的问题进行整改后再次检查确认。没有复验的整改不算闭环。

| 阶段 | 动作 |
|---|---|
| 发现问题 | 拍照编号 |
| 记录问题 | 写位置、现象、责任 |
| 确认方案 | 写整改方式 |
| 约定期限 | 写完成时间 |
| 完成整改 | 责任方处理 |
| 复验确认 | 业主或监理检查 |
| 关闭问题 | 记录复验结果 |

### 3. 尾款和验收关系

尾款应与质量确认和整改闭环挂钩。若存在重大质量问题，应谨慎支付全部尾款；若是轻微问题，可书面约定整改期限和保留合理金额。

| 问题类型 | 付款建议 |
|---|---|
| 重大安全问题 | 暂缓相关款项 |
| 漏水漏电 | 整改复验后再支付 |
| 材料不符 | 查清责任和补偿后处理 |
| 功能问题 | 保留整改款 |
| 轻微观感 | 记录后可协商支付 |

## 六、验收流程

### 1. 竣工交付流程

1. 施工方完成自检。
2. 清理现场和建筑垃圾。
3. 业主、项目经理、监理共同验收。
4. 按空间和工种逐项检查。
5. 进行通水、通电、试机、开合测试。
6. 编制整改清单。
7. 确认整改责任、方式和期限。
8. 整改完成后复验。
9. 移交图纸、说明书、保修资料。
10. 确认费用结算和尾款。
11. 办理钥匙、门禁、设备账号等交接。

### 2. 整改复验流程

| 步骤 | 内容 |
|---|---|
| 编号 | 每个问题一个编号 |
| 定位 | 写清房间和具体位置 |
| 描述 | 说明问题现象 |
| 责任 | 确认责任方 |
| 方案 | 写明怎么修 |
| 期限 | 写明完成日期 |
| 复验 | 检查是否真正解决 |
| 关闭 | 记录复验结果 |

## 九、常见问题

### 1. 竣工验收发现问题还能收房吗？

要看问题严重程度。轻微问题可以写入整改清单后交付，重大问题如漏水、漏电、防水失败、燃气隐患、严重材料不符，应整改复验后再确认。

### 2. 整改清单怎么写才有用？

要写清位置、现象、责任方、整改方案、截止时间和复验方式。只写“墙面有问题”没有执行力。

### 3. 尾款什么时候付比较合适？

通常应在主要工程验收合格、重大问题整改完成、资料移交清楚后支付。若存在遗留问题，可按合同和协商保留合理尾款。

### 4. 保修从什么时候开始？

一般从竣工验收或交付确认后开始计算，具体以合同约定为准。保修范围、期限和联系人必须书面确认。

## 十、避坑提醒

1. 竣工验收不要只看保洁效果。
2. 整改问题不要只发微信群，要形成表单。
3. 重大问题未复验不要签无异议。
4. 尾款不要脱离整改闭环。
5. 保修资料和水电照片必须收齐。
6. 家电、智能设备账号和密码要交接。
7. 钥匙、门禁卡、遥控器要清点。
8. 入住前要再做一次通水通电测试。

## 十一、案例分析

### 案例 1：整改没有复验

竣工时发现墙面开裂，工长说已经安排修补。业主未复验就付尾款，入住后裂缝再次出现，沟通困难。

经验：整改完成不等于问题关闭，必须复验确认。

### 案例 2：资料未移交

业主入住后想安装挂架，没有水电照片，不敢打孔。联系装修公司后资料遗失。

经验：竣工交付必须收齐水电照片和竣工资料。

## 十三、用户咨询与AI回复模板

### 模板 1：竣工验收

用户问：装修竣工验收要注意什么？

AI 回复：竣工验收要按空间和系统查，不要只看表面。水要试漏和排水，电要测插座和开关，门柜要开合，地板要踩踏，家电要试机，墙面顶面要看开裂和色差。发现问题写整改清单，明确责任方、整改方式和期限，整改后复验再确认尾款和交付。

### 模板 2：整改清单

用户问：装修问题很多，怎么记录？

AI 回复：建议每个问题单独编号，写清房间位置、问题现象、照片、责任方、整改方案和完成时间。例如“主卫马桶底部渗水，洁具安装方负责重装密封，3 天内完成，复验方式为连续冲水和纸巾检查”。这样后续才容易闭环。
