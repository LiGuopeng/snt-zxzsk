# 全屋收纳与柜体补充

## 一、概述

全屋收纳是软装阶段决定长期居住秩序的核心内容。硬装阶段的定制柜解决了大框架，软装阶段的收纳则解决真实物品如何分类、拿取、归位、隐藏、展示和维护。

很多家庭装修完看起来很美，但入住三个月后杂物堆满台面，原因不是房子太小，而是收纳没有按物品、频率和动线设计。全屋收纳不是多买柜子，而是让每类物品都有合适位置。

## 二、适用范围

本文适用于玄关、客厅、厨房、餐厅、卧室、衣帽间、儿童房、书房、卫生间、阳台、储物间等空间的收纳规划、成品柜补充、收纳用品选购和验收。

## 六、规划流程

1. 盘点现有物品。
2. 按空间和类别分类。
3. 判断高频、低频、展示和隐藏物品。
4. 先用现有柜体分配位置。
5. 找出收纳缺口。
6. 再购买成品柜和收纳用品。
7. 贴标签并试用一段时间。
8. 根据真实习惯调整。

## 七、关键标准

| 标准 | 说明 |
|---|---|
| 就近收纳 | 使用地和收纳地接近 |
| 高频顺手 | 常用物品不需要弯腰翻找 |
| 分类清楚 | 家人能找到也能放回 |
| 容量留余 | 不要一开始塞满 |
| 易清洁 | 开放收纳不宜过多 |
| 安全 | 高柜防倾倒，重物放低处 |

## 八、验收标准

| 检查项 | 合格表现 |
|---|---|
| 分类 | 物品有明确位置 |
| 动线 | 拿取顺手 |
| 容量 | 有余量 |
| 稳固 | 柜体和架子不晃 |
| 防潮 | 厨卫阳台收纳不易受潮 |
| 标识 | 家庭成员容易理解 |
| 美观 | 开放区整洁不过满 |

## 九、常见问题

### 1. 收纳是不是柜子越多越好？

不是。柜子多但分类混乱，仍然会乱。收纳要按物品和动线规划，不是简单增加柜体。

### 2. 开放收纳好不好？

开放收纳拿取方便，但容易积灰和显乱。适合少量高频物品或展示品，不适合大量杂物。

### 3. 厨房台面总是乱怎么办？

先看小家电和调料是否有固定位置，再看插座和收纳动线。台面只保留高频物品，低频家电进柜。

## 十、避坑提醒

1. 不要没盘点物品就买收纳盒。
2. 收纳用品规格不要太多，否则更乱。
3. 厨卫收纳要防潮防霉。
4. 重物不要放高处。
5. 儿童玩具收纳要孩子能自己拿放。
6. 开放格不要做太多。
7. 成品柜要确认尺寸和防倾倒。
8. 收纳要留 20% 左右余量更好用。

## 十一、案例分析

### 案例 1：收纳盒买了一堆却更乱

业主没有先分类物品，按颜值买了大量收纳盒，结果尺寸不合，很多盒子空着，杂物仍然堆在外面。

经验：先盘点分类，再买收纳用品。

### 案例 2：玄关鞋柜不够用

鞋柜只按常住人口估算，没有考虑换季鞋、拖鞋、雨具和快递工具，入住后玄关长期杂乱。

经验：玄关收纳要按真实出门回家动作设计。

## 十二、法规依据

收纳家具涉及家具产品质量、儿童安全、防倾倒、环保和消费者权益等相关标准。高柜、书柜、斗柜等应按产品说明进行固定。

## 十三、用户咨询与AI回复模板

用户问：家里收纳怎么规划？

AI 回复：先不要急着买收纳盒。你可以先按空间盘点物品，再按使用频率分类：每天用的放顺手，换季低频放高处或深处，重物放低处。收纳位置尽量靠近使用场景，比如玄关放钥匙雨伞，厨房水槽下放清洁用品，餐边柜放水杯零食。最后再根据缺口买收纳盒或成品柜。
