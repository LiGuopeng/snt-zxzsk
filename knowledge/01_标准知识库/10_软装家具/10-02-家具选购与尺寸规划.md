# 家具选购与尺寸规划

## 一、概述

家具选购与尺寸规划是软装阶段最重要的基础工作。家具买错通常不是“款式不好看”，而是尺寸不合、比例失衡、动线拥挤、搬不进去、挡插座、挡柜门、影响开门、使用不舒服或环保不达标。

家具规划必须先从空间尺寸、使用动作和家庭成员需求出发，再考虑风格和价格。尤其是沙发、床、餐桌、书桌、衣柜、成品柜、茶几等大件，一旦进场后发现不合适，退换成本高、时间长、还可能损坏墙地面。

## 二、适用范围

本文适用于客厅、卧室、餐厅、书房、儿童房、老人房、玄关、阳台等空间的成品家具选购、尺寸复核、动线规划和进场验收。

## 三、基础知识

### 1. 家具选购的核心维度

| 维度 | 说明 |
|---|---|
| 尺寸 | 长宽高是否适合空间 |
| 动线 | 人能否顺畅通过 |
| 功能 | 是否满足真实使用 |
| 舒适 | 坐、躺、写、吃是否舒服 |
| 材质 | 耐用、环保、易清洁 |
| 风格 | 与硬装和其他家具协调 |
| 安全 | 稳固、防倾倒、防磕碰 |
| 售后 | 退换、安装、质保是否清楚 |

### 2. 家具下单前必量尺寸

| 尺寸 | 用途 |
|---|---|
| 房间净尺寸 | 判断家具最大体量 |
| 门洞宽高 | 判断能否搬入 |
| 电梯尺寸 | 判断大件运输 |
| 楼道转角 | 判断是否能转弯 |
| 插座位置 | 避免被挡 |
| 窗台高度 | 影响书桌、床头和柜体 |
| 柜门开合范围 | 避免家具冲突 |
| 空调风口 | 避免直吹人 |

## 四、专业知识

### 1. 客厅家具尺寸规划

| 家具 | 规划重点 |
|---|---|
| 沙发 | 坐深、长度、靠背高度、与电视距离 |
| 茶几 | 不阻碍通行，边角安全 |
| 电视柜 | 不挡插座和弱电口 |
| 边几 | 不影响沙发起身 |
| 休闲椅 | 留出旋转或拉动空间 |
| 地毯 | 覆盖沙发前区，便于清洁 |

客厅最常见错误是沙发过大、茶几过宽、电视柜挡插座。小户型可考虑边几替代大茶几，避免中间动线拥堵。

### 2. 卧室家具尺寸规划

| 家具 | 规划重点 |
|---|---|
| 床 | 床体外径不是床垫尺寸 |
| 床头柜 | 不挡衣柜门和插座 |
| 衣柜 | 开门、抽屉、床侧通道 |
| 梳妆台 | 灯光和插座 |
| 书桌 | 椅子后退空间 |
| 斗柜 | 防倾倒固定 |

卧室规划要先确定床，再确定衣柜、床头柜和通道。床垫 1.8 米不等于床外径 1.8 米，软包床、悬浮床、排骨架床的外径差异很大。

### 3. 餐厅家具尺寸规划

| 家具 | 规划重点 |
|---|---|
| 餐桌 | 桌长和家庭人数匹配 |
| 餐椅 | 拉出后仍能通行 |
| 餐边柜 | 不挡开关插座 |
| 岛台 | 周边通道和用电 |
| 儿童餐椅 | 摆放和收纳 |

餐桌不能只看桌面尺寸，还要算椅子拉出空间。餐边柜与冰箱、厨房门、过道的关系也要提前确认。

### 4. 书房家具尺寸规划

| 家具 | 规划重点 |
|---|---|
| 书桌 | 深度、腿部空间、显示器距离 |
| 人体工学椅 | 后退和旋转空间 |
| 书柜 | 承重、防倾倒 |
| 文件柜 | 抽屉拉出空间 |
| 沙发床 | 展开后是否占满房间 |

### 5. 家具材质选择

| 材质 | 优点 | 风险 |
|---|---|---|
| 实木 | 质感好，可修复 | 价格高，受湿度影响 |
| 板式 | 款式多，性价比高 | 封边和环保要看清 |
| 金属 | 轻薄、现代 | 冷感、磕碰 |
| 玻璃 | 通透 | 易留指纹，儿童家庭慎用 |
| 皮革 | 质感强 | 维护要求高，怕划 |
| 布艺 | 温暖舒适 | 易脏，需可拆洗更好 |
| 岩板石材 | 耐热耐磨 | 边角脆，重量大 |

## 六、选购流程

1. 先列家庭成员和使用需求。
2. 测量房间、门洞、电梯、楼道。
3. 在户型图或地面模拟大件家具尺寸。
4. 核对插座、开关、空调、柜门和门扇。
5. 确定大件家具尺寸上限。
6. 对比材质、环保、售后和交期。
7. 下单前确认运输、安装、退换货规则。
8. 到货后验收外观、尺寸、结构和配件。

## 七、关键标准

| 标准 | 说明 |
|---|---|
| 能搬入 | 电梯楼道门洞满足 |
| 放得下 | 家具外径适配现场 |
| 走得通 | 人体动线不拥挤 |
| 用得顺 | 开门、抽屉、插座不冲突 |
| 坐躺舒服 | 符合家庭成员身高习惯 |
| 环保可靠 | 材料证明和气味可控 |
| 售后清楚 | 质保、退换、维修明确 |

## 八、验收标准

| 检查项 | 合格表现 |
|---|---|
| 尺寸 | 与订单一致，现场摆放合适 |
| 外观 | 无明显划伤、磕碰、色差异常 |
| 结构 | 不晃动、不异响 |
| 五金 | 开合顺畅 |
| 材质 | 与样品或约定一致 |
| 气味 | 无强烈刺激性气味 |
| 配件 | 螺丝、脚垫、说明书齐全 |
| 安装 | 不破坏墙地面 |

## 九、常见问题

### 1. 网上买家具靠谱吗？

可以，但必须确认尺寸、材质、评价、安装方式、退换规则和运费。大件家具尤其要确认是否送货入户、是否包安装、退货是否承担物流费。

### 2. 家具尺寸怎么避免买大？

用纸胶带在地面贴出家具外径，模拟走路、开门、拉抽屉和坐下起身，比只看网页尺寸更可靠。

### 3. 成品家具和定制家具怎么选？

定制适合严丝合缝和收纳最大化，成品适合灵活、更换和风格变化。预算有限时，可以定制解决收纳，成品解决沙发、床、餐桌等舒适类家具。

## 十、避坑提醒

1. 床垫尺寸不等于床外径。
2. 沙发不要只看长度，还要看坐深和靠背。
3. 餐桌要算椅子拉出空间。
4. 家具下单前确认能否进电梯和门洞。
5. 电视柜、床头柜、书桌不要挡插座。
6. 高柜、书柜、斗柜要防倾倒。
7. 玻璃、尖角家具不适合儿童活动区。
8. 大件家具到货先验收再安装。

## 十一、案例分析

### 案例 1：床买大导致衣柜打不开

业主只按床垫 1.8 米规划，实际软包床外径接近 2 米，放入卧室后衣柜抽屉无法完全拉出。

经验：购买床要看外径，不是只看床垫尺寸。

### 案例 2：餐桌堵住动线

餐桌长度合适，但餐椅拉出后过道只剩很窄，端菜和通行都不方便。

经验：餐厅规划要把椅子拉出状态纳入尺寸。

## 十二、法规依据

家具选购涉及产品质量、家具环保、儿童家具安全、消费者权益保护、售后服务和电商交易规则等。具体以订单、合同、产品说明、检测报告和平台规则为准。

## 十三、用户咨询与AI回复模板

用户问：买家具怎么避免尺寸翻车？

AI 回复：先量四类尺寸：房间尺寸、门洞电梯尺寸、插座开关位置、柜门和房门开合范围。下单前用纸胶带在地面贴出家具外径，模拟走路、开门、坐下、拉抽屉。特别注意床要看外径，餐桌要算椅子拉出空间，沙发不要挡插座。
