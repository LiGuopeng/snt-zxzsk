# 拆改验收标准

## 一、概述

拆改验收是拆改工程结束后、水电工程开始前的重要节点。拆改验收不是简单看“墙拆完没有”，而是要核对拆改范围、结构安全、墙体新建、门洞尺寸、基层修补、垃圾清运、成品保护、管线状态和现场是否具备后续施工条件。

如果拆改没有验收就直接进入水电阶段，后期可能出现墙体位置不准、水电点位偏差、门洞尺寸错误、基层空鼓、垃圾堵塞下水、误拆漏拆责任不清等问题。

拆改验收的目标是：

1. 确认拆改结果与图纸一致。
2. 确认没有破坏结构和管线。
3. 确认新建墙、门洞和基层具备后续施工条件。
4. 确认垃圾和现场安全问题已处理。
5. 为水电进场建立清晰边界。

## 二、适用范围

本文适用于以下场景：

1. 拆改工程完成后准备验收的用户。
2. 准备进入水电阶段的装修项目。
3. 二手房拆除、局部改造、新建墙体后的验收。
4. 装修公司项目经理进行节点验收时使用。
5. 后续 AI 客服回答“拆改验收看什么”等问题时使用。

本文主要面向住宅装修拆改验收。涉及结构安全、燃气、消防、外立面等问题时，应结合物业和专业人员意见。

## 三、基础知识

### 1. 拆改验收是什么

拆改验收是对拆除、新建、修补、清运和现场安全结果进行检查确认的过程。它是进入水电工程前的前置验收。

### 2. 拆改验收为什么重要

拆改验收能提前发现：

1. 拆错或漏拆。
2. 新建墙位置偏差。
3. 门洞尺寸不准。
4. 墙地面基层未处理。
5. 下水口被堵。
6. 公共区域损坏。
7. 垃圾未清理。
8. 管线被误伤。

## 四、专业知识

### 1. 拆除项目验收明细

| 检查项 | 合格标准 | 风险表现 |
|---|---|---|
| 拆除范围 | 与拆改图一致 | 误拆、漏拆 |
| 墙体边界 | 拆除边缘整齐 | 破坏相邻墙体 |
| 保留结构 | 未破坏梁柱承重 | 安全风险 |
| 成品保留 | 需要保留的门窗设备完好 | 后期赔偿 |
| 管线保护 | 无误伤水电燃气 | 渗漏、短路 |

### 2. 新建墙验收明细

| 检查项 | 合格标准 | 风险表现 |
|---|---|---|
| 位置 | 与图纸一致 | 空间尺寸偏差 |
| 垂直度 | 墙面基本垂直 | 门柜安装困难 |
| 平整度 | 基层平整 | 后续墙面问题 |
| 新旧连接 | 拉结和挂网处理 | 交接开裂 |
| 门洞 | 尺寸和方正度合格 | 木门安装困难 |
| 挂重加强 | 需要挂重处已加强 | 固定不牢 |

### 3. 基层验收明细

| 检查项 | 合格标准 | 风险表现 |
|---|---|---|
| 墙面空鼓 | 大面积空鼓已处理 | 后期开裂脱落 |
| 地面破损 | 拆除区域已修补 | 找平困难 |
| 顶面缺口 | 拆墙后收口处理 | 吊顶油工问题 |
| 开槽处 | 临时破损已确认 | 后续水电冲突 |
| 粉尘垃圾 | 基层清理干净 | 影响粘结 |

### 4. 厨卫阳台验收明细

| 检查项 | 合格标准 | 风险表现 |
|---|---|---|
| 下水口 | 已封堵保护或清理 | 建筑垃圾堵塞 |
| 排水 | 初步排水通畅 | 后期堵塞 |
| 防水层 | 破坏范围明确 | 漏水风险 |
| 管道 | 未破坏主管 | 渗漏和邻里纠纷 |
| 烟道 | 未破坏 | 排烟问题 |
| 燃气 | 未私自改动 | 安全风险 |

### 5. 垃圾清运验收明细

| 检查项 | 合格标准 |
|---|---|
| 室内垃圾 | 已装袋或清理 |
| 公共区域 | 无垃圾堆放 |
| 电梯走廊 | 无明显污染和损坏 |
| 下水口 | 无碎渣和堵塞 |
| 清运费用 | 与合同或物业约定一致 |

### 6. 水电进场条件

拆改验收后，应确认现场是否具备水电进场条件：

1. 墙体位置确定。
2. 门洞和空间尺寸确定。
3. 垃圾清理完成。
4. 需要修补的位置已处理。
5. 水电点位图可根据现场复核。
6. 地面和墙面具备开槽条件。
7. 厨卫管线和下水状态清楚。

## 六、验收流程

### 1. 对照拆改图

逐项核对拆除、新建、封堵和保留位置。

### 2. 检查结构安全

确认承重墙、梁柱、烟道、燃气、外立面和公共管井未被破坏。

### 3. 检查新建墙和门洞

核对位置、尺寸、垂直度、门洞和新旧墙交接处理。

### 4. 检查基层和修补

检查墙地顶面破损、空鼓、裂缝、缺口和粉尘。

### 5. 检查厨卫阳台

重点检查下水、地漏、管道、防水破坏范围和垃圾堵塞。

### 6. 检查垃圾和保护

确认垃圾清理、公共区域保护、入户门和电梯状态。

### 7. 形成验收记录

拍照留档，问题形成整改清单，整改后再进入水电。

## 七、关键标准

### 1. 合格拆改验收标准

1. 拆改范围与图纸一致。
2. 结构和管线无破坏。
3. 新建墙位置和质量合格。
4. 门洞尺寸基本准确。
5. 基层问题已处理或记录。
6. 垃圾清运完成。
7. 下水口无堵塞风险。
8. 现场具备水电进场条件。

### 2. 不建议进入水电的情况

1. 拆改范围未完成。
2. 新建墙位置未确认。
3. 门洞尺寸有明显问题。
4. 垃圾未清理。
5. 下水可能堵塞。
6. 管线被破坏未处理。
7. 结构安全存在疑问。
8. 需要修补的基层未处理。

## 八、验收标准

拆改验收总表：

| 类别 | 合格标准 | 处理建议 |
|---|---|---|
| 拆除 | 与图纸一致 | 误拆漏拆立即整改 |
| 新建 | 位置、垂直、平整合格 | 偏差大需返工 |
| 结构 | 无破坏 | 有疑问先停工确认 |
| 管线 | 无损坏 | 先修复再水电 |
| 厨卫 | 下水防水状态清楚 | 堵塞或渗漏先处理 |
| 基层 | 松动破损已处理 | 补齐后再施工 |
| 垃圾 | 清理规范 | 清理后再进场 |
| 记录 | 照片和验收单完整 | 保留证据 |

## 九、常见问题

### 1. 拆改验收需要业主到场吗？

建议到场。拆改决定后续水电和空间尺寸，业主现场确认可以避免后期责任不清。

### 2. 拆改验收后才能做水电吗？

建议是。拆改未确认就做水电，可能导致点位偏差、线路返工和责任混乱。

### 3. 拆改验收主要看什么？

看拆改范围、结构安全、新建墙、门洞、基层修补、垃圾清运、管线保护和现场是否具备水电条件。

### 4. 拆完发现墙面问题怎么办？

应先记录并判断是否需要修补、找平、挂网或基层处理，再进入后续施工。

## 十、避坑提醒

1. 不要拆改未验收就做水电。
2. 不要只看墙拆没拆完。
3. 不要忽略下水口和垃圾。
4. 不要新建墙不验收。
5. 不要门洞尺寸后期再看。
6. 不要结构疑问继续施工。
7. 不要问题只口头说。

## 十一、案例分析

### 案例一：拆改未验收，水电点位返工

用户 A 拆改后没有验收，水电工直接进场。后期发现新建墙位置偏差，插座和开关位置不合理，需要重新调整。

问题分析：

1. 拆改后未复核墙体位置。
2. 水电图没有基于实际现场更新。
3. 节点验收缺失。

正确做法：

1. 拆改后先验收。
2. 根据实际现场复核水电点位。
3. 确认后再开槽布线。

### 案例二：地漏被建筑垃圾堵塞

用户 B 卫生间拆除后没有检查地漏和下水，后期施工时发现排水变慢。

问题分析：

1. 拆改前未封堵下水。
2. 拆改后未检查排水。
3. 垃圾清理不彻底。

正确做法：

1. 拆改前保护下水口。
2. 拆改后检查清理。
3. 进入防水前确认排水正常。

## 十二、法规依据

拆改验收涉及合同履行、住宅装修管理、结构安全和施工质量。通常可参考：

1. 《住宅室内装饰装修管理办法》中关于住宅装修禁止行为和管理要求的规定。
2. 装修合同、拆改图、报价单、开工交底记录和节点验收记录。
3. 物业装修管理协议和小区施工管理规定。

具体质量责任应结合合同约定、施工记录和现场照片判断。
