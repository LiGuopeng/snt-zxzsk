# 拆改工程基础知识

## 一、概述

拆改工程是装修正式施工后的重要前置阶段，通常发生在开工交底和成品保护之后、水电改造之前。拆改工程包括墙体拆除、墙体新建、门洞调整、铲墙皮、拆除旧装修、拆除柜体和地面、修补基层、垃圾清运等内容。

拆改工程看起来只是“拆掉旧的、改成新的”，但它直接关系到房屋结构安全、后续水电施工、空间布局、预算增项、物业管理和邻里关系。尤其是承重墙、梁柱、烟道、燃气管道、外立面、公共管井等位置，不能随意拆改。

拆改工程的目标是：

1. 按设计方案清理和调整原有结构或装修。
2. 为水电、防水、瓦工、木工等后续施工创造条件。
3. 保证拆改过程安全、合规、可追溯。
4. 减少因误拆、漏拆、乱改导致的返工和纠纷。

## 二、适用范围

本文适用于以下场景：

1. 新房装修中涉及局部墙体调整的用户。
2. 二手房翻新中需要拆除旧装修的用户。
3. 精装房改造中需要拆除局部成品或墙面的用户。
4. 准备进行开工交底和拆改验收的用户。
5. 装修公司项目经理、设计师、客服进行拆改说明时使用。
6. 后续 AI 客服回答“拆改能不能做、拆改注意什么”等问题时使用。

本文主要面向住宅装修。涉及结构安全、燃气、消防、外立面和公共设施的改造，应以当地规定、物业要求、原始结构图和专业意见为准。

## 三、基础知识

### 1. 拆改工程包括什么

常见拆改工程包括：

| 类型 | 常见内容 |
|---|---|
| 墙体拆除 | 拆除非承重隔墙、局部轻体墙 |
| 墙体新建 | 新砌隔墙、封门洞、改空间分隔 |
| 门洞调整 | 扩门洞、移门洞、封门洞 |
| 铲墙皮 | 铲除原墙面涂层、腻子或基层 |
| 地面拆除 | 拆除旧地砖、地板、找平层 |
| 顶面拆除 | 拆除旧吊顶、灯具、基层 |
| 厨卫拆除 | 拆除旧橱柜、洁具、墙地砖 |
| 成品拆除 | 拆除柜体、木门、五金、窗帘盒 |
| 基层修补 | 拆除后的墙地面修补 |
| 垃圾清运 | 建筑垃圾袋装、搬运、清运 |

### 2. 哪些位置不能随意拆改

| 位置 | 风险 |
|---|---|
| 承重墙 | 影响结构安全 |
| 梁柱 | 承担结构荷载，不能随意破坏 |
| 剪力墙 | 高层住宅结构核心部位 |
| 烟道 | 影响排烟和邻里使用 |
| 燃气管道 | 涉及安全，不能私改 |
| 公共管井 | 涉及检修和公共设施 |
| 外立面 | 影响小区统一和安全 |
| 消防设施 | 涉及公共安全 |
| 下水主管 | 影响排水和邻里 |

### 3. 拆改为什么要在水电前完成

拆改完成后，空间结构、墙体位置、门洞位置和基层状态才基本确定。水电点位、线路走向和管道位置需要基于拆改后的实际空间进行规划。

如果先做水电再拆改，可能出现：

1. 线路被拆改破坏。
2. 点位位置不准确。
3. 墙体变化导致返工。
4. 水电图和现场不一致。

## 四、专业知识

### 1. 拆改前确认明细

| 确认项 | 应确认内容 | 风险 |
|---|---|---|
| 原始结构 | 承重墙、梁柱、剪力墙位置 | 误拆结构 |
| 物业规定 | 是否允许拆改、施工时间 | 被停工或扣押金 |
| 设计图纸 | 拆哪里、砌哪里、保留哪里 | 现场理解偏差 |
| 报价范围 | 拆除、修补、清运是否包含 | 后期增项 |
| 成品保护 | 入户门、电梯、公共区域 | 损坏赔偿 |
| 水电燃气 | 管线位置和安全处理 | 破坏管线 |
| 邻里影响 | 噪音、震动、垃圾清运 | 投诉停工 |

### 2. 拆改项目报价明细

| 项目 | 计价方式 | 容易漏项 |
|---|---|---|
| 拆墙 | 按平方米或项 | 修补、清运 |
| 砌墙 | 按平方米 | 抹灰、挂网、植筋 |
| 铲墙皮 | 按平方米 | 基层修补 |
| 拆地砖 | 按平方米 | 找平层拆除、清运 |
| 拆吊顶 | 按平方米或项 | 灯具线路保护 |
| 拆橱柜 | 按项或米 | 水电封堵 |
| 拆洁具 | 按件 | 下水保护 |
| 门洞修补 | 按项 | 过梁、找方 |
| 垃圾清运 | 按车、袋、面积或项 | 上楼下楼、物业清运费 |

拆改报价必须问清是否包含垃圾装袋、搬运、清运、墙地面修补、门洞修补和公共区域保护。

### 3. 拆改施工流程明细

| 步骤 | 内容 | 重点 |
|---|---|---|
| 开工交底 | 现场确认拆改范围 | 拆改图和现场一致 |
| 成品保护 | 保护门窗、电梯、地面 | 先保护后拆 |
| 管线确认 | 确认水电燃气位置 | 避免破坏管线 |
| 标记拆改 | 在现场标出拆除和保留位置 | 防止误拆 |
| 拆除施工 | 按顺序拆除墙体或成品 | 安全和噪音控制 |
| 垃圾装袋 | 分类堆放和及时清运 | 避免堵塞和投诉 |
| 基层清理 | 清理松动、空鼓、破损区域 | 为后续施工准备 |
| 修补处理 | 门洞、墙地面、管口修补 | 防止后续返工 |
| 拆改验收 | 核对图纸和现场 | 验收后再水电 |

### 4. 拆改现场安全明细

| 风险 | 防控方法 |
|---|---|
| 误拆承重结构 | 开工前确认结构图和物业要求 |
| 破坏水电管线 | 拆前确认管线位置 |
| 高空坠物 | 拆除门窗、吊顶时做好防护 |
| 粉尘污染 | 封闭门窗、湿法作业、及时清理 |
| 噪音扰民 | 按物业规定时间施工 |
| 垃圾堵塞下水 | 地漏和下水口封堵保护 |
| 公共区域损坏 | 电梯、走廊、入户门保护 |

### 5. 拆改与后续工程衔接

| 后续工程 | 拆改影响 |
|---|---|
| 水电 | 墙体和点位确定后才能布线 |
| 防水 | 厨卫拆除后需重新处理基层 |
| 瓦工 | 地面和墙面基层影响找平和铺贴 |
| 木工 | 梁位、墙体、门洞影响吊顶和柜体 |
| 油工 | 铲墙和基层处理影响墙面质量 |
| 安装 | 门洞、墙体垂直度影响木门和柜体 |

## 六、施工或服务流程

### 1. 拆改前确认图纸

业主、设计师、项目经理、施工负责人应现场确认拆改图，明确拆除、新建、保留和禁止施工区域。

### 2. 办理物业手续

确认物业是否允许拆改、是否需要提交图纸、施工时间和垃圾清运方式。

### 3. 做成品保护

入户门、电梯、走廊、地面、窗户、下水口等位置先保护，再施工。

### 4. 现场标记拆改位置

用记号或胶带标出拆除墙体、新建墙体、门洞位置和保留位置。

### 5. 拆除旧结构或旧装修

按顺序拆除，避免暴力施工破坏保留结构和管线。

### 6. 清理和清运垃圾

建筑垃圾应按物业要求装袋、堆放和清运，不能堵塞下水和公共通道。

### 7. 基层修补

拆除后墙地面破损、门洞边缘、管道周边需要修补，为后续施工创造条件。

### 8. 拆改验收

拆改完成后核对图纸、现场尺寸、墙体位置、垃圾清理、修补质量和安全隐患。

## 七、关键标准

### 1. 合格拆改标准

1. 拆改范围与图纸一致。
2. 未破坏承重结构和公共设施。
3. 管线未被误伤。
4. 成品和公共区域保护到位。
5. 垃圾清理干净。
6. 需要修补的位置已处理。
7. 现场具备水电进场条件。
8. 拆改过程有照片记录。

### 2. 高风险拆改表现

1. 没有拆改图就施工。
2. 现场口头说拆哪里。
3. 不确认承重墙。
4. 不办理物业手续。
5. 下水口不保护。
6. 垃圾乱堆乱倒。
7. 拆完不修补。
8. 未验收直接做水电。

## 八、验收标准

拆改完成后检查清单：

| 检查项 | 合格标准 | 风险表现 |
|---|---|---|
| 拆除范围 | 与图纸一致 | 误拆或漏拆 |
| 新建位置 | 放线准确 | 后续尺寸偏差 |
| 结构安全 | 未动承重、梁柱、烟道 | 安全隐患 |
| 管线保护 | 水电燃气未破坏 | 后期维修 |
| 门洞 | 尺寸和垂直度基本合格 | 木门安装困难 |
| 墙地面 | 松动基层清理 | 后续空鼓开裂 |
| 垃圾 | 已清运或规范堆放 | 影响施工和物业 |
| 保护 | 公共区域无损坏 | 押金扣除 |

## 九、常见问题

### 1. 拆改工程是不是越早做越好？

拆改通常在开工交底和成品保护后进行，但不能在图纸、物业手续、结构确认不清楚时仓促施工。

### 2. 非承重墙一定可以拆吗？

不一定。非承重墙也可能涉及管线、烟道、外立面、物业限制或相邻空间影响。拆前仍需确认图纸和物业要求。

### 3. 拆改费用为什么容易增项？

常见原因是报价只写拆除，没有包含修补、垃圾清运、门洞处理、基层处理和公共区域保护。

### 4. 拆改后可以直接做水电吗？

应先验收。确认拆改范围、墙体位置、垃圾清理、基层修补和现场安全后，再进入水电阶段。

### 5. 二手房拆改要特别注意什么？

二手房要注意旧水电、旧防水、墙面基层、下水管道、原有拆改是否合规，以及拆除后暴露出的隐藏问题。

## 十、避坑提醒

1. 不要没有拆改图就开工。
2. 不要听工人现场判断承重墙。
3. 不要私自拆梁柱、承重墙、烟道和燃气管道。
4. 不要忽略物业手续。
5. 不要报价只看拆除费，不看修补和清运。
6. 不要下水口不保护。
7. 不要拆改后不验收。
8. 不要拆完直接进入水电。
9. 不要不拍照留档。
10. 不要忽略邻里和噪音投诉风险。

## 十一、案例分析

### 案例一：拆改报价低，后期修补和清运加钱

用户 A 签约时拆改报价很低，只写了“墙体拆除”。施工后装修公司提出垃圾清运、门洞修补、墙面修补另收费，用户认为不合理。

问题分析：

1. 报价只写拆除，没有写清运和修补。
2. 拆改项目边界不清。
3. 签约前没有审核报价明细。

正确做法：

1. 拆改报价写清拆除、修补、清运和保护。
2. 不包含项目提前列出。
3. 拆改变更书面确认。

### 案例二：未确认墙体性质导致停工

用户 B 想扩大客厅空间，现场标记拆除一段墙。物业巡查时认为该位置可能涉及结构安全，要求停工并提交资料。

问题分析：

1. 拆改前未确认原始结构图。
2. 物业手续和图纸报备不足。
3. 现场凭经验判断墙体。

正确做法：

1. 拆改前确认结构和物业要求。
2. 重要墙体不凭肉眼判断。
3. 涉及结构安全时咨询专业人员。

## 十二、法规依据

拆改工程涉及住宅结构安全、物业管理、合同履行和相邻关系。通常可参考：

1. 《住宅室内装饰装修管理办法》中关于住宅装修禁止行为、装修申报和管理要求的规定。
2. 《中华人民共和国民法典》中关于相邻关系、合同履行、侵权责任等规定。
3. 小区物业装修管理协议、业主规约和装修施工规定。
4. 双方确认的装修合同、拆改图、报价单、开工交底记录和验收记录。

涉及承重结构、燃气、外立面、消防等事项，应以当地规定和专业意见为准。
