# 量房注意事项

## 一、概述

量房是装修设计、报价和施工的基础动作。准确量房可以帮助设计师判断户型结构、空间尺寸、梁柱位置、门窗尺寸、水电燃气位置、排水条件和现场问题；量房不准确，则可能导致设计方案落不了地、报价工程量不准、柜体尺寸错误、主材数量偏差和后期返工。

很多用户把量房理解成“测一下房间长宽”，但专业量房远不止测面积。它应同时记录结构、尺寸、设备、管线、采光、通风、排水、墙体、门窗和现场问题。

量房的目标是：

1. 获取准确尺寸。
2. 识别房屋限制。
3. 为设计方案提供依据。
4. 为报价工程量提供依据。
5. 为后续施工减少返工。

## 二、适用范围

本文适用于以下场景：

1. 准备找装修公司或设计师上门量房的用户。
2. 第一次装修，不知道量房要注意什么的用户。
3. 担心量房不准影响报价和施工的用户。
4. 准备做全屋定制、橱柜、木门、窗帘等复尺的用户。
5. 装修公司客服、设计师进行量房前提醒时使用。

本文主要面向住宅装修，包括新房、二手房、局部改造和精装房改造。

## 三、基础知识

### 1. 量房是什么

量房是对房屋现场尺寸、结构和条件进行测量与记录的工作。它通常包括：

1. 房间长宽高。
2. 墙体厚度。
3. 门窗洞口尺寸。
4. 梁柱位置和尺寸。
5. 下水、地漏、烟道、燃气位置。
6. 强弱电箱位置。
7. 原始开关插座位置。
8. 层高和吊顶限制。
9. 墙面、地面、顶面问题。
10. 采光、通风和噪音情况。

### 2. 初次量房和复尺的区别

| 类型 | 目的 | 时间 |
|---|---|---|
| 初次量房 | 为设计方案、预算和报价提供基础数据 | 装修准备阶段 |
| 施工复核 | 开工前确认尺寸和现场变化 | 开工交底前 |
| 定制复尺 | 为橱柜、衣柜、木门等下单生产 | 墙地面基层完成后 |
| 安装复尺 | 为窗帘、台面、玻璃等安装确认尺寸 | 安装前 |

初次量房不能替代后期复尺。尤其是定制柜、木门、橱柜等产品，必须按施工完成后的实际尺寸复尺。

## 四、专业知识

### 1. 量房前准备明细

| 准备事项 | 说明 |
|---|---|
| 准备户型图 | 有开发商户型图更方便核对 |
| 明确装修需求 | 提前想好居住人数、功能需求 |
| 带房屋资料 | 收房资料、物业装修手册、原始图纸 |
| 确认物业要求 | 承重墙、燃气、外立面、空调位限制 |
| 准备拍照 | 记录现场和问题 |
| 预留时间 | 不要催促设计师快速量完 |

### 2. 空间尺寸测量明细

| 测量项 | 应记录内容 | 作用 |
|---|---|---|
| 房间长宽 | 墙到墙实际尺寸 | 平面布局和面积计算 |
| 层高 | 地面到顶面高度 | 吊顶、中央空调、新风判断 |
| 墙体厚度 | 承重和非承重墙判断参考 | 拆改和门洞判断 |
| 门洞尺寸 | 宽、高、墙厚 | 木门和门套定制 |
| 窗户尺寸 | 宽、高、离地高度 | 窗帘、窗台、家具摆放 |
| 梁位尺寸 | 梁高、梁宽、位置 | 吊顶和柜体设计 |
| 柱体尺寸 | 宽度、深度、位置 | 空间利用和收口 |
| 管道位置 | 下水、燃气、烟道、管井 | 厨卫布局和改造限制 |

### 3. 厨房量房明细

| 项目 | 重点 |
|---|---|
| 烟道位置 | 决定烟机和橱柜布局 |
| 燃气管位置 | 不能随意改动，影响灶具位置 |
| 上下水位置 | 影响水槽、洗碗机、净水器 |
| 窗户位置 | 影响吊柜和台面 |
| 冰箱位置 | 影响插座、散热和动线 |
| 地漏 | 判断是否有排水条件 |
| 墙体垂直度 | 影响橱柜安装和收口 |

### 4. 卫生间量房明细

| 项目 | 重点 |
|---|---|
| 马桶坑距 | 决定马桶型号 |
| 下水位置 | 决定浴室柜、淋浴、洗衣机布局 |
| 地漏位置 | 影响坡度和排水 |
| 管道井 | 影响包管和空间利用 |
| 窗户 | 影响淋浴区、镜柜和通风 |
| 门洞 | 影响开门方向和干湿分离 |
| 层高 | 影响吊顶和浴霸安装 |

### 5. 水电设备记录明细

| 项目 | 应记录 |
|---|---|
| 强电箱 | 位置、容量、回路情况 |
| 弱电箱 | 位置、网线、光纤入户 |
| 原插座 | 数量、位置、高度 |
| 原开关 | 控制关系和位置 |
| 空调孔 | 数量、位置、高度 |
| 水表 | 位置和检修空间 |
| 燃气表 | 位置和安全距离 |
| 地漏 | 位置、数量、排水状态 |

### 6. 现场问题记录明细

| 问题 | 影响 |
|---|---|
| 墙面空鼓 | 影响后续基层处理和报价 |
| 墙面裂缝 | 需要判断结构或基层问题 |
| 渗水痕迹 | 影响防水和维修 |
| 地面不平 | 影响找平和地板安装 |
| 门窗损坏 | 需要区分原房责任 |
| 下水不畅 | 影响厨卫布局 |
| 层高偏低 | 影响吊顶和设备安装 |
| 采光不足 | 影响设计和照明规划 |

## 六、量房流程

### 1. 先看整体户型

确认入户、客厅、餐厅、卧室、厨房、卫生间、阳台的位置关系和动线。

### 2. 逐个空间测量

按空间顺序测量长、宽、高、门窗、梁柱、管道和特殊位置。

### 3. 记录设备和管线

重点记录强弱电箱、水表、燃气表、烟道、地漏、下水、空调孔等。

### 4. 拍照留档

每个空间拍全景，重点位置拍特写，例如梁柱、管道、墙面问题、门窗、强弱电箱。

### 5. 现场沟通需求

业主应现场说明生活需求，例如是否要洗碗机、烘干机、投影、扫地机器人、办公区、儿童房、老人房。

### 6. 回去整理图纸和记录

量房后应整理为原始平面图，并标注尺寸、梁柱、门窗、设备和管线。

## 七、关键标准

### 1. 合格量房标准

1. 尺寸完整。
2. 梁柱管道记录清楚。
3. 厨卫水电燃气位置清楚。
4. 门窗洞口尺寸清楚。
5. 层高和吊顶限制清楚。
6. 原房问题有照片。
7. 用户需求有记录。
8. 能形成可用原始平面图。

### 2. 高风险量房表现

1. 只测房间长宽。
2. 不记录梁柱和管道。
3. 厨卫设备位置不清。
4. 不拍照。
5. 不问用户需求。
6. 量房后没有图纸。
7. 直接用开发商户型图报价。

## 八、验收标准

量房结果检查清单：

| 检查项 | 合格标准 | 风险表现 |
|---|---|---|
| 尺寸 | 每个空间长宽高完整 | 面积估算 |
| 门窗 | 尺寸和位置清楚 | 后期安装冲突 |
| 梁柱 | 位置和尺寸记录 | 吊顶柜体冲突 |
| 厨卫 | 水电燃气下水清楚 | 方案落不了地 |
| 设备 | 强弱电、空调孔、地漏记录 | 水电点位遗漏 |
| 问题 | 空鼓、裂缝、渗水记录 | 责任不清 |
| 照片 | 全景和重点特写 | 后期无法复核 |
| 需求 | 用户需求同步记录 | 设计偏离生活 |

## 九、常见问题

### 1. 有开发商户型图还需要量房吗？

需要。开发商户型图通常是示意图，可能与现场实际尺寸、梁柱、管道、墙体厚度存在差异。装修设计和报价应以现场量房为准。

### 2. 量房一次就够了吗？

不够。初次量房用于设计和预算，定制柜、木门、橱柜、窗帘等还需要在对应施工阶段复尺。

### 3. 量房时业主需要在场吗？

建议在场。业主可以现场说明生活需求、家电计划、收纳需求和特殊习惯，避免设计师只按空间尺寸做方案。

### 4. 量房会影响报价吗？

会。墙面面积、地面面积、水电点位、拆改范围、门窗尺寸、厨卫条件都会影响报价。

### 5. 量房时需要确定家电吗？

至少要确定关键家电计划，例如冰箱、洗碗机、烘干机、热水器、空调、投影、扫地机器人等，因为它们会影响水电点位和尺寸预留。

## 十、避坑提醒

1. 不要只用户型图报价。
2. 不要只测长宽，不记录梁柱管道。
3. 不要忽略厨卫下水和燃气位置。
4. 不要量房时不说生活需求。
5. 不要认为初次量房能替代定制复尺。
6. 不要不拍照。
7. 不要忽略墙面空鼓、裂缝、渗水。
8. 不要在尺寸不准时直接下单定制。

## 十一、案例分析

### 案例一：没有记录梁位，吊顶方案返工

用户 A 量房时只记录了房间尺寸，没有详细记录梁位。设计吊顶后现场发现梁高影响造型，原方案无法施工，只能重新调整。

问题分析：

1. 梁位记录不完整。
2. 设计方案没有结合现场结构。
3. 开工前未复核图纸。

正确做法：

1. 量房时记录梁高、梁宽和位置。
2. 吊顶方案结合层高和梁位。
3. 开工交底时再次复核。

### 案例二：马桶坑距未测，洁具买错

用户 B 选购马桶时只看款式，没有核对坑距。安装时发现坑距不匹配，需要更换型号。

问题分析：

1. 卫生间量房不细。
2. 主材选购前没有核对尺寸。
3. 洁具和施工没有衔接。

正确做法：

1. 量房记录马桶坑距。
2. 选购洁具前核对尺寸。
3. 安装前再次确认。

## 十二、法规依据

量房本身不是独立法律程序，但量房结果会影响合同、报价、施工图和后续责任判断。相关依据包括：

1. 装修合同、报价单、施工图和设计确认文件。
2. 《住宅室内装饰装修管理办法》中关于住宅装修活动和禁止行为的规定。
3. 物业装修管理协议和小区装修要求。

涉及结构拆改、燃气管道、外立面等事项时，应遵守物业和相关管理部门规定。
