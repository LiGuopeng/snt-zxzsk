# 主材选购计划

## 一、概述

主材选购计划是装修预算控制和工期管理的重要工具。主材包括瓷砖、地板、木门、洁具、橱柜、灯具、开关插座、吊顶、五金等直接影响装修效果和使用体验的材料。主材如果选得太晚，容易影响施工进度；如果选得太急，又容易买错尺寸、风格或型号。

很多用户主材超预算、工期延误或安装冲突，往往不是因为某一件材料本身有问题，而是没有提前做采购计划。例如瓦工进场前瓷砖没到，水电施工前洁具和家电尺寸没定，木门复尺太晚，全屋定制生产周期被低估。

主材选购计划的目标是：

1. 明确需要买什么。
2. 明确什么时候买。
3. 明确谁负责购买和安装。
4. 明确预算和型号。
5. 避免材料延误影响施工。

## 二、适用范围

本文适用于以下场景：

1. 准备装修，想提前规划主材采购的用户。
2. 选择半包，需要自己购买主材的用户。
3. 选择全包或整装，需要审核套餐主材的用户。
4. 担心主材超预算、买错或到货延误的用户。
5. 装修公司客服、设计师、项目经理进行主材提醒时使用。

本文主要面向住宅装修，包括新房、二手房翻新、精装房改造和局部改造。

## 三、基础知识

### 1. 主材是什么

主材通常是装修中最终可见、影响使用和效果的材料，与辅材相对。辅材多用于施工基层和隐蔽工程，例如水泥、电线、水管、腻子、防水等。

常见主材包括：

| 类别 | 常见材料 |
|---|---|
| 地面 | 瓷砖、地板、过门石 |
| 墙面 | 墙砖、乳胶漆、墙布、护墙板 |
| 门窗 | 木门、推拉门、门套、窗套 |
| 厨房 | 橱柜、台面、水槽、龙头 |
| 卫浴 | 马桶、花洒、浴室柜、地漏、五金 |
| 电气 | 开关插座、灯具、浴霸 |
| 顶面 | 集成吊顶、扣板 |
| 定制 | 衣柜、玄关柜、阳台柜 |

### 2. 半包、全包中的主材责任

| 模式 | 主材责任 |
|---|---|
| 半包 | 通常由业主自购主材 |
| 全包 | 装修公司负责部分或多数主材 |
| 整装 | 主材可能包含在套餐中 |
| 清包 | 多数材料由业主购买 |

无论哪种模式，都应明确主材品牌、型号、规格、数量、安装责任和售后责任。

## 四、专业知识

### 1. 主材采购时间表

| 主材 | 建议确认时间 | 影响节点 |
|---|---|---|
| 瓷砖 | 瓦工进场前确认并到货 | 影响铺贴 |
| 地板 | 油工后期确认，安装前到货 | 影响竣工安装 |
| 木门 | 瓦工完成后复尺，提前下单 | 生产周期长 |
| 橱柜 | 水电前确认方案，瓦工后复尺 | 影响厨房水电和安装 |
| 洁具 | 水电前确认尺寸和位置 | 影响给排水点位 |
| 浴室柜 | 水电前确认宽度和排水 | 影响水口和插座 |
| 开关插座 | 水电点位确定后统计 | 影响安装 |
| 灯具 | 油工后期确认 | 影响安装排期 |
| 集成吊顶 | 瓦工后确认 | 影响厨卫安装 |
| 全屋定制 | 设计阶段规划，墙地完成后复尺 | 生产周期长 |
| 窗帘 | 油工完成后复尺 | 影响入住 |

### 2. 主材预算明细

| 主材 | 预算关注点 | 隐藏费用 |
|---|---|---|
| 瓷砖 | 单价、规格、损耗、铺贴方式 | 加工费、上楼费、退补货 |
| 地板 | 材质、厚度、环保等级 | 踢脚线、扣条、防潮垫 |
| 木门 | 门扇、门套、锁具、合页 | 门套加宽、五金升级 |
| 橱柜 | 地柜、吊柜、台面、五金 | 拉篮、见光板、灯带 |
| 洁具 | 马桶、花洒、浴室柜 | 角阀、软管、安装辅材 |
| 灯具 | 主灯、筒灯、射灯、灯带 | 驱动、电源、安装 |
| 开关插座 | 品牌、系列、数量 | 特殊面板、智能开关 |
| 定制柜 | 板材、五金、计价方式 | 抽屉、拉直器、特殊门板 |

### 3. 主材选购顺序

建议按“影响水电和施工的先买，纯装饰类后买”的原则安排。

优先确认：

1. 橱柜方案。
2. 洁具尺寸。
3. 家电尺寸。
4. 瓷砖。
5. 木门和定制。

可以后期确认：

1. 部分灯具。
2. 窗帘。
3. 部分软装。
4. 装饰画和摆件。

### 4. 主材型号审核明细

| 材料 | 必须确认 |
|---|---|
| 瓷砖 | 品牌、型号、规格、批次、颜色、数量 |
| 地板 | 品牌、型号、厚度、环保等级、辅料 |
| 木门 | 材质、颜色、门套、锁具、合页 |
| 马桶 | 坑距、排水方式、尺寸 |
| 花洒 | 安装方式、冷热水间距 |
| 浴室柜 | 尺寸、排水方式、镜柜电源 |
| 橱柜 | 板材、台面、五金、延米或面积 |
| 灯具 | 尺寸、色温、功率、安装方式 |
| 开关插座 | 品牌、系列、数量、特殊功能 |

### 5. 主材进场验收明细

| 检查项 | 说明 |
|---|---|
| 品牌型号 | 是否与合同或订单一致 |
| 规格尺寸 | 是否符合设计和现场 |
| 数量 | 是否足够，损耗是否合理 |
| 外观 | 是否破损、色差、划痕 |
| 批次 | 瓷砖、地板注意批次 |
| 配件 | 五金、辅料、说明书是否齐全 |
| 票据 | 订单、收据、质保凭证 |
| 安装条件 | 是否具备安装条件 |

### 6. 主材与施工衔接明细

| 主材 | 衔接事项 |
|---|---|
| 瓷砖 | 到货后瓦工才能连续施工 |
| 地板 | 地面平整、干燥后安装 |
| 木门 | 墙地完成后复尺，安装前墙面基本完成 |
| 橱柜 | 水电前定方案，墙砖后复尺 |
| 洁具 | 水电阶段确定给排水和电源 |
| 灯具 | 吊顶和电路需提前匹配 |
| 定制柜 | 墙地完成后复尺，注意插座位置 |
| 窗帘 | 窗帘盒、轨道和插座提前考虑 |

## 五、资料清单

选购主材前，应准备：

| 资料 | 用途 |
|---|---|
| 设计方案 | 确认风格和尺寸 |
| 施工图 | 判断安装条件 |
| 水电点位图 | 确认设备电源和水口 |
| 预算表 | 控制价格 |
| 主材清单 | 防止漏买 |
| 采购排期表 | 控制工期 |
| 合同和报价 | 核对包含范围 |
| 现场尺寸 | 防止买错 |

## 六、选购流程

### 1. 先做主材清单

按空间列出需要购买的主材，不要只凭记忆采购。

### 2. 确认预算上限

每类主材设置预算，不要单项不断升级导致整体超支。

### 3. 确认关键尺寸

涉及安装和水电的主材，应先确认尺寸和接口。

### 4. 按施工节点下单

瓷砖、木门、橱柜、定制等长周期材料要提前安排。

### 5. 到货后验收

材料进场要核对品牌、型号、规格、数量和外观。

### 6. 安装后验收

主材安装后检查功能、外观、牢固度和收口。

## 七、关键标准

### 1. 合格主材计划标准

1. 主材清单完整。
2. 采购时间匹配施工节点。
3. 品牌型号明确。
4. 预算上限清楚。
5. 安装责任明确。
6. 售后责任明确。
7. 进场验收有记录。

### 2. 高风险主材采购表现

1. 临到施工才买材料。
2. 只看款式不看尺寸。
3. 只看单价不看辅料和安装。
4. 没有确认品牌型号。
5. 不保留订单和票据。
6. 主材到货后不验收。
7. 半包中主材和施工责任不清。

## 八、验收标准

主材计划检查清单：

| 检查项 | 合格标准 | 风险表现 |
|---|---|---|
| 清单 | 按空间和类别完整列出 | 想到什么买什么 |
| 时间 | 与施工节点匹配 | 材料拖工期 |
| 预算 | 每类有上限 | 不断升级 |
| 型号 | 品牌型号规格明确 | 只写品牌 |
| 尺寸 | 与现场匹配 | 买错尺寸 |
| 安装 | 谁安装、谁负责清楚 | 出问题互推 |
| 验收 | 到货和安装都验收 | 发现问题太晚 |

## 九、常见问题

### 1. 主材什么时候开始买？

水电相关设备、洁具、橱柜方案要尽早确认；瓷砖要在瓦工前到货；木门、橱柜、全屋定制要注意复尺和生产周期；灯具、窗帘可相对后期。

### 2. 半包主材都要业主买吗？

通常半包由业主购买主材，装修公司负责人工和辅材。但具体要看合同，主材、辅材、安装和售后责任必须写清。

### 3. 全包主材还需要审核吗？

需要。全包也要看品牌、型号、规格、可选范围、升级差价和安装责任。不能只听“包含主材”。

### 4. 主材只看品牌可以吗？

不够。同一品牌有不同系列和等级，应确认型号、规格、颜色、环保等级和使用区域。

### 5. 主材买多了怎么办？

购买前要确认退补货规则。瓷砖、地板等材料还要注意批次，后期补货可能有色差。

## 十、避坑提醒

1. 不要临到施工才买主材。
2. 不要只看款式，不看尺寸和安装条件。
3. 不要忽略辅料、配件、上楼费和安装费。
4. 不要只写品牌不写型号。
5. 不要木门、橱柜、定制复尺太晚。
6. 不要材料到货不验收。
7. 不要不保留订单和质保凭证。
8. 不要让主材选择无限升级。

## 十一、案例分析

### 案例一：瓷砖未提前订，瓦工停工

用户 A 选择半包，瓦工进场前才开始选瓷砖。由于看中的瓷砖需要调货，瓦工只能停工等待，导致工期延误。

问题分析：

1. 主材采购没有排期。
2. 瓷砖到货周期被低估。
3. 半包模式下业主采购影响施工。

正确做法：

1. 瓦工前提前确认瓷砖。
2. 问清库存、送货和退补货。
3. 主材排期和施工排期联动。

### 案例二：马桶坑距不符导致退换

用户 B 购买马桶时没有确认坑距，安装时发现不匹配，只能更换型号，增加时间和费用。

问题分析：

1. 主材选购前未核对现场尺寸。
2. 卫生间量房数据没有使用。
3. 只看款式忽略安装条件。

正确做法：

1. 购买前核对坑距和排水方式。
2. 让商家确认适配条件。
3. 安装前再次核对。

## 十二、法规依据

主材选购涉及合同附件、消费者权益、产品质量和售后责任。通常可参考：

1. 《中华人民共和国民法典》中关于合同履行、买卖合同、承揽合同等规定。
2. 《中华人民共和国消费者权益保护法》中关于知情权、公平交易权和依法维权等规定。
3. 产品订单、发票、质保卡、材料清单、装修合同和补充协议。

具体质量和售后争议应结合购买凭证、合同约定和产品实际情况判断。
