# 开工前准备

## 一、概述

开工前准备是装修从“纸面方案”进入“现场施工”的关键环节。很多施工问题并不是工人技术问题，而是开工前没有把图纸、预算、材料、物业手续、现场保护、施工范围和责任人确认清楚。

开工前准备做得越充分，后期返工、增项、扯皮和延期的概率越低。尤其是水电点位、拆改位置、材料品牌、付款节点和验收标准，一旦开工后再反复修改，不仅增加费用，还会影响工期和施工质量。

开工前准备的目标是：

1. 手续合法合规。
2. 图纸和方案确认。
3. 报价和合同完整。
4. 现场保护到位。
5. 材料和工人安排清楚。
6. 开工交底有记录。

## 二、适用范围

本文适用于以下场景：

1. 已经签订装修合同，准备正式开工的用户。
2. 准备办理物业装修手续的用户。
3. 准备进行开工交底的用户。
4. 担心施工前遗漏事项导致后期增项的用户。
5. 装修公司项目经理、设计师、客服进行开工前提醒时使用。
6. 后续 AI 客服回答“开工前要准备什么”等问题时使用。

本文主要面向住宅装修，包括新房装修、二手房翻新、局部改造、半包、全包和整装。

## 三、基础知识

### 1. 开工前准备是什么

开工前准备是指正式施工前，业主、装修公司、设计师、项目经理、施工负责人和物业之间完成的一系列确认动作。

主要包括：

1. 物业手续办理。
2. 合同和报价确认。
3. 施工图确认。
4. 材料清单确认。
5. 开工交底。
6. 成品保护。
7. 施工计划确认。
8. 邻里和物业沟通。
9. 现场拍照存档。

### 2. 为什么开工前准备重要

开工前准备不足，容易导致：

1. 物业不允许施工或中途停工。
2. 拆改位置错误。
3. 水电点位遗漏。
4. 材料进场不符合合同。
5. 成品保护不到位。
6. 口头交底导致理解偏差。
7. 后期增项和变更频繁。
8. 施工延期。

### 3. 开工前必须确认的核心文件

| 文件 | 用途 |
|---|---|
| 装修合同 | 明确双方权利义务 |
| 报价单 | 明确施工项目和费用 |
| 施工图 | 指导现场施工 |
| 材料清单 | 明确品牌型号和规格 |
| 工期表 | 明确施工节点 |
| 付款节点表 | 明确付款条件 |
| 物业装修协议 | 明确小区施工要求 |
| 开工交底记录 | 明确现场确认内容 |

## 四、专业知识

### 1. 开工前准备总清单

| 类别 | 准备事项 | 是否必须 |
|---|---|---|
| 手续 | 物业装修登记、施工许可证、装修押金 | 必须 |
| 文件 | 合同、报价、图纸、材料清单 | 必须 |
| 现场 | 原房拍照、成品保护、钥匙交接 | 必须 |
| 施工 | 项目经理、工长、工人安排 | 必须 |
| 材料 | 首批辅材、保护材料、拆改工具 | 必须 |
| 邻里 | 告知施工时间和可能噪音 | 建议 |
| 安全 | 水电燃气检查、承重墙确认 | 必须 |
| 记录 | 开工交底单、照片、视频 | 必须 |

### 2. 物业手续明细

不同小区要求不同，但常见包括：

| 项目 | 说明 | 风险 |
|---|---|---|
| 装修申请 | 向物业提交装修申请 | 未申请可能被停工 |
| 装修协议 | 确认施工时间、垃圾清运、公共区域保护 | 违反可能扣押金 |
| 装修押金 | 业主或施工方缴纳 | 退还条件要问清 |
| 施工人员登记 | 工人出入证或登记 | 无证可能无法进场 |
| 图纸报备 | 拆改、水电、施工方案报备 | 涉及结构时重点审核 |
| 垃圾清运 | 清运地点、时间、费用 | 后期额外收费 |
| 电梯保护 | 保护要求和使用规定 | 损坏公共区域需赔偿 |
| 施工时间 | 噪音施工时间限制 | 违规被投诉停工 |

### 3. 图纸确认明细

开工前至少应确认以下图纸：

| 图纸 | 重点 |
|---|---|
| 原始结构图 | 承重墙、梁柱、烟道、管井 |
| 平面布置图 | 家具、动线、功能分区 |
| 拆改图 | 拆除和新建墙体 |
| 水电点位图 | 开关、插座、灯位、水口 |
| 顶面图 | 吊顶、灯具、空调、新风 |
| 地面铺贴图 | 地砖、地板、过门石 |
| 立面图 | 背景墙、柜体、墙面造型 |
| 节点图 | 复杂收口和特殊工艺 |

没有图纸或图纸不完整时，不建议仓促开工。

### 4. 现场检查明细

开工前应对原房状态拍照和记录。

| 检查项 | 重点 | 作用 |
|---|---|---|
| 墙面 | 裂缝、空鼓、返碱、渗水 | 区分原房问题和施工问题 |
| 地面 | 空鼓、开裂、平整度 | 判断是否需要找平 |
| 顶面 | 裂缝、渗水、脱落 | 判断基层处理 |
| 门窗 | 开关、密封、破损 | 避免后期责任争议 |
| 水路 | 下水、地漏、渗漏 | 防止施工后责任不清 |
| 电路 | 强弱电箱、插座、照明 | 判断改造基础 |
| 燃气 | 管道位置、阀门 | 不得私自改动 |
| 公共区域 | 电梯、走廊、入户门 | 保护和赔偿依据 |

### 5. 成品保护明细

| 保护位置 | 保护要求 | 风险 |
|---|---|---|
| 入户门 | 门套、门扇、防撞保护 | 搬运材料刮伤 |
| 电梯 | 物业要求保护 | 损坏公共设施 |
| 走廊 | 地面和墙面保护 | 邻里和物业投诉 |
| 窗户 | 防尘、防撞 | 拆改和搬运损坏 |
| 地面 | 保护膜或保护板 | 施工磨损 |
| 下水口 | 封堵保护 | 建筑垃圾堵塞 |
| 强弱电箱 | 防尘保护 | 施工污染和损坏 |

### 6. 开工交底明细

开工交底应尽量现场完成，参与人员包括业主、设计师、项目经理、施工负责人，必要时物业也应参与。

| 交底内容 | 应确认什么 |
|---|---|
| 施工范围 | 哪些空间、哪些项目施工 |
| 拆改位置 | 拆哪里、砌哪里、哪里不能动 |
| 水电点位 | 插座、开关、灯位、水口、设备位置 |
| 材料标准 | 首批材料品牌型号 |
| 工艺做法 | 防水、铺贴、吊顶、墙面处理 |
| 工期安排 | 开工、节点、竣工时间 |
| 保护措施 | 门窗、电梯、地面、下水 |
| 验收节点 | 水电、防水、瓦工等验收时间 |
| 沟通机制 | 谁负责现场，问题找谁 |
| 变更规则 | 增减项如何确认 |

交底后建议形成书面交底记录，并拍照留档。

### 7. 首批材料进场明细

开工初期常见进场材料包括：

| 材料 | 验收重点 |
|---|---|
| 电线 | 品牌、规格、线径、数量 |
| 水管 | 品牌、管径、冷热水管 |
| 线管 | 品牌、阻燃性能、规格 |
| 防水材料 | 品牌、型号、生产日期 |
| 水泥沙子 | 品牌、强度、质量 |
| 腻子 | 品牌、类型、环保等级 |
| 石膏板 | 品牌、厚度、防潮性能 |
| 龙骨 | 材质、规格、厚度 |
| 保护材料 | 数量和覆盖范围 |

材料进场时应对照合同和材料清单验收，不一致时不要直接使用。

## 六、准备流程

### 1. 完成合同和附件审核

确认合同、报价单、材料清单、施工图、付款节点和工期表完整。

### 2. 办理物业手续

提交装修申请，办理施工人员登记、押金、垃圾清运、电梯保护等事项。

### 3. 做原房检查和拍照

记录墙面、地面、顶面、门窗、水电、燃气、公共区域状态。

### 4. 完成现场保护

入户门、电梯、地面、下水口、窗户等位置做好保护。

### 5. 组织开工交底

业主、设计师、项目经理、工长现场确认施工范围、图纸、材料和验收节点。

### 6. 确认首批材料

材料进场时对照材料清单验收，确认品牌、型号、规格和数量。

### 7. 建立沟通和记录机制

明确项目经理、设计师、业主沟通方式，重要事项书面确认。

## 七、关键标准

### 1. 合格开工标准

1. 物业手续已办理。
2. 合同附件完整。
3. 施工图已确认。
4. 施工范围清楚。
5. 成品保护到位。
6. 原房状态已拍照。
7. 开工交底已完成。
8. 首批材料已验收。
9. 工期和验收节点已确认。
10. 变更规则已明确。

### 2. 高风险开工表现

1. 未办理物业手续就施工。
2. 图纸未确认就拆改。
3. 水电点位未确认就开槽。
4. 报价和材料清单不完整。
5. 没有成品保护。
6. 原房问题未记录。
7. 只有口头交底。
8. 项目经理和工长责任不清。

## 八、验收标准

开工前检查清单：

| 检查项 | 合格标准 | 风险表现 |
|---|---|---|
| 物业手续 | 已登记、押金、施工时间清楚 | 可能被停工 |
| 合同附件 | 报价、图纸、材料、工期完整 | 后期扯皮 |
| 图纸 | 拆改、水电、平面等确认 | 现场凭经验施工 |
| 现场拍照 | 原房和公共区域有记录 | 责任不清 |
| 成品保护 | 入户门、电梯、地面保护 | 损坏赔偿 |
| 交底记录 | 各方签字或确认 | 口头交代 |
| 材料进场 | 对照清单验收 | 材料替换 |
| 沟通机制 | 责任人明确 | 问题无人处理 |

## 九、常见问题

### 1. 装修开工前必须办物业手续吗？

通常需要。物业会要求装修登记、施工人员管理、垃圾清运、电梯保护、施工时间等。未办理手续可能被停工或扣押金。

### 2. 开工交底一定要做吗？

建议必须做。开工交底能让业主、设计师、项目经理和施工负责人现场确认施工范围、拆改位置、水电点位、材料标准和验收节点。

### 3. 没有完整施工图可以开工吗？

不建议。至少应有平面图、拆改图、水电点位图和关键施工说明。没有图纸容易导致现场凭经验施工，后期返工风险高。

### 4. 开工前为什么要拍照？

拍照可以记录原房状态和公共区域状态，后期如果出现门窗损坏、墙面裂缝、地面问题或公共区域纠纷，可以作为责任判断依据。

### 5. 首批材料进场要验收吗？

要验收。应对照合同和材料清单检查品牌、型号、规格、数量、生产日期等。不一致时应先确认再使用。

## 十、避坑提醒

1. 不要未办物业手续就开工。
2. 不要图纸未确认就拆改。
3. 不要水电点位没确认就开槽。
4. 不要只口头开工交底。
5. 不要忽略原房拍照。
6. 不要忽略公共区域保护。
7. 不要材料未验收就使用。
8. 不要让项目经理、设计师、工长责任混乱。
9. 不要开工前不确认付款和验收节点。
10. 不要把变更规则留到施工中再谈。

## 十一、案例分析

### 案例一：未确认水电点位导致返工

用户 A 开工前没有认真确认水电点位，施工方按初步方案开槽。后期用户购买洗碗机和烘干机，发现没有预留水电位置，只能重新开槽改线。

问题分析：

1. 水电点位未在开工前确认。
2. 家电清单没有提前确定。
3. 开工交底不充分。

正确做法：

1. 开工前确认家电和家具尺寸。
2. 水电图现场交底。
3. 变更前确认费用和工期影响。

### 案例二：物业手续不全导致停工

用户 B 装修公司进场后直接拆改，物业发现未办理装修登记和施工人员手续，要求停工补办，导致工期延误。

问题分析：

1. 开工前未办理物业手续。
2. 装修公司和业主责任分工不清。
3. 工期计划没有考虑手续时间。

正确做法：

1. 开工前向物业确认要求。
2. 办理装修登记、押金、施工证。
3. 把物业限制写入工期计划。

### 案例三：原房问题未记录导致责任争议

用户 C 装修后发现窗户划痕和墙面裂缝，装修公司认为是原房问题，用户认为施工造成。由于开工前没有拍照，双方难以判断责任。

问题分析：

1. 原房状态没有拍照留档。
2. 开工检查不完整。
3. 责任边界不清。

正确做法：

1. 开工前拍摄墙地面、门窗、水电、公共区域。
2. 发现原房问题及时记录。
3. 交底单中写明特殊问题。

## 十二、法规依据

开工前准备涉及物业管理、住宅装修管理、合同履行和安全施工。通常可参考：

1. 《住宅室内装饰装修管理办法》中关于住宅装修活动、禁止行为、装修申报和管理的规定。
2. 《中华人民共和国民法典》中关于合同履行、违约责任等规定。
3. 小区物业装修管理协议、业主规约和施工管理要求。
4. 双方签订的装修合同、施工图、报价单、材料清单和开工交底记录。

具体执行要求应结合当地规定和小区物业管理制度。
