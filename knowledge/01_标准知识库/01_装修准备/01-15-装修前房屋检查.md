# 装修前房屋检查

## 一、概述

装修前房屋检查是正式开工前对房屋原始状态进行系统检查和记录的工作。它的目的不是替代专业验房，而是帮助业主在装修前发现墙面、地面、顶面、门窗、水电、渗漏、空鼓、裂缝、下水、燃气和公共区域等问题，避免后期责任不清。

很多用户开工后才发现墙面空鼓、窗户漏风、卫生间渗水、下水不畅、地面不平等问题。此时再判断是开发商交付问题、原房问题、装修施工问题，往往会变得复杂。

装修前房屋检查的目标是：

1. 发现原房质量问题。
2. 明确哪些问题应先整改。
3. 为报价和施工提供依据。
4. 为后期责任判断留证据。
5. 减少施工返工和纠纷。

## 二、适用范围

本文适用于以下场景：

1. 新房收房后准备装修的用户。
2. 二手房翻新前需要检查房屋状态的用户。
3. 精装房改造前需要确认原交付质量的用户。
4. 准备开工，需要拍照留档的用户。
5. 装修公司客服、设计师、项目经理进行开工前提醒时使用。

本文主要面向住宅装修。严重结构问题、重大渗漏、燃气安全、电气安全等事项，应咨询专业机构或相关单位。

## 三、基础知识

### 1. 装修前房屋检查是什么

装修前房屋检查是对房屋当前状态进行观察、测试、记录和拍照。它通常包括：

1. 墙面检查。
2. 地面检查。
3. 顶面检查。
4. 门窗检查。
5. 厨卫渗漏检查。
6. 下水排水检查。
7. 强弱电检查。
8. 燃气和管道检查。
9. 空鼓和裂缝检查。
10. 公共区域和入户门检查。

### 2. 新房和二手房检查重点不同

| 类型 | 检查重点 |
|---|---|
| 新房 | 开发商交付质量、空鼓、裂缝、渗漏、门窗、水电 |
| 二手房 | 老化管线、防水失效、墙面基层、结构改动、下水 |
| 精装房 | 成品保护、材料质量、安装质量、局部改造限制 |
| 老房翻新 | 管线老化、墙体基层、渗漏、结构安全 |

### 3. 为什么要拍照留档

拍照可以记录装修前状态，后期如果出现墙面裂缝、门窗损坏、地面问题、公共区域赔偿等争议，可以帮助判断责任。

## 四、专业知识

### 1. 房屋检查总清单

| 类别 | 检查内容 | 重点 |
|---|---|---|
| 墙面 | 空鼓、裂缝、起砂、返碱、渗水 | 影响基层处理 |
| 地面 | 空鼓、裂缝、平整度、高低差 | 影响找平和铺装 |
| 顶面 | 裂缝、渗水、脱落 | 影响吊顶和油工 |
| 门窗 | 开关、密封、破损、渗水 | 影响使用和责任 |
| 厨卫 | 防水、地漏、下水、管道 | 影响渗漏风险 |
| 水路 | 水压、排水、渗漏 | 影响水电改造 |
| 电路 | 强弱电箱、插座、照明 | 影响电路规划 |
| 燃气 | 表位、管道、阀门 | 涉及安全 |
| 公共区域 | 电梯、走廊、入户门 | 避免赔偿争议 |

### 2. 墙面检查明细

| 检查项 | 方法 | 风险 |
|---|---|---|
| 空鼓 | 空鼓锤或敲击听声音 | 后期墙面开裂、脱落 |
| 裂缝 | 观察墙角、门窗洞口 | 可能是基层或结构问题 |
| 返碱 | 看是否有白色粉化 | 潮气或基层问题 |
| 渗水 | 看水印、霉斑、潮湿 | 防水或外墙问题 |
| 平整度 | 靠尺或目测 | 影响柜体和墙面效果 |
| 起砂 | 手摸是否掉粉 | 基层强度不足 |

### 3. 地面检查明细

| 检查项 | 方法 | 风险 |
|---|---|---|
| 空鼓 | 敲击检查 | 铺砖或找平风险 |
| 裂缝 | 观察明显裂纹 | 基层问题 |
| 平整度 | 水平尺或靠尺 | 地板安装受影响 |
| 高低差 | 检查不同空间地面 | 影响门槛和铺装 |
| 起砂 | 手摸或扫地观察 | 找平层质量差 |

### 4. 顶面检查明细

| 检查项 | 重点 |
|---|---|
| 渗水痕迹 | 顶楼、卫生间下方尤其注意 |
| 裂缝 | 梁边、板缝、阴角 |
| 脱落 | 原顶面基层强度 |
| 层高 | 影响吊顶、中央空调、新风 |
| 梁位 | 影响吊顶和柜体 |

### 5. 门窗检查明细

| 检查项 | 方法 |
|---|---|
| 开关是否顺畅 | 多次开合 |
| 密封是否良好 | 看胶条和缝隙 |
| 玻璃是否破损 | 看划痕、裂纹 |
| 窗框是否渗水 | 雨后或洒水观察 |
| 五金是否松动 | 检查把手、合页、锁具 |
| 门洞是否方正 | 影响木门安装 |

### 6. 厨卫和阳台检查明细

| 检查项 | 重点 |
|---|---|
| 地漏排水 | 倒水测试排水速度 |
| 下水异味 | 判断存水弯和密封 |
| 管根渗漏 | 看管道周边水印 |
| 防水状态 | 新房可结合闭水测试 |
| 烟道 | 是否堵塞、止逆阀位置 |
| 燃气 | 管道位置和阀门状态 |
| 阳台排水 | 地漏、坡度、雨水 |

### 7. 水电检查明细

| 检查项 | 重点 |
|---|---|
| 强电箱 | 回路、空开、漏保 |
| 弱电箱 | 网线、光纤、空间 |
| 插座 | 是否通电、位置 |
| 照明 | 开关控制是否正常 |
| 水压 | 出水是否稳定 |
| 下水 | 排水是否通畅 |
| 管道 | 是否有渗漏 |

### 8. 二手房重点检查

二手房翻新尤其要注意：

1. 原水电管线是否老化。
2. 卫生间和厨房是否有历史渗漏。
3. 墙面基层是否多次翻新。
4. 原有拆改是否合规。
5. 门窗是否变形和漏风。
6. 下水是否堵塞或反味。
7. 楼上楼下是否存在渗漏纠纷。
8. 原地面是否适合直接施工。

## 六、检查流程

### 1. 先拍全屋视频

从入户开始，按空间拍摄全屋视频，记录装修前整体状态。

### 2. 按空间逐项检查

依次检查客厅、卧室、厨房、卫生间、阳台和公共区域。

### 3. 重点检查厨卫阳台

这些区域涉及水、防水、排水和渗漏，是装修前检查重点。

### 4. 标注问题位置

在户型图上标出空鼓、裂缝、渗水、损坏、下水问题等位置。

### 5. 判断处理方式

能由开发商或原责任方整改的，先联系整改；需要装修处理的，纳入报价和施工方案。

### 6. 保存资料

保存照片、视频、问题清单、沟通记录和整改记录。

## 七、关键标准

### 1. 合格检查标准

1. 全屋有照片和视频。
2. 墙地顶面问题有记录。
3. 厨卫阳台排水和渗漏检查完成。
4. 门窗和五金检查完成。
5. 水电基础检查完成。
6. 公共区域状态有记录。
7. 问题已形成清单。
8. 需要整改的问题已明确责任。

### 2. 高风险表现

1. 开工前不检查。
2. 不拍照留档。
3. 墙面空鼓不处理。
4. 渗漏问题直接装修覆盖。
5. 下水不测。
6. 二手房不检查水电老化。
7. 原房问题和施工问题混在一起。

## 八、验收标准

装修前检查清单：

| 检查项 | 合格标准 | 风险表现 |
|---|---|---|
| 墙面 | 空鼓裂缝渗水有记录 | 后期责任不清 |
| 地面 | 平整和空鼓检查 | 铺装返工 |
| 顶面 | 渗水和裂缝检查 | 吊顶遮盖问题 |
| 门窗 | 开关密封正常 | 后期争议 |
| 厨卫 | 排水和渗漏检查 | 漏水风险 |
| 水电 | 基础功能检查 | 改造方案不准 |
| 公共区 | 电梯走廊入户门拍照 | 赔偿争议 |
| 问题清单 | 位置、照片、处理方式清楚 | 口头记录 |

## 九、常见问题

### 1. 新房已经验房了，装修前还要检查吗？

建议还要检查。验房和装修前检查目的不同。装修前检查可以帮助装修公司了解现场问题，并为后期施工责任留证据。

### 2. 墙面空鼓一定要处理吗？

要看空鼓位置、面积和后续施工方式。大面积空鼓或影响贴砖、墙面处理的位置，应在施工前处理。

### 3. 二手房装修前最该检查什么？

重点检查水电老化、厨卫渗漏、墙面基层、下水、门窗、原有拆改和结构安全。

### 4. 开工前拍公共区域有必要吗？

有必要。搬运材料可能涉及电梯、走廊、入户门损坏，开工前照片能帮助判断责任。

### 5. 发现渗漏可以直接装修遮盖吗？

不建议。渗漏原因应先查清并处理，否则装修后可能再次出现，维修成本更高。

## 十、避坑提醒

1. 不要不检查就开工。
2. 不要不拍照留档。
3. 不要忽略墙面空鼓和裂缝。
4. 不要忽略厨卫阳台渗漏。
5. 不要二手房不查水电老化。
6. 不要原房问题未处理就覆盖施工。
7. 不要公共区域不拍照。
8. 不要发现问题只口头沟通。

## 十一、案例分析

### 案例一：墙面空鼓未处理，后期乳胶漆开裂

用户 A 开工前没有检查墙面空鼓，油工完成后部分墙面出现开裂和起皮。施工方认为原墙基层差，用户认为施工质量差。

问题分析：

1. 开工前未检查基层。
2. 原房问题没有记录。
3. 报价中未包含基层处理。

正确做法：

1. 开工前检查墙面空鼓。
2. 需要处理的基层写入报价。
3. 拍照记录原始状态。

### 案例二：二手房下水未测，装修后反味

用户 B 二手房翻新前没有测试下水和地漏。入住后卫生间反味，下水排水慢，需要重新检查管道。

问题分析：

1. 装修前未做排水测试。
2. 老房管道问题被忽略。
3. 后期维修影响已完成装修。

正确做法：

1. 装修前测试下水。
2. 检查地漏和存水弯。
3. 必要时提前改造排水。

## 十二、法规依据

装修前房屋检查涉及房屋质量、装修施工、合同责任和物业管理。通常可参考：

1. 《住宅室内装饰装修管理办法》中关于住宅装修活动和禁止行为的规定。
2. 《中华人民共和国民法典》中关于合同履行、质量责任、侵权责任等规定。
3. 购房合同、收房文件、物业装修协议和装修合同。
4. 双方确认的现场照片、问题清单、整改记录和验收单。

具体质量责任应结合房屋交付情况、合同约定和证据材料判断。
