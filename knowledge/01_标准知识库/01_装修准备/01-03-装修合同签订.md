# 装修合同签订

## 一、概述

装修合同是业主与装修公司、施工队或设计施工服务方之间确认权利义务的核心文件。它不仅决定装修价格，还决定施工范围、材料标准、付款节点、工期、验收方式、增减项规则、保修责任和违约处理方式。

很多装修纠纷并不是施工当天才发生，而是在签合同前就已经埋下风险。例如报价单漏项、材料品牌型号模糊、付款比例不合理、工期没有违约责任、增项没有确认规则、保修条款写得过于笼统等。

因此，装修合同不能只看总价，也不能只看合同正文。正确做法是把合同正文、报价单、施工图、材料清单、工期表、付款节点、补充协议、保修条款作为一个整体来审核。

## 二、适用范围

本文适用于以下场景：

1. 准备与装修公司签订装修合同的业主。
2. 准备选择半包、全包、整装服务的用户。
3. 已经拿到装修报价单，但还没有签约的用户。
4. 对合同付款方式、增项、工期、保修存在疑问的用户。
5. 装修公司客服、销售、设计师进行合同讲解时使用。
6. 后续 AI 客服回答装修合同相关问题时使用。

本文主要面向住宅装修合同，包括新房装修、二手房翻新、局部改造、半包、全包和整装服务。商业空间装修、工装项目、别墅大宅项目可参考本文框架，但需要结合消防、报建、工程管理和专项施工要求另行补充。

## 三、基础知识

### 1. 装修合同是什么

装修合同是约定装修服务内容、价格、工期、质量、付款、验收、保修和违约责任的书面协议。它的作用不是“走流程”，而是在出现争议时明确双方责任。

装修合同通常包括：

| 内容 | 作用 |
|---|---|
| 合同主体 | 明确谁和谁签约 |
| 工程地址 | 明确装修房屋位置 |
| 装修范围 | 明确做哪些项目 |
| 合同金额 | 明确总价和计价方式 |
| 付款方式 | 明确什么时候付款 |
| 工期约定 | 明确开工、竣工和延期责任 |
| 材料标准 | 明确品牌、型号、规格、等级 |
| 施工标准 | 明确施工工艺和质量要求 |
| 变更规则 | 明确增减项如何确认 |
| 验收方式 | 明确节点验收和竣工验收 |
| 保修条款 | 明确保修范围和期限 |
| 违约责任 | 明确违约后的处理方式 |

### 2. 合同正文和附件同样重要

装修合同中，真正决定后续施工细节的往往不是合同正文，而是附件。

常见附件包括：

1. 装修报价单。
2. 施工图纸。
3. 材料清单。
4. 工艺说明。
5. 工期进度表。
6. 付款节点表。
7. 增减项确认单。
8. 保修服务说明。
9. 设计方案确认文件。

如果合同正文写得很完整，但附件不清楚，后期仍然容易产生纠纷。

### 3. 为什么不能只看总价

装修报价中的总价可能被很多因素影响，例如项目是否完整、工程量是否准确、材料标准是否明确、工艺是否包含、管理费和税费是否计入、后期是否容易增项等。

同样是 10 万元装修合同，可能存在完全不同的内容：

| 情况 | 表面总价 | 实际风险 |
|---|---:|---|
| 项目完整、材料明确 | 10 万元 | 风险较低 |
| 低价漏项 | 8 万元 | 后期增项可能超过 3 万元 |
| 材料模糊 | 9 万元 | 交付品质不可控 |
| 付款过快 | 10 万元 | 用户后期缺少制约 |

所以合同审核的核心不是“便不便宜”，而是“是否清楚、完整、可执行、可追责”。

## 四、专业知识

### 1. 装修合同的核心审核逻辑

审核装修合同可以按照五个问题判断：

1. 谁负责？
2. 做什么？
3. 用什么？
4. 怎么做？
5. 出问题怎么办？

如果这五个问题都能在合同和附件中找到明确答案，合同风险就会明显降低。

### 2. 合同条款审核明细

装修合同审核不能只看有没有盖章，而要逐条看是否清楚、完整、可执行。

| 条款 | 应写清楚什么 | 常见风险 |
|---|---|---|
| 合同主体 | 公司全称、地址、联系方式、签约人 | 门店名、品牌名和合同主体不一致 |
| 工程地址 | 小区、楼栋、房号、施工房屋 | 地址模糊影响责任认定 |
| 施工范围 | 空间、项目、工程内容 | 只写全屋装修 |
| 合同金额 | 总价、计价方式、是否含税 | 后期开票另收费 |
| 报价附件 | 项目、工程量、单价、材料、工艺 | 报价单不作为合同附件 |
| 材料条款 | 品牌、型号、规格、等级、使用区域 | 只写品牌或同档次 |
| 工期条款 | 开工日、竣工日、延期责任 | 只写预计工期 |
| 付款条款 | 付款比例、付款节点、验收条件 | 开工前支付过多 |
| 增减项 | 报价、确认、施工、结算流程 | 先施工后收费 |
| 验收条款 | 节点验收、竣工验收、整改期限 | 没有验收流程 |
| 保修条款 | 范围、期限、响应时间、责任主体 | 只写质保两年 |
| 违约责任 | 逾期、质量、材料替换等责任 | 只有原则性描述 |

### 3. 合同主体必须清楚

签约前应确认装修公司的主体信息，包括公司全称、统一社会信用代码、注册地址、联系电话、授权签约人等。

用户要注意：

1. 合同上的公司名称应与营业执照一致。
2. 收款账户应尽量使用公司对公账户。
3. 如果由门店、设计师、项目经理代签，应确认其授权。
4. 不建议把大额装修款转给个人账户。

如果合同主体不清，后期发生纠纷时，用户可能难以确认责任方。

主体信息审核明细：

| 审核项 | 合格表现 | 风险表现 |
|---|---|---|
| 公司名称 | 与营业执照、合同章一致 | 品牌名和签约主体不一致 |
| 收款账户 | 对公账户或合同约定账户 | 要求转个人账户 |
| 签约人 | 有授权或代表公司签约 | 临时人员代签 |
| 合同印章 | 公司公章或合同专用章清楚 | 只签字不盖章 |
| 门店关系 | 直营、加盟、合作关系清楚 | 出问题时互相推责 |
| 售后主体 | 明确哪个公司负责 | 门店撤场后无人负责 |

### 4. 施工范围必须具体

施工范围应明确到空间、项目和工程内容，不能只写“全屋装修”“基础施工”“水电改造”等宽泛描述。

较好的写法：

```text
客厅、餐厅、卧室、厨房、卫生间、阳台的墙面、地面、顶面、水电、防水、瓦工、木工、油工及安装工程，具体以报价单和施工图为准。
```

风险写法：

```text
全屋装修一套。
```

施工范围越模糊，后期越容易发生“这个不包含”“那个要加钱”的争议。

施工范围明细示例：

| 空间 | 应明确内容 |
|---|---|
| 客厅餐厅 | 墙顶地面处理、水电点位、吊顶、灯具安装 |
| 卧室 | 墙顶地面、门、插座、开关、空调点位 |
| 厨房 | 水电、防水、墙地砖、橱柜配合、吊顶 |
| 卫生间 | 水电、防水、墙地砖、洁具、地漏、排风 |
| 阳台 | 防水、地面、墙面、洗衣机点位、地漏 |
| 全屋 | 成品保护、垃圾清运、材料搬运、竣工保洁 |

### 5. 报价单必须作为合同附件

报价单不是销售沟通材料，而应成为合同附件。否则，签约后装修公司可以主张合同只约定总价，没有约定具体项目和材料。

报价单至少应包含：

| 字段 | 要求 |
|---|---|
| 项目名称 | 不能过于笼统 |
| 单位 | 平方米、米、项、个等 |
| 工程量 | 与现场实际匹配 |
| 单价 | 人工、材料或综合单价清楚 |
| 合价 | 计算准确 |
| 材料 | 品牌、型号、规格、等级 |
| 工艺 | 施工做法清楚 |
| 备注 | 包含或不包含内容明确 |

报价单附件检查明细：

| 检查项 | 合格表现 | 风险表现 |
|---|---|---|
| 项目名称 | 具体到施工内容 | 只写基础施工 |
| 工程量 | 与房屋面积和现场情况匹配 | 明显低估，后期按实结算 |
| 单位 | 平方米、米、项、个清楚 | 单位混乱，难以核算 |
| 单价 | 人工、材料或综合单价明确 | 只写总价 |
| 材料 | 品牌、型号、规格明确 | 只写品牌 |
| 工艺 | 施工做法和标准清楚 | 只写标准工艺 |
| 不含项 | 明确列出不包含内容 | 后期才说不包含 |
| 增项单价 | 常见增项提前约定 | 临时议价 |

### 6. 材料标准不能只写品牌

材料条款如果只写品牌，不写型号、规格、系列、等级，仍然存在风险。因为同一品牌下可能有不同价格和质量等级。

例如：

风险写法：

```text
乳胶漆：立邦。
```

较好写法：

```text
乳胶漆：立邦某系列，规格、颜色、环保等级、使用区域以材料清单为准。
```

主材、辅材、定制产品都应尽量写清楚品牌、型号、规格、颜色、等级和适用区域。

材料清单明细：

| 材料类别 | 应写明细 | 风险点 |
|---|---|---|
| 电线 | 品牌、规格、线径、阻燃等级 | 线径不足、品牌替换 |
| 水管 | 品牌、管径、冷热水管规格 | 管件和水管品牌不一致 |
| 防水 | 品牌、型号、涂刷区域、高度 | 只写防水施工 |
| 腻子 | 品牌、类型、环保等级 | 使用低价非耐水腻子 |
| 乳胶漆 | 品牌、系列、颜色、环保等级 | 低端系列替代 |
| 瓷砖 | 品牌、型号、规格、数量、损耗 | 同品牌低配产品 |
| 地板 | 品牌、型号、厚度、环保等级 | 安装辅料另算 |
| 木门 | 品牌、材质、门套、五金 | 门套线和五金另收费 |
| 洁具 | 品牌、型号、规格 | 套餐款式受限 |
| 定制柜 | 板材、厚度、五金、计价方式 | 展开面积和投影面积混淆 |

### 7. 付款方式决定用户主动权

装修合同中，付款方式非常关键。付款过快，用户在后期验收、整改和售后中会缺少制约。

常见付款节点包括：

1. 签约定金或首付款。
2. 开工款。
3. 水电验收款。
4. 瓦木油阶段款。
5. 安装阶段款。
6. 竣工验收尾款。

建议付款与工程进度、节点验收绑定，而不是按日期简单付款。

风险较高的付款方式：

1. 开工前支付大部分款项。
2. 未验收就支付下一阶段款。
3. 尾款比例过低，无法约束整改。
4. 付款节点写得模糊，例如“按工程进度付款”。

付款比例风险明细：

| 付款方式 | 风险等级 | 原因 |
|---|---|---|
| 开工前付 80% 以上 | 高 | 后期用户缺少约束 |
| 开工前付 50% 左右 | 中 | 需要看后续尾款和验收绑定 |
| 按节点验收付款 | 较低 | 工程进度和付款相匹配 |
| 竣工前几乎付清 | 高 | 整改和售后推动困难 |
| 尾款过低 | 中高 | 对问题整改约束有限 |

合同中不一定存在唯一标准比例，但原则是付款进度不能明显快于施工进度。

### 8. 工期必须有起止时间和延期责任

合同应明确开工日期、竣工日期、总工期、延期情形、延期责任和违约赔偿方式。

需要区分的延期原因：

| 延期原因 | 责任判断 |
|---|---|
| 装修公司施工组织问题 | 通常由装修公司承担 |
| 材料未按时到货 | 看材料采购责任归属 |
| 业主变更方案 | 通常需顺延工期 |
| 物业停工或政策限制 | 需结合实际判断 |
| 不可抗力 | 按合同和法律规定处理 |

工期条款不能只写“预计 90 天完工”，应写清楚逾期责任。

### 9. 增减项必须书面确认

增减项是装修纠纷高发点。合同应约定：

1. 什么情况属于增项。
2. 增项由谁提出。
3. 增项报价如何确认。
4. 是否必须书面签字或线上确认。
5. 未经确认的增项是否可以收费。
6. 减项如何退款或抵扣。

建议写明：

```text
任何增减项须经业主书面确认后方可施工。未经业主确认的增项，业主有权拒绝支付。
```

增减项明细：

| 增减项类型 | 常见内容 | 审核重点 |
|---|---|---|
| 拆改增项 | 拆墙、砌墙、门洞修补 | 是否原报价漏项 |
| 水电增项 | 点位增加、线路延长、回路增加 | 单价是否提前约定 |
| 防水增项 | 防水高度增加、区域增加 | 是否确有必要 |
| 瓦工增项 | 大砖铺贴、异形铺贴、倒角 | 特殊工艺是否提前说明 |
| 木工增项 | 吊顶造型、基层加固 | 是否有图纸确认 |
| 油工增项 | 墙面找平、挂网、防裂处理 | 基层问题由谁承担 |
| 安装增项 | 打孔、高空、辅材、五金 | 是否属于套餐外 |
| 减项 | 用户取消项目或材料 | 退款方式和金额 |

### 10. 验收节点要写进合同

合同应明确至少以下验收节点：

1. 开工交底确认。
2. 拆改验收。
3. 水电验收。
4. 防水验收。
5. 瓦工验收。
6. 木工验收。
7. 油工验收。
8. 安装验收。
9. 竣工验收。

隐蔽工程尤其要在封闭前验收。水电、防水未验收就封槽、贴砖或吊顶，后期责任很难判断。

### 11. 保修条款不能笼统

保修条款应明确保修范围、保修期限、响应时间、维修责任和不保修情形。

常见保修内容包括：

| 项目 | 关注点 |
|---|---|
| 防水工程 | 渗漏责任和维修范围 |
| 水电工程 | 管线质量、接头问题 |
| 墙面工程 | 开裂、脱落、起皮 |
| 瓷砖工程 | 空鼓、脱落 |
| 木作安装 | 变形、松动、五金问题 |

保修不是一句“质保两年”就够了，应写清楚哪些项目保、怎么报修、多久响应。

## 五、合同资料清单

签约前，用户应要求装修公司提供以下资料：

| 资料 | 是否必须 | 审核重点 |
|---|---|---|
| 营业执照 | 必须 | 公司名称是否与合同一致 |
| 合同正文 | 必须 | 权利义务是否清楚 |
| 报价单 | 必须 | 项目、工程量、单价、材料 |
| 施工图 | 建议必须 | 平面、水电、吊顶、立面等 |
| 材料清单 | 必须 | 品牌、型号、规格、等级 |
| 工艺说明 | 建议必须 | 施工标准是否明确 |
| 工期表 | 必须 | 开工、节点、竣工时间 |
| 付款节点表 | 必须 | 是否与验收绑定 |
| 增减项规则 | 必须 | 是否需书面确认 |
| 保修说明 | 必须 | 保修范围和期限 |
| 补充协议 | 视情况 | 是否覆盖特殊承诺 |

## 六、签订流程

### 1. 初步沟通需求

用户先明确房屋面积、户型、装修模式、预算范围、风格偏好、入住时间和家庭成员需求。

### 2. 量房

装修公司或设计师上门量房，记录空间尺寸、梁柱位置、门窗位置、上下水、强弱电、燃气、烟道、墙体结构等信息。

### 3. 方案确认

用户应确认平面布局、功能分区、收纳规划、主要材料方向和施工可行性。方案不清楚时，不建议直接签施工合同。

### 4. 报价审核

对报价单逐项审核，重点检查是否漏项、工程量是否明显偏低、材料是否模糊、工艺是否缺失、单价是否异常。

### 5. 合同审核

把合同正文、报价单、材料清单、施工图、付款节点、工期表和保修条款一起审核。

### 6. 补充协议确认

销售口头承诺、赠送项目、特殊优惠、材料升级、工期承诺、零增项承诺等，必须写入补充协议。

### 7. 正式签约付款

确认无误后再签字付款。建议付款到公司账户，并保留合同、发票、收据、转账记录和沟通记录。

### 8. 开工交底

签约后，正式开工前必须现场交底，确认施工范围、水电点位、拆改位置、保护措施、材料进场和验收节点。

## 七、关键标准

### 1. 合同完整性标准

合格的装修合同应至少回答以下问题：

| 问题 | 合同中应体现 |
|---|---|
| 谁施工 | 装修公司主体和项目负责人 |
| 做哪里 | 房屋地址和施工范围 |
| 做什么 | 报价单和工程项目 |
| 用什么 | 材料清单 |
| 怎么做 | 工艺标准和施工图 |
| 多少钱 | 合同金额和计价方式 |
| 怎么付 | 付款节点 |
| 多久做完 | 工期条款 |
| 怎么验 | 验收节点 |
| 坏了谁修 | 保修条款 |
| 违约怎么办 | 违约责任 |

### 2. 报价清晰标准

报价单应做到：

1. 项目完整。
2. 单位明确。
3. 工程量合理。
4. 单价清楚。
5. 材料明确。
6. 工艺明确。
7. 不含项目说明清楚。
8. 增项单价提前约定。

### 3. 付款安全标准

相对稳妥的付款原则：

1. 首付款不宜过高。
2. 每次付款前应对应工程进度。
3. 隐蔽工程验收前不应支付后续大额款项。
4. 竣工尾款应在问题整改后支付。
5. 每次付款都应留凭证。

### 4. 变更管理标准

任何变更应包含：

1. 变更原因。
2. 变更内容。
3. 增减金额。
4. 是否影响工期。
5. 业主确认记录。
6. 装修公司确认记录。

## 八、验收标准

装修合同签订前，可以用以下清单判断是否合格：

| 检查项 | 合格标准 | 风险表现 |
|---|---|---|
| 合同主体 | 公司名称、盖章、收款一致 | 个人收款或主体不明 |
| 施工范围 | 具体到空间和项目 | 只写全屋装修 |
| 报价单 | 项目完整、材料清楚 | 低价漏项、材料模糊 |
| 材料清单 | 品牌型号规格明确 | 只写品牌或写同等档次 |
| 施工图 | 关键图纸已确认 | 只有效果图 |
| 付款节点 | 与验收绑定 | 开工前付大部分 |
| 工期条款 | 起止时间和延期责任清楚 | 只写预计工期 |
| 增减项 | 书面确认后施工 | 口头增项 |
| 验收条款 | 节点验收明确 | 无验收流程 |
| 保修条款 | 范围、期限、响应明确 | 只写质保两年 |
| 违约责任 | 可执行 | 只有原则性表述 |

如果以上关键项缺失较多，不建议直接签约。

## 九、常见问题

### 1. 装修合同签之前最应该看什么？

最应该看合同附件，包括报价单、材料清单、施工图、付款节点、工期表和保修条款。合同正文重要，但很多实际施工问题都藏在附件里。

### 2. 装修公司说先签合同后面再细化报价，可以吗？

不建议。报价、材料、施工范围没有确认前签合同，后期容易出现增项和争议。至少应先确认主要项目、材料标准、付款节点和增减项规则。

### 3. 装修合同里写“材料同等品牌”安全吗？

风险较高。“同等品牌”容易产生解释空间。建议写清楚品牌、型号、规格、等级和替换规则。如果确需替换，应经业主书面确认。

### 4. 销售口头承诺有效吗？

发生纠纷时，口头承诺通常证明难度较高。赠送项目、升级材料、工期承诺、优惠条件、零增项承诺等，都应写入合同或补充协议。

### 5. 合同签了还能改吗？

可以改，但应通过补充协议、变更单或增减项确认单书面确认。不要只在微信里简单说一句就施工，重要变更应明确金额、工期和责任。

### 6. 装修定金和订金有什么区别？

通常“定金”具有担保性质，违约时可能涉及定金罚则；“订金”更偏预付款性质。具体还要结合合同约定和实际交易情况判断。用户付款前应看清收据和合同用词。

### 7. 装修尾款应该什么时候付？

建议在竣工验收完成、问题整改确认、材料和保修资料交付后再支付尾款。不要在明显问题未整改前结清尾款。

### 8. 合同里没有写保修怎么办？

应要求补充保修条款，明确保修范围、期限、响应时间和维修责任。涉及防水、水电、墙面、瓷砖等项目时，保修条款尤其重要。

### 9. 装修公司要求款项转给个人，可以吗？

不建议。大额装修款尽量支付到公司对公账户，并保留转账记录、收据或发票。个人收款可能增加后期维权难度。

### 10. 签合同当天需要带什么？

建议带身份证明、房屋资料、前期沟通记录、预算清单、已确认的报价单、材料清单和需要写入补充协议的承诺事项。

## 十、避坑提醒

1. 不要只看总价，低价合同往往通过漏项、低估工程量、材料模糊来降低表面价格。
2. 不要只看效果图，效果图不能替代施工图和材料清单。
3. 不要相信口头“零增项”，要看报价是否完整、增项规则是否明确。
4. 不要开工前支付大部分款项，付款应与工程进度和验收结果绑定。
5. 不要让合同附件空白，空白处应划掉或写明无内容。
6. 不要接受“同等档次材料”这种模糊表述，应明确替换需业主确认。
7. 不要忽略工期违约责任，只写完工日期不够。
8. 不要把赠品、优惠、升级材料只停留在聊天记录里，应写进补充协议。
9. 不要让未经确认的增项先施工后报价。
10. 不要在问题未整改前结清尾款。

## 十一、案例分析

### 案例一：低价合同后期增项

用户 A 签约时看到某装修公司报价比其他公司低 2 万元，于是快速签约。开工后，装修公司陆续提出墙面找平、防水加强、门洞修补、水电点位增加、垃圾清运等费用。用户认为这些应包含在原合同中，但报价单里确实没有写。

问题分析：

1. 用户只比较总价，没有比较项目完整性。
2. 报价单没有作为审核重点。
3. 合同没有约定增项确认流程。
4. 施工前没有做完整开工交底。

正确做法：

1. 签约前逐项审核报价单。
2. 对低价项目追问是否包含必要工序。
3. 约定未经书面确认的增项不得收费。
4. 把常见增项单价提前写清。

### 案例二：材料只写品牌导致争议

用户 B 合同中写明使用某知名品牌瓷砖，但没有写系列、规格和型号。送货时，用户发现实际瓷砖属于该品牌较低价系列，与前期沟通的效果不一致。装修公司认为合同只写了品牌，已经符合约定。

问题分析：

1. 合同材料描述过于笼统。
2. 用户没有要求材料清单写明型号。
3. 前期沟通没有形成可执行附件。

正确做法：

1. 材料清单写明品牌、型号、规格、颜色、等级、使用区域。
2. 主材选样后拍照确认。
3. 材料进场时对照清单验收。

### 案例三：尾款过早支付导致整改困难

用户 C 在竣工前已支付 95% 合同款，剩余尾款金额很低。竣工验收时发现墙面裂缝、插座不通电、柜门缝隙不均等问题。装修公司整改进度缓慢，用户催促多次无果。

问题分析：

1. 付款比例设置不合理。
2. 尾款约束力不足。
3. 问题整改与付款没有绑定。

正确做法：

1. 付款节点与验收节点绑定。
2. 竣工问题整改完成后再支付尾款。
3. 验收问题形成书面整改清单，明确完成时间。

## 十二、法规依据

装修合同相关问题通常涉及以下依据：

1. 《中华人民共和国民法典》关于合同订立、合同履行、违约责任、承揽合同等规定。
2. 《住宅室内装饰装修管理办法》关于住宅室内装饰装修活动、禁止行为、装修管理等规定。
3. 《消费者权益保护法》关于消费者知情权、公平交易权、依法维权等规定。
4. 国家、地方或行业关于住宅装饰装修工程施工和质量验收的相关标准。
5. 物业服务合同、业主规约、小区装修管理协议中的装修管理要求。

需要注意：具体纠纷处理应结合合同文本、证据材料、当地政策和实际损失判断。本文不能替代律师意见。
