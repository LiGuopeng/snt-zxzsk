# 厨房防水标准

## 一、概述

厨房防水是住宅防水工程中容易被忽略的一部分。相比卫生间，厨房地面长期大面积积水的概率较低，但厨房仍然存在水槽漏水、下水管渗漏、净水器漏水、洗碗机漏水、管道周边渗水、橱柜受潮等风险。

厨房是否做防水、做到什么范围，应结合户型、是否有地漏、是否安装洗碗机和净水设备、橱柜布局、管道位置、楼下空间和当地施工习惯判断。

本文的目标是说明厨房防水的适用场景、重点区域、施工流程和验收标准。

## 二、适用范围

本文适用于以下场景：

1. 新房厨房装修。
2. 二手房厨房翻新。
3. 厨房水电改造后需要防水处理。
4. 安装洗碗机、净水器、小厨宝、垃圾处理器等设备。
5. 用户咨询“厨房要不要做防水”。

## 三、基础知识

### 1. 厨房防水为什么有争议

厨房不像卫生间那样长期淋水，因此有些施工做法不做全厨房防水。但厨房仍然有局部漏水风险，尤其是水槽、下水、管道和设备集中区域。

厨房防水不能简单理解为“必须全做”或“完全不用做”，应结合实际风险判断。

### 2. 厨房常见漏水来源

| 来源 | 风险 |
|---|---|
| 水槽下水 | 接口松动、堵塞、渗水 |
| 水管接头 | 给水接头漏水 |
| 净水器 | 接头漏水、废水管脱落 |
| 洗碗机 | 进水或排水漏水 |
| 小厨宝 | 接头和设备漏水 |
| 地面管道 | 管根或开槽处渗漏 |
| 窗边 | 雨水渗入或墙体返潮 |

## 四、专业知识

### 1. 厨房防水适用场景

| 场景 | 建议 |
|---|---|
| 厨房有地漏 | 建议做地面防水并测试排水 |
| 厨房无地漏 | 重点做水槽和管道区域防水 |
| 二手房翻新 | 建议检查原防水和管道 |
| 安装洗碗机 | 重点关注设备进排水 |
| 水槽下设备多 | 建议加强局部防水和检修 |
| 厨房靠近木地板区域 | 门口和交接处防水要关注 |

### 2. 厨房防水区域明细

| 区域 | 重点 |
|---|---|
| 水槽下方 | 给排水接口、净水设备 |
| 厨房地面 | 管道、地漏、门口 |
| 墙地交接 | 防止水向墙体渗 |
| 管道穿墙穿地 | 管根密封 |
| 橱柜背后 | 防潮和渗漏 |
| 厨房门口 | 防止水外溢到地板 |

### 3. 厨房防水前置条件

| 条件 | 要求 |
|---|---|
| 水电完成 | 水管打压、排水测试完成 |
| 橱柜方案 | 水槽和设备位置明确 |
| 基层处理 | 地面墙面清洁牢固 |
| 管根处理 | 管道周边修补密封 |
| 排水确认 | 有地漏时确认坡度和通水 |

### 4. 厨房防水施工重点

| 项目 | 要点 |
|---|---|
| 基层清理 | 无灰尘、油污、松动物 |
| 管根加强 | 水管、下水管周边重点处理 |
| 水槽墙面 | 水槽周边墙面防潮 |
| 地面防水 | 根据方案和风险确定范围 |
| 门口处理 | 防止水外渗 |
| 成品保护 | 橱柜安装前后注意管道 |

### 5. 厨房防水与橱柜关系

厨房防水与橱柜安装关系密切：

1. 水槽下方应便于检修。
2. 管道接口不要被完全封死。
3. 橱柜板材应避免长期受潮。
4. 安装洗碗机、净水器、小厨宝时应检查接口。
5. 橱柜安装打孔不要破坏水管和防水。

## 六、施工或服务流程

### 1. 确认厨房水电和设备

先确认水槽、净水器、洗碗机、小厨宝、垃圾处理器等设备位置。

### 2. 完成水电验收

给水打压、排水测试合格后再做防水。

### 3. 处理基层和管根

清理基层，修补管道周边和墙地交接处。

### 4. 做防水涂刷

按约定范围涂刷防水，重点加强水槽下方、管根和地面。

### 5. 做必要测试

如厨房有地漏，可结合现场做蓄水或排水测试；无地漏时重点检查管道和接口。

### 6. 拍照留档

记录防水区域、管根、地面和水槽周边处理。

## 七、关键标准

### 1. 合格厨房防水标准

1. 水电验收完成。
2. 水槽和设备位置明确。
3. 管根和墙地交接处理到位。
4. 防水范围与约定一致。
5. 有地漏时排水顺畅。
6. 橱柜安装前防水和管线记录完整。

### 2. 高风险表现

1. 厨房设备未定就施工。
2. 水槽下管道不检修。
3. 水管未打压。
4. 洗碗机进排水未确认。
5. 防水区域不清楚。
6. 橱柜安装后无法检查漏水。

## 八、验收标准

| 检查项 | 合格标准 | 风险表现 |
|---|---|---|
| 水电 | 打压和排水测试完成 | 后期漏水 |
| 管根 | 密封和加强 | 管根渗漏 |
| 水槽区 | 防水防潮处理 | 橱柜受潮 |
| 地面 | 与约定范围一致 | 漏刷 |
| 门口 | 防止水外渗 | 地板受潮 |
| 记录 | 照片完整 | 责任不清 |

## 九、常见问题

### 1. 厨房一定要做防水吗？

不一定所有厨房都必须做全地面防水，但建议根据是否有地漏、是否安装洗碗机净水器、水槽下设备数量和楼下情况判断。水槽、管道和设备区域建议重点处理。

### 2. 厨房没有地漏，做防水有用吗？

有一定作用，但如果没有地漏，大量漏水仍然需要排出路径。防水不能替代排水，应同时关注管道质量和设备接口。

### 3. 厨房防水需要闭水试验吗？

如果厨房有地漏和可蓄水条件，可以根据现场做闭水或排水测试；无地漏时更应重点检查管道接口和设备连接。

### 4. 橱柜安装后怎么防止漏水？

水槽、净水器、洗碗机、小厨宝等设备安装后，应做通水测试，并检查接口是否渗漏。

## 十、避坑提醒

1. 不要只问厨房要不要防水，要先看用水设备。
2. 不要水管未打压就做防水。
3. 不要忽略水槽下方。
4. 不要洗碗机净水器接口不检查。
5. 不要管道被橱柜完全封死无法检修。
6. 不要以为做了防水就不需要排水。

## 十一、案例分析

### 案例一：净水器接头漏水导致橱柜受潮

用户 A 厨房安装净水器后，水槽下接头轻微渗漏，长期未发现，导致橱柜底板受潮变形。

问题分析：

1. 水槽下设备多，检修不便。
2. 安装后未做通水检查。
3. 橱柜内部防潮不足。

正确做法：

1. 水槽下设备接口安装后测试。
2. 保留检修空间。
3. 水槽区重点防潮防水。

### 案例二：厨房门口水外溢影响地板

用户 B 厨房地面发生漏水，水从门口流到餐厅木地板区域，造成地板起翘。

问题分析：

1. 厨房门口防水和挡水不足。
2. 厨房没有有效排水。
3. 地板区域未考虑水外溢风险。

正确做法：

1. 厨房门口和相邻地面重点处理。
2. 检查水槽和设备接口。
3. 有地漏时保证排水通畅。

## 十二、法规依据

厨房防水涉及住宅装修质量、给排水安全、合同责任和相邻关系。通常可参考：

1. 住宅装饰装修工程施工和验收相关标准。
2. 建筑防水和给排水施工相关规范。
3. 装修合同、防水材料清单、水电图、验收记录和现场照片。

具体施工范围应结合合同约定、当地习惯和现场条件确定。
