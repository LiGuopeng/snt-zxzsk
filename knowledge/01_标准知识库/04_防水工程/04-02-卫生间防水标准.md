# 卫生间防水标准

## 一、概述

卫生间防水是家庭装修防水工程中最重要、最容易发生渗漏纠纷的部分。卫生间长期用水，包含淋浴、马桶、洗手盆、地漏、管道、墙地交接、门口挡水等多个风险点，一旦防水不到位，可能造成楼下渗漏、墙面返潮、门口发霉、瓷砖空鼓和邻里赔偿。

卫生间防水的核心不是简单刷一遍防水涂料，而是要做好基层处理、节点加强、墙地面涂刷、闭水试验、验收记录和后续保护。

本文的目标是系统说明卫生间防水的区域、高度、节点、流程、验收和常见风险。

## 二、适用范围

本文适用于以下场景：

1. 新房卫生间装修防水施工。
2. 二手房卫生间翻新重做防水。
3. 卫生间水电改造后重新做防水。
4. 干湿分离、智能马桶、浴缸、淋浴房等卫生间改造。
5. 用户准备做闭水试验和防水验收。
6. 后续 AI 客服回答“卫生间防水怎么做”等问题时使用。

## 三、基础知识

### 1. 卫生间为什么必须重点做防水

卫生间风险高，因为：

1. 用水频率高。
2. 地面长期潮湿。
3. 管道和地漏多。
4. 墙地交接节点多。
5. 淋浴区水量大。
6. 防水层后期被瓷砖覆盖，维修困难。

### 2. 卫生间防水包括哪些位置

| 位置 | 防水重点 |
|---|---|
| 地面 | 全面防水，重点管根和地漏 |
| 淋浴区墙面 | 墙面防水重点区域 |
| 洗手盆墙面 | 防止墙体返潮 |
| 马桶周边 | 管根和地面防水 |
| 门口 | 防止水向外渗 |
| 阴阳角 | 防裂和防渗 |
| 管道根部 | 渗漏高发点 |

## 四、专业知识

### 1. 卫生间防水前置条件

| 条件 | 要求 |
|---|---|
| 水电完成 | 水管打压、排水测试完成 |
| 基层检查 | 无大面积空鼓、起砂、裂缝 |
| 地漏位置 | 已确认排水位置 |
| 管根处理 | 管道周边密封和修补 |
| 坡度规划 | 地面排水方向明确 |
| 墙面基层 | 牢固、清洁、无松动 |

水电未验收、基层不合格时，不建议直接做防水。

### 2. 卫生间防水区域明细

| 区域 | 施工重点 | 风险 |
|---|---|---|
| 淋浴区 | 墙面和地面重点防水 | 墙体返潮、楼下渗漏 |
| 马桶区 | 排污管周边 | 管根渗漏、反味 |
| 洗手盆区 | 墙面和地面 | 墙面潮湿、柜体受潮 |
| 门口 | 门槛石和挡水 | 水外渗到干区 |
| 干区 | 地面和局部墙面 | 局部积水渗漏 |

### 3. 防水高度明细

卫生间防水高度应结合设计方案、当地施工习惯、材料要求和合同约定确定。重点原则：

1. 地面必须整体防水。
2. 淋浴区墙面应重点加高。
3. 洗手盆、马桶周边墙面应根据用水情况做防水。
4. 门口和墙地交接处不能漏刷。

防水高度应在合同、报价或施工交底中明确，避免只靠口头说法。

### 4. 关键节点处理明细

| 节点 | 处理重点 |
|---|---|
| 管根 | 堵漏、密封、加强涂刷 |
| 地漏 | 周边找坡、密封、防水加强 |
| 阴阳角 | 圆弧或加强处理 |
| 门口 | 门槛石、挡水和外侧防渗 |
| 墙地交接 | 涂刷连续，不漏刷 |
| 开槽处 | 水电开槽修补后再防水 |
| 淋浴墙面 | 防水连续完整 |

### 5. 卫生间防水施工流程

| 步骤 | 内容 | 重点 |
|---|---|---|
| 基层检查 | 查空鼓、裂缝、起砂 | 不合格先修 |
| 基层清理 | 清理灰尘和杂物 | 保证附着 |
| 节点加强 | 管根、地漏、阴阳角、门口 | 防渗重点 |
| 第一遍涂刷 | 均匀涂刷 | 不漏刷 |
| 第二遍涂刷 | 交叉涂刷更稳妥 | 覆盖完整 |
| 干燥养护 | 等待防水成膜 | 未干不施工 |
| 闭水试验 | 蓄水观察 | 楼下确认 |
| 保护施工 | 贴砖前保护防水层 | 防止破坏 |

### 6. 闭水试验明细

| 项目 | 要求 |
|---|---|
| 试验前 | 防水层干燥成膜 |
| 蓄水区域 | 卫生间地面 |
| 观察位置 | 楼下顶面、管根、墙角 |
| 记录 | 开始结束时间、照片 |
| 结果 | 无渗漏后再贴砖 |

闭水试验不能只在自家看水位，还应关注楼下是否渗漏。

### 7. 卫生间防水与贴砖关系

防水通过后，后续瓦工仍可能破坏防水层。

注意事项：

1. 贴砖前不要用尖锐工具破坏防水。
2. 地面防水层上施工要注意保护。
3. 门口、地漏、管根周边施工要谨慎。
4. 如发现防水层破损，应先修补再继续。

## 六、施工或服务流程

### 1. 完成水电验收

确认水管打压、排水通水、电路检查完成。

### 2. 处理基层

墙地面清洁、牢固、无明显空鼓裂缝。

### 3. 做节点加强

管根、地漏、阴阳角、门口和墙地交接处重点处理。

### 4. 涂刷防水

按材料要求分遍涂刷，保证均匀、连续、不漏刷。

### 5. 干燥养护

防水层干燥成膜后再进行闭水试验。

### 6. 闭水验收

蓄水并观察楼下是否渗漏，记录结果。

### 7. 后续保护

贴砖和安装过程中避免破坏防水层。

## 七、关键标准

### 1. 合格卫生间防水标准

1. 水电验收完成。
2. 基层处理合格。
3. 地面防水完整。
4. 淋浴区墙面重点防水。
5. 管根、地漏、阴阳角、门口加强。
6. 防水层干燥成膜。
7. 闭水试验合格。
8. 照片和记录完整。

### 2. 高风险表现

1. 基层未处理直接刷防水。
2. 管根地漏未加强。
3. 门口防水忽略。
4. 防水高度不清。
5. 闭水时间不足或不做。
6. 未通知楼下确认。
7. 防水未干就贴砖。
8. 贴砖破坏防水层。

## 八、验收标准

| 检查项 | 合格标准 | 风险表现 |
|---|---|---|
| 基层 | 平整牢固清洁 | 防水脱落 |
| 地面 | 全面涂刷 | 楼下渗漏 |
| 墙面 | 重点区域高度明确 | 墙体返潮 |
| 管根 | 加强处理 | 管根漏水 |
| 地漏 | 周边加强 | 地漏渗漏 |
| 门口 | 挡水防渗 | 水外溢 |
| 闭水 | 无渗漏 | 贴砖后返工 |
| 记录 | 照片和结果完整 | 责任不清 |

## 九、常见问题

### 1. 卫生间防水只做地面可以吗？

不建议只做地面。淋浴区、洗手盆周边、墙地交接和门口等位置也需要根据用水情况做墙面防水。

### 2. 闭水试验一定要通知楼下吗？

建议通知楼下或物业配合查看，尤其是新房和二手房。只看自家水位不够直观。

### 3. 卫生间防水做完多久能贴砖？

应等防水层干燥成膜、闭水试验合格后再贴砖。具体时间根据材料说明、温湿度和现场情况判断。

### 4. 防水做好后还能打孔吗？

应尽量避免在防水区域随意打孔。洁具安装需要打孔时，应注意密封处理。

## 十、避坑提醒

1. 不要水电没验收就做防水。
2. 不要基层起砂空鼓仍刷防水。
3. 不要只刷地面不管墙面。
4. 不要忽略门口和管根。
5. 不要防水未干就闭水或贴砖。
6. 不要不做闭水试验。
7. 不要闭水不看楼下。
8. 不要贴砖施工破坏防水。

## 十一、案例分析

### 案例一：门口防水不足导致外侧返潮

用户 A 卫生间闭水试验没有明显渗漏，但入住后门口外侧地板发黑返潮。

问题分析：

1. 门口挡水和防水处理不足。
2. 淋浴水可能长期向外渗。
3. 闭水试验未覆盖真实使用场景。

正确做法：

1. 门口和门槛石重点防水。
2. 淋浴区做好挡水。
3. 防水验收时检查门口节点。

### 案例二：地漏周边渗漏到楼下

用户 B 卫生间防水整体涂刷，但地漏周边没有加强，入住后楼下顶面出现水印。

问题分析：

1. 地漏节点处理不足。
2. 排水周边密封不严。
3. 防水验收不细。

正确做法：

1. 地漏周边做加强处理。
2. 闭水试验重点观察楼下。
3. 贴砖时保护地漏周边防水。

## 十二、法规依据

卫生间防水涉及住宅装修质量、给排水、防水工程、相邻关系和合同责任。通常可参考：

1. 住宅装饰装修工程施工和验收相关标准。
2. 建筑防水工程相关国家、地方或行业规范。
3. 《住宅室内装饰装修管理办法》中关于装修活动和防水层保护的规定。
4. 装修合同、防水材料清单、闭水试验记录、验收单和现场照片。

具体责任应结合合同约定、闭水记录和实际渗漏原因判断。
