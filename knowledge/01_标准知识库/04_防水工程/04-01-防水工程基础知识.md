# 防水工程基础知识

## 一、概述

防水工程是住宅装修中最重要的隐蔽工程之一，主要用于防止卫生间、厨房、阳台等用水区域发生渗漏。防水一旦施工完成并被瓷砖、地面、洁具、柜体覆盖，后期维修通常需要拆砖、拆洁具、重新做防水，成本高且容易引发邻里纠纷。

防水工程不是简单“刷一层防水涂料”，而是包含基层处理、节点加强、防水涂刷、干燥养护、闭水试验、验收记录和后续保护等一整套流程。

防水工程的目标是：

1. 阻止用水区域渗漏到楼下或相邻空间。
2. 保护墙地面基层。
3. 降低后期返工和邻里纠纷风险。
4. 为瓦工贴砖和洁具安装创造可靠基础。

## 二、适用范围

本文适用于以下场景：

1. 新房装修中的卫生间、厨房、阳台防水。
2. 二手房翻新中的旧防水拆除和重做。
3. 水电改造后需要重新做防水的空间。
4. 用户准备进行闭水试验和防水验收。
5. 装修公司项目经理、瓦工、防水工进行施工说明时使用。
6. 后续 AI 客服回答“防水怎么做、防水验收看什么”等问题时使用。

本文主要面向住宅室内防水。屋面、地下室、外墙、露台等特殊防水工程应由专业防水单位结合具体结构和规范处理。

## 三、基础知识

### 1. 家装防水主要做哪些区域

| 区域 | 是否常做防水 | 说明 |
|---|---|---|
| 卫生间 | 必须重点做 | 淋浴、地漏、管根、墙地面风险高 |
| 厨房 | 建议根据情况做 | 水槽、管道、地面用水风险 |
| 阳台 | 建议重点关注 | 洗衣机、地漏、雨水、晾晒 |
| 洗衣区 | 建议做 | 洗衣机排水和溢水风险 |
| 露台 | 需专业防水 | 风吹日晒，要求更高 |

### 2. 防水工程包括什么

| 环节 | 内容 |
|---|---|
| 基层检查 | 空鼓、裂缝、起砂、积水、坡度 |
| 基层处理 | 清理、找平、修补、阴阳角处理 |
| 节点加强 | 管根、地漏、阴阳角、门槛石 |
| 防水涂刷 | 按要求涂刷防水材料 |
| 干燥养护 | 等待防水层成膜 |
| 闭水试验 | 检查地面防水是否渗漏 |
| 验收记录 | 拍照、记录、楼下确认 |
| 成品保护 | 贴砖前防止破坏防水层 |

### 3. 防水为什么容易出问题

防水问题常见原因：

1. 基层未处理好。
2. 管根、地漏、阴阳角节点处理不到位。
3. 防水高度不足。
4. 涂刷遍数或厚度不足。
5. 闭水试验未做或时间不足。
6. 防水层未干就施工。
7. 贴砖施工破坏防水层。
8. 后期洁具安装打孔破坏防水。

## 四、专业知识

### 1. 防水区域明细

| 区域 | 重点位置 | 风险 |
|---|---|---|
| 卫生间地面 | 地漏、管根、门口 | 漏到楼下 |
| 卫生间墙面 | 淋浴区、洗手盆背面 | 墙体返潮 |
| 厨房地面 | 水槽下方、管道周边 | 渗漏或橱柜受潮 |
| 阳台地面 | 洗衣机、地漏、窗边 | 渗漏和返潮 |
| 管道周边 | 穿楼板管道 | 管根渗漏 |
| 门口位置 | 门槛石、挡水 | 水外溢到干区 |

### 2. 防水基层处理明细

| 检查项 | 合格要求 | 风险表现 |
|---|---|---|
| 基层清洁 | 无灰尘、油污、松散物 | 防水附着差 |
| 平整度 | 无明显坑洼和尖锐凸起 | 涂膜厚薄不均 |
| 空鼓裂缝 | 已修补 | 防水层开裂 |
| 起砂 | 已加固或修补 | 防水脱落 |
| 阴阳角 | 做圆弧或加强处理 | 节点开裂 |
| 管根 | 密封和加强 | 管根渗漏 |

### 3. 防水节点明细

| 节点 | 处理重点 |
|---|---|
| 地漏周边 | 密封、加强、防止积水 |
| 管根 | 堵漏、密封、防水加强 |
| 阴阳角 | 防裂加强 |
| 门槛石 | 防止水向外渗 |
| 墙地交接 | 涂刷连续 |
| 淋浴区墙面 | 防水高度和涂刷完整 |
| 下水管周边 | 防水层连续 |

### 4. 防水高度明细

不同区域防水高度应结合当地施工习惯、产品要求和设计方案确定。常见关注点如下：

| 区域 | 高度关注 |
|---|---|
| 卫生间地面 | 全地面 |
| 淋浴区墙面 | 通常应重点加高 |
| 洗手盆墙面 | 防止墙面返潮 |
| 厨房墙面 | 水槽附近重点关注 |
| 阳台墙面 | 洗衣机、水池、窗边重点关注 |

防水高度不能只听口头说法，应写入报价、施工说明或验收记录。

### 5. 防水施工流程明细

| 步骤 | 内容 | 重点 |
|---|---|---|
| 基层检查 | 查空鼓、裂缝、起砂 | 不合格先处理 |
| 基层清理 | 清理灰尘和杂物 | 保证附着 |
| 节点处理 | 管根、地漏、阴阳角加强 | 防水重点 |
| 第一遍涂刷 | 均匀涂刷 | 不漏刷 |
| 第二遍涂刷 | 与第一遍方向交叉更稳妥 | 保证覆盖 |
| 干燥养护 | 等待成膜 | 未干不施工 |
| 闭水试验 | 蓄水观察 | 检查渗漏 |
| 验收记录 | 拍照、楼下确认 | 留证据 |
| 保护施工 | 避免后续破坏 | 瓦工注意 |

### 6. 闭水试验基础

闭水试验是检查地面防水是否渗漏的重要方法。通常在防水层干燥后进行，蓄水一定时间，并观察楼下顶面、管根和墙角是否渗漏。

闭水试验应重点记录：

1. 开始时间。
2. 结束时间。
3. 蓄水区域。
4. 水位情况。
5. 楼下检查结果。
6. 现场照片。

### 7. 防水和水电的关系

水电施工会影响防水：

| 水电项目 | 防水风险 |
|---|---|
| 地面开槽 | 可能破坏基层 |
| 墙面开槽 | 影响墙面防水连续 |
| 管道穿楼板 | 管根渗漏高发 |
| 地漏改造 | 周边防水必须加强 |
| 排水移位 | 坡度和防水都需重新考虑 |

水电完成并验收后，才能进入防水施工。水电未验收不建议直接做防水。

## 六、施工或服务流程

### 1. 水电验收完成

确认水管打压、排水测试、电路检查完成，水电照片已保存。

### 2. 基层处理

清理基层，修补空鼓、裂缝、起砂和管根问题。

### 3. 节点加强

对管根、地漏、阴阳角、墙地交接和门口位置做加强处理。

### 4. 涂刷防水

按材料要求分遍涂刷，保证不漏刷、不堆积、不起皮。

### 5. 干燥养护

等待防水层成膜，未干燥前避免踩踏和施工。

### 6. 闭水试验

蓄水并观察是否渗漏，必要时通知楼下共同确认。

### 7. 验收和保护

验收通过后拍照记录，后续贴砖施工注意保护防水层。

## 七、关键标准

### 1. 合格防水工程标准

1. 基层处理合格。
2. 节点加强到位。
3. 防水区域和高度明确。
4. 涂刷均匀完整。
5. 防水层干燥成膜。
6. 闭水试验合格。
7. 验收照片和记录完整。
8. 后续施工保护到位。

### 2. 高风险表现

1. 基层未处理直接刷防水。
2. 管根、地漏不加强。
3. 防水高度不清楚。
4. 防水涂刷偷工减料。
5. 未干就贴砖。
6. 不做闭水试验。
7. 闭水试验不通知楼下。
8. 贴砖破坏防水层。

## 八、验收标准

| 检查项 | 合格标准 | 风险表现 |
|---|---|---|
| 基层 | 平整、牢固、清洁 | 防水脱落 |
| 节点 | 管根地漏阴阳角加强 | 节点渗漏 |
| 高度 | 与约定一致 | 墙面返潮 |
| 涂刷 | 均匀无漏刷 | 局部渗漏 |
| 干燥 | 成膜后再试水 | 防水失效 |
| 闭水 | 无渗漏 | 漏到楼下 |
| 记录 | 照片和结果完整 | 后期责任不清 |

## 九、常见问题

### 1. 防水是不是刷得越厚越好？

不是。防水应按产品要求和施工工艺涂刷，过薄可能失效，过厚也可能开裂或干燥不良。

### 2. 卫生间防水必须做闭水试验吗？

建议必须做。闭水试验是发现地面防水渗漏的重要方式。

### 3. 厨房一定要做防水吗？

不同地区和做法不同，但厨房有水槽、管道和橱柜，建议根据用水情况和装修方案考虑防水，尤其水槽周边和地面。

### 4. 阳台要做防水吗？

如果阳台有洗衣机、地漏、洗衣池、雨水或晾晒用水，建议重点做防水和排水。

### 5. 防水做好后为什么还会漏？

可能是基层问题、节点处理不到位、闭水未做、后续施工破坏、管道漏水或门口挡水处理不足。

## 十、避坑提醒

1. 不要水电未验收就做防水。
2. 不要基层不处理就刷防水。
3. 不要只刷地面忽略墙地交接。
4. 不要管根地漏不加强。
5. 不要防水未干就贴砖。
6. 不要不做闭水试验。
7. 不要闭水不通知楼下确认。
8. 不要贴砖时破坏防水层。
9. 不要漏水只做表面修补。

## 十一、案例分析

### 案例一：管根未加强导致漏水

用户 A 卫生间防水施工时地面整体刷了防水，但管根周边没有重点加强。入住后楼下卫生间顶面出现渗水。

问题分析：

1. 防水节点处理不足。
2. 管根是渗漏高发点。
3. 闭水试验记录不完整。

正确做法：

1. 管根、地漏、阴阳角做加强处理。
2. 防水完成后做闭水试验。
3. 楼下确认后再贴砖。

### 案例二：闭水合格但入住后漏水

用户 B 卫生间闭水试验合格，但入住后淋浴时门口外侧返潮。

问题分析：

1. 闭水主要验证地面整体防水，不代表所有使用场景都无风险。
2. 门口挡水或门槛石处理可能不足。
3. 淋浴区墙面或门口节点可能存在问题。

正确做法：

1. 门口和门槛石重点防水。
2. 淋浴区墙面防水高度足够。
3. 贴砖和安装时保护防水层。

## 十二、法规依据

防水工程涉及住宅装修质量、相邻关系、合同履行和渗漏责任。通常可参考：

1. 住宅装饰装修工程施工和验收相关标准。
2. 建筑防水工程相关国家、地方或行业规范。
3. 《住宅室内装饰装修管理办法》中关于装修活动和防水层保护的规定。
4. 装修合同、防水材料清单、施工记录、闭水试验记录和验收单。

具体责任应结合合同约定、施工记录、闭水结果和现场情况判断。
