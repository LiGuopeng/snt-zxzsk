# 防水验收标准

## 一、概述

防水验收是防水工程交付前最关键的质量控制环节。它不是简单看“有没有刷蓝色或绿色涂料”，而是要检查材料、基层、节点、高度、涂膜、闭水、成品保护和资料留档。

防水属于隐蔽工程，一旦贴砖后再发现问题，维修通常涉及拆砖、重做防水、重新铺贴、赔偿楼下损失和邻里协调。因此防水验收必须在贴砖前完成，并形成照片、视频和书面记录。

## 二、适用范围

本文适用于：

1. 卫生间防水验收。
2. 厨房防水验收。
3. 阳台和洗衣区防水验收。
4. 二手房翻新防水验收。
5. 装修公司、监理、业主共同验收。
6. AI 客服回答“防水怎么验收”等问题。

## 三、基础知识

### 1. 防水验收分为哪些层次

| 验收层次 | 检查内容 | 目的 |
|---|---|---|
| 材料验收 | 品牌、型号、批次、保质期 | 防止材料替换 |
| 基层验收 | 平整、牢固、干净、无裂缝 | 保证防水附着 |
| 节点验收 | 管根、地漏、阴阳角、门口 | 控制漏水高发点 |
| 涂膜验收 | 完整、均匀、无漏刷 | 保证防水连续性 |
| 高度验收 | 墙面上返和淋浴区高度 | 防止墙面返潮 |
| 闭水验收 | 蓄水观察和楼下检查 | 验证防水效果 |
| 资料验收 | 照片、记录、签字 | 明确责任 |

### 2. 防水验收应在什么时候做

1. 材料进场时做材料验收。
2. 基层处理后、防水施工前做基层验收。
3. 节点加强后做节点验收。
4. 防水完成并干燥后做外观验收。
5. 贴砖前做闭水验收。
6. 贴砖和洁具安装后关注二次渗漏风险。

## 四、专业知识

### 1. 防水验收总表

| 项目 | 验收标准 | 不合格风险 |
|---|---|---|
| 材料 | 与合同一致，在保质期内 | 材料降级、假冒 |
| 基层 | 坚实平整，无起砂空鼓 | 起皮、脱层、开裂 |
| 管根 | 密实、固定、加强 | 管根渗漏 |
| 地漏 | 周边密实，坡向合理 | 地漏周边漏水或积水 |
| 阴阳角 | 加强处理，无裂缝 | 墙地交接渗漏 |
| 墙面高度 | 达到约定和区域要求 | 墙面返潮 |
| 涂膜 | 连续均匀，无漏刷起皮 | 防水层失效 |
| 闭水 | 无楼下渗漏 | 后期漏水纠纷 |
| 成品保护 | 后续未破坏 | 贴砖后漏水 |

### 2. 各区域验收重点

| 区域 | 验收重点 |
|---|---|
| 卫生间地面 | 闭水、地漏、管根、门口止水 |
| 卫生间淋浴区 | 墙面高度、墙角、花洒墙面 |
| 卫生间干区 | 门口、洗手盆墙面、地面上返 |
| 厨房 | 水槽下方、地漏、管道根部 |
| 阳台 | 洗衣机地漏、外窗边、排水坡度 |
| 二手房 | 旧基层、旧管根、裂缝和历史渗漏点 |

### 3. 防水高度验收明细

| 区域 | 建议验收关注点 |
|---|---|
| 卫生间地面 | 地面整体满做并上返墙面 |
| 淋浴区墙面 | 高度应满足长期淋水需求 |
| 非淋浴墙面 | 按合同和当地习惯执行 |
| 洗手盆墙面 | 注意水汽和溅水区域 |
| 厨房墙面 | 水槽周边重点关注 |
| 阳台墙脚 | 地面上返和墙脚防潮 |

具体高度应以合同、设计、地方标准和项目要求为准，验收时要避免“口头说做了”，应通过弹线、卷尺和照片确认。

### 4. 闭水验收明细

| 项目 | 要求 |
|---|---|
| 闭水区域 | 卫生间、可蓄水阳台等 |
| 闭水前状态 | 防水层干燥完整 |
| 地漏封堵 | 封堵可靠，不破坏地漏 |
| 水位记录 | 起始水位拍照或标记 |
| 观察时间 | 按项目要求持续观察 |
| 楼下检查 | 查看顶面、管根、墙角 |
| 结果记录 | 有照片、视频或书面确认 |
| 失败处理 | 修补后重新闭水 |

### 5. 材料验收明细表

| 验收项 | 合格标准 | 不合格处理 |
|---|---|---|
| 品牌型号 | 与合同、报价单一致 | 暂停使用，要求说明或更换 |
| 包装状态 | 未开封、无破损 | 拍照留证，拒绝异常材料 |
| 生产日期 | 在保质期内 | 过期材料不得使用 |
| 适用范围 | 适合厨卫或对应区域 | 不匹配时更换 |
| 施工说明 | 配比、遍数、干燥时间明确 | 要求按说明施工 |
| 辅材配置 | 有堵漏、加强布等 | 补齐后再施工 |

### 6. 基层验收明细表

| 验收项 | 合格表现 | 风险 |
|---|---|---|
| 平整度 | 无明显坑洼和积水 | 防水厚薄不均 |
| 强度 | 不起砂、不松散 | 防水层脱落 |
| 空鼓 | 无明显空鼓 | 后期开裂 |
| 裂缝 | 裂缝已修补 | 防水层被拉裂 |
| 管根 | 固定牢靠、周边密实 | 管根渗漏 |
| 阴阳角 | 可做圆弧或加强 | 墙角开裂 |
| 清洁度 | 无灰尘、油污、浮浆 | 粘结不牢 |

### 7. 节点验收明细表

| 节点 | 验收标准 | 必拍照片 |
|---|---|---|
| 管根 | 堵漏密实，防水加强覆盖 | 管根近照 |
| 地漏 | 周边密实，防水到口 | 地漏周边近照 |
| 阴角 | 加强连续，无开裂 | 墙地交接近照 |
| 阳角 | 无破损和薄刷 | 阳角近照 |
| 门口 | 有上返、翻边或止水措施 | 门口整体和细部 |
| 管槽 | 回填密实后做防水 | 管槽修补照 |

### 8. 高度验收记录表

| 区域 | 应记录内容 | 验收方法 |
|---|---|---|
| 淋浴区 | 防水高度、墙面范围 | 卷尺测量加照片 |
| 非淋浴区 | 墙面上返高度 | 弹线和测量 |
| 洗手盆墙 | 溅水区域高度 | 对照设计和合同 |
| 厨房水槽墙 | 水槽周边高度 | 现场测量 |
| 阳台墙脚 | 地面上返高度 | 测量和拍照 |
| 门口 | 外翻或止水高度 | 近照记录 |

### 9. 不合格整改流程

1. 标记不合格位置。
2. 暂停进入下一工序，尤其不能贴砖。
3. 判断问题属于材料、基层、节点、高度还是闭水失败。
4. 要求施工方提出整改方案。
5. 整改过程拍照留档。
6. 整改完成后重新验收。
7. 涉及闭水失败的，必须重新闭水。
8. 复验通过后再签字确认。

## 七、关键标准

1. 防水材料与合同一致。
2. 基层合格后再做防水。
3. 防水层连续完整，没有漏刷、起皮、开裂。
4. 管根、地漏、阴阳角、门口为重点验收位置。
5. 防水高度符合合同和区域需求。
6. 闭水试验通过后才能进入贴砖。
7. 验收过程必须留照片和记录。
8. 发现问题必须整改并复验，不能带病进入下一工序。

## 八、验收标准

### 1. 合格标准

| 项目 | 合格表现 |
|---|---|
| 材料 | 品牌型号清楚，与合同一致 |
| 基层 | 无起砂、空鼓、明显裂缝 |
| 节点 | 加强明显，覆盖完整 |
| 涂膜 | 均匀、连续、无破损 |
| 高度 | 达到约定要求 |
| 闭水 | 楼下无渗漏，自家无外溢 |
| 资料 | 照片、视频、记录完整 |

### 2. 不合格表现

1. 材料型号不明或与合同不一致。
2. 防水层局部起皮、开裂、露底。
3. 管根、地漏周边没有加强。
4. 墙面防水高度明显不足。
5. 闭水时楼下出现水印、滴水或潮湿。
6. 门口向外渗水或相邻空间返潮。
7. 施工方拒绝闭水或拒绝留档。

## 九、常见问题

### 1. 防水验收只看闭水就行吗？

不行。闭水很重要，但还要看材料、基层、节点、高度和成品保护。闭水主要验证地面蓄水状态，不能替代全过程验收。

### 2. 墙面防水怎么验收？

墙面重点看高度、涂刷是否连续、是否漏刷、是否起皮，以及淋浴区墙面是否重点处理。墙面通常不能用闭水完全验证。

### 3. 楼下没人配合闭水怎么办？

应尽量通过物业联系楼下。如果无法进入，也要保留闭水时间、水位变化、自家门口和相邻墙面的记录，但楼下确认会更有利于责任判断。

### 4. 闭水失败后可以局部补一下吗？

要先查明渗漏位置和原因。轻微节点问题可局部修补，但如果基层或大面积防水有问题，应扩大处理范围，修补后必须重新闭水。

## 十、避坑提醒

1. 不要让施工方在未验收前贴砖。
2. 不要只拍整体照片，管根和地漏要近距离拍。
3. 不要接受“我们一直这么做”的口头解释。
4. 不要忽略门口和墙脚外渗。
5. 不要闭水刚开始就草率判定合格。
6. 不要闭水失败后不复验。
7. 不要把验收记录只放在聊天记录里，关键资料要整理保存。

## 十一、案例分析

### 案例一：只做闭水，忽略墙面高度

用户卫生间地面闭水通过，但淋浴区墙面防水高度不足。入住半年后，淋浴墙背面衣柜返潮发霉。  

分析：闭水不能验证墙面长期淋水风险，墙面高度和涂刷范围必须单独验收。

### 案例二：验收通过后无照片留档

防水验收时口头通过，没有照片和记录。后期楼下漏水，施工方称是业主后期安装破坏，业主难以证明防水交付状态。  

分析：隐蔽工程必须留档，照片、视频和验收记录是后续责任判断的重要依据。

## 十二、法规依据

防水验收应结合住宅装饰装修工程施工规范、建筑防水工程质量验收要求、地方住宅装修管理规定以及双方合同约定执行。涉及漏水赔偿和维修责任时，应以合同、验收记录、现场鉴定和相关法律规定综合判断。

## 十三、用户咨询与AI回复模板

### 咨询一：防水验收我应该怎么做？

建议按七步验收：先核对材料，再看基层，再看管根地漏和阴阳角，再量墙面高度，再看涂膜完整性，然后做闭水试验，最后拍照并形成验收记录。闭水通过后再贴砖。

### 咨询二：防水验收发现漏水怎么办？

不要继续贴砖。应先排水，查楼下渗漏位置，对照自家管根、地漏、墙角和门口，找到原因后修补或重做，干燥后重新闭水，复验通过再进入下一步。

### 咨询三：装修公司不让拍照正常吗？

不正常。防水是隐蔽工程，业主拍摄材料、节点、防水完成和闭水结果属于合理留档。拒绝拍照会增加后期维权风险。

### 咨询四：防水验收不合格，可以先贴砖后补吗？

不建议。防水属于隐蔽工程，贴砖后再补会增加拆除成本和责任争议。发现材料、基层、节点、高度或闭水问题，应先整改并复验，通过后再贴砖。

### 咨询五：验收记录要写多详细？

至少要写清验收区域、材料品牌型号、施工日期、防水高度、闭水起止时间、楼下检查结果、参与人员和验收结论。关键位置照片要同步保存。
