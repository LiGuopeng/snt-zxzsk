# 闭水试验

## 一、概述

闭水试验是防水工程完成后、贴砖前用于检查地面防水是否渗漏的重要验收方法。它通常用于卫生间、阳台等可蓄水区域，通过蓄水观察一定时间，检查楼下顶面、管根、墙角和相邻空间是否出现渗漏。

闭水试验不是形式流程，而是防水工程最关键的验收动作之一。如果不做闭水试验就贴砖，后期发现漏水时往往需要拆砖、重做防水、赔偿楼下损失，维修成本和纠纷风险都很高。

闭水试验的目标是：

1. 在贴砖前发现防水渗漏。
2. 验证地面防水和关键节点效果。
3. 为后续施工和责任判断留下记录。
4. 降低入住后漏水和邻里纠纷风险。

## 二、适用范围

本文适用于以下场景：

1. 卫生间防水完成后验收。
2. 阳台或洗衣区防水完成后验收。
3. 二手房翻新重做防水后检查。
4. 用户担心楼下漏水或防水质量。
5. 后续 AI 客服回答“闭水试验怎么做”等问题时使用。

厨房是否做闭水试验应结合是否有地漏、是否具备蓄水条件和当地施工习惯判断。

## 三、基础知识

### 1. 什么是闭水试验

闭水试验是指在防水层完成并干燥后，将地面蓄一定深度的水，保持一段时间，通过观察水位变化和楼下是否渗漏来检查防水效果。

### 2. 闭水试验主要检查什么

| 检查内容 | 说明 |
|---|---|
| 地面防水 | 是否渗到楼下 |
| 管根节点 | 管道周边是否渗漏 |
| 地漏周边 | 地漏口是否渗漏 |
| 墙地交接 | 墙角是否渗水 |
| 门口位置 | 是否向外渗 |
| 楼下顶面 | 是否有水印或滴水 |

### 3. 闭水试验不能证明什么

闭水试验主要验证地面蓄水状态下的防水效果，但不能完全证明：

1. 墙面淋水长期不渗。
2. 后续贴砖不会破坏防水。
3. 洁具安装后不会漏水。
4. 管道本身不会渗漏。
5. 门口挡水一定合格。

因此闭水试验通过后，后续施工仍要保护防水层。

## 四、专业知识

### 1. 闭水试验前置条件

| 条件 | 要求 |
|---|---|
| 防水施工完成 | 防水区域和节点已处理 |
| 防水层干燥 | 已成膜，未被踩踏破坏 |
| 地漏临时封堵 | 能蓄水 |
| 门口挡水 | 避免水外溢 |
| 楼下可检查 | 尽量通知楼下或物业 |
| 现场拍照 | 记录试验前状态 |

### 2. 闭水试验步骤明细

| 步骤 | 内容 | 重点 |
|---|---|---|
| 检查防水层 | 看是否完整、干燥 | 破损先修补 |
| 封堵地漏 | 防止水直接流走 | 封堵要可靠 |
| 门口挡水 | 防止水流到外面 | 不破坏防水 |
| 蓄水 | 地面形成稳定水面 | 水位适当 |
| 标记水位 | 记录开始水位 | 便于观察 |
| 通知楼下 | 查看顶面和管根 | 防止漏看 |
| 定时观察 | 观察水位和渗漏 | 留照片 |
| 结束排水 | 检查排水是否通畅 | 不堵地漏 |
| 形成记录 | 记录时间和结果 | 留证据 |

### 3. 闭水观察重点

| 位置 | 看什么 |
|---|---|
| 楼下顶面 | 水印、潮湿、滴水 |
| 楼下管根 | 管道周边渗水 |
| 自家门口 | 水是否外渗 |
| 墙角 | 阴角是否渗漏 |
| 地漏周边 | 是否有异常渗漏 |
| 相邻墙面 | 是否返潮 |

### 4. 闭水试验记录明细

闭水记录建议包含：

| 字段 | 内容 |
|---|---|
| 房屋地址 | 哪个项目 |
| 试验区域 | 主卫、客卫、阳台 |
| 开始时间 | 具体日期时间 |
| 结束时间 | 具体日期时间 |
| 初始水位 | 拍照或标记 |
| 观察结果 | 是否渗漏 |
| 楼下确认 | 是否查看 |
| 参与人员 | 业主、项目经理、物业等 |
| 照片视频 | 留档 |

### 5. 闭水失败处理

如果闭水发现渗漏，不应直接贴砖，应按以下步骤处理：

1. 立即排水或控制水位。
2. 查看楼下渗漏位置。
3. 对照自家管根、地漏、墙角、门口位置。
4. 查找防水薄弱点。
5. 重新修补防水。
6. 防水干燥后再次闭水。
7. 复验合格后再进入瓦工。

### 6. 闭水试验常见误区

| 误区 | 正确认识 |
|---|---|
| 水位没降就一定合格 | 还要看楼下是否渗漏 |
| 闭水时间越长越好 | 应按合理要求执行，避免影响施工 |
| 闭水通过就永不漏水 | 后续施工破坏仍可能漏 |
| 只看自己家 | 楼下确认更关键 |
| 不拍照也没关系 | 后期责任难判断 |

## 六、操作流程

### 1. 防水干燥后检查

确认防水层已干燥成膜，表面无明显破损。

### 2. 封堵排水口

封堵地漏和排水口，确保能蓄水。

### 3. 门口挡水

门口做好临时挡水，防止水流到外面。

### 4. 蓄水并标记

蓄水后拍照记录水位和开始时间。

### 5. 通知楼下查看

请楼下业主、物业或项目人员查看顶面是否渗漏。

### 6. 观察和记录

试验期间记录水位、楼下情况和现场照片。

### 7. 结束后排水

排水时检查地漏是否通畅。

### 8. 形成验收结论

无渗漏则记录通过；有渗漏则整改后复验。

## 七、关键标准

### 1. 合格闭水试验标准

1. 防水层完整干燥。
2. 蓄水区域覆盖地面。
3. 观察期间无明显渗漏。
4. 楼下顶面和管根无水印。
5. 门口无异常外渗。
6. 试验过程有照片和记录。
7. 结果确认后再贴砖。

### 2. 高风险表现

1. 不做闭水试验。
2. 防水未干就闭水。
3. 闭水时间过短。
4. 不通知楼下查看。
5. 有渗漏仍贴砖。
6. 闭水后不拍照记录。
7. 后续贴砖破坏防水层。

## 八、验收标准

| 检查项 | 合格标准 | 风险表现 |
|---|---|---|
| 防水层 | 完整干燥 | 破损未修 |
| 地漏封堵 | 可蓄水 | 试验无效 |
| 水位记录 | 有照片或标记 | 难判断 |
| 楼下检查 | 无渗漏 | 漏水风险 |
| 门口 | 无外渗 | 门口返潮 |
| 结果 | 有记录 | 责任不清 |

## 九、常见问题

### 1. 闭水试验一定要做吗？

卫生间建议必须做。闭水试验能在贴砖前发现防水问题，避免后期拆砖返工。

### 2. 闭水试验要多久？

具体时间应按当地习惯、合同约定和材料要求执行。关键是要有足够观察时间，并检查楼下是否渗漏。

### 3. 闭水试验只看水位下降可以吗？

不够。水位变化可能受蒸发、封堵等因素影响，重点还要看楼下顶面、管根和墙角是否渗漏。

### 4. 闭水通过后还会漏水吗？

可能。后续贴砖、洁具安装、打孔、管道漏水或门口处理不好，仍可能导致漏水。

### 5. 厨房需要闭水吗？

要看是否有地漏和蓄水条件。厨房通常更应关注水槽、设备接口、管道和排水测试。

## 十、避坑提醒

1. 不要不做闭水就贴砖。
2. 不要防水未干就闭水。
3. 不要只看自家，不看楼下。
4. 不要有渗漏还继续施工。
5. 不要不拍照记录。
6. 不要闭水通过后忽略后续保护。
7. 不要把闭水通过等同于永久不漏。

## 十一、案例分析

### 案例一：未通知楼下，贴砖后发现漏水

用户 A 做了闭水，但只在自家观察水位，没有通知楼下。贴砖后楼下发现顶面水印，维修需要拆砖。

问题分析：

1. 闭水观察不完整。
2. 楼下未确认。
3. 记录不足。

正确做法：

1. 闭水时通知楼下查看。
2. 拍照记录楼下顶面。
3. 无渗漏后再贴砖。

### 案例二：闭水通过但贴砖后漏水

用户 B 闭水试验通过，但瓦工贴砖时破坏了地漏周边防水，入住后漏水。

问题分析：

1. 后续施工保护不足。
2. 地漏周边是高风险节点。
3. 闭水通过不代表后续不会被破坏。

正确做法：

1. 贴砖前保护防水层。
2. 地漏周边施工谨慎。
3. 发现防水破损及时修补。

## 十二、法规依据

闭水试验涉及防水工程质量、合同履行、相邻关系和渗漏责任。通常可参考：

1. 住宅装饰装修工程施工和验收相关标准。
2. 建筑防水工程相关国家、地方或行业规范。
3. 装修合同、防水施工记录、闭水试验记录、验收单和现场照片。
4. 《住宅室内装饰装修管理办法》中关于装修活动和防水层保护的规定。

具体责任应结合合同约定、闭水记录和实际渗漏原因判断。
