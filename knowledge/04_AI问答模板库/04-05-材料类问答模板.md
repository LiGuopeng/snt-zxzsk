# 材料类问答模板

## 一、适用场景

适用于装修材料品牌、型号、环保、耐用性、真假货、替代材料、口碑争议等问题。

## 二、用户常见问法

1. 这个品牌好不好。
2. 这个材料环保吗。
3. 便宜材料能不能用。
4. 网上说这个材料容易翻车，是真的吗。
5. 材料只写品牌不写型号可以吗。

## 三、调用知识库

1. 01_标准知识库/对应材料模块。
2. 02_民间装修知识库/02-04 材料品牌与口碑经验。
3. 02_民间装修知识库/02-10 民间经验可信度分级。
4. 03_装修决策案例库/相关决策案例。
5. 05_知识规则与风险控制/产品安全和环保规则。

## 四、标准回答结构

```text
1. 不做绝对品牌好坏判断
2. 拆成品牌、型号、等级、检测、安装、售后
3. 提醒单品环保不等于全屋环保
4. 给选购核对清单
5. 给合同或验收建议
```

## 五、模板 1：品牌好不好

AI 回复模板：

```text
不能只按品牌判断好不好。装修材料更应该看具体型号、等级、检测报告、适用场景、安装工艺和售后。

你可以重点核对：

1. 合同是否写清品牌、型号、规格和等级。
2. 是否有检测报告或环保标识。
3. 是否适合你家的使用环境。
4. 安装辅料是否同样可靠。
5. 售后责任由谁承担。

同一个品牌也有不同档次，不能只写品牌不写型号。
```

## 六、模板 2：环保材料

AI 回复模板：

```text
单个材料环保，不代表全屋空气质量一定达标。装修里的板材、胶、漆、地板、家具、窗帘都会叠加释放。

更稳妥的做法是：选材料时看检测报告和环保等级，施工时控制用量和胶类，完工后充分通风，入住前根据家庭情况考虑空气检测。家里有老人、孩子、孕妇时，要更保守一些。
```

## 七、需要追问的信息

1. 是哪类材料。
2. 用在哪个空间。
3. 合同是否写型号。
4. 是否有检测报告。
5. 家里是否有老人、孩子、孕妇。

## 八、禁用表达

1. 这个品牌一定好。
2. 这个材料绝对环保。
3. 贵的肯定没问题。
4. 网上说不好就别买。
