# 合同类问答模板

## 一、适用场景

适用于装修合同、口头承诺、付款节点、工期延期、保修条款、材料不符、合同漏项等问题。

## 二、用户常见问法

1. 合同里没写清楚怎么办。
2. 设计师口头答应的算数吗。
3. 装修公司催签合同要不要签。
4. 工期拖延怎么处理。
5. 材料和合同不一致怎么办。
6. 签装修合同具体怎么做。
7. 签合同当天要检查什么。
8. 装修合同怎么签才不踩坑。

## 三、调用知识库

1. 01_标准知识库/01_装修准备/01-03 装修合同签订。
2. 01_标准知识库/01_装修准备/01-07 装修付款方式。
3. 02_民间装修知识库/02-01 装修公司与合同套路。
4. 03_装修决策案例库/03-01 预算合同决策案例。
5. 03_装修决策案例库/03-08 售后维权决策案例。

## 四、标准回答结构

```text
1. 先说明合同判断依据
2. 提醒书面记录的重要性
3. 列出应核对条款
4. 给沟通或补充协议话术
5. 说明证据留存和升级路径
```

## 五、模板 1：口头承诺

用户问：

```text
设计师口头答应送东西，需要写进合同吗？
```

AI 回复模板：

```text
建议写进去。装修里只要涉及价格、材料、赠品、工期、施工范围、增项减免、整改和保修，都不要只停留在口头承诺。

比较稳妥的做法是：

1. 写进合同或补充协议。
2. 写进报价单备注。
3. 至少让对方在微信里明确确认。

后期如果人员变动或说法不一致，书面记录才是你维权和沟通的依据。
```

## 六、模板 2：催签合同

用户问：

```text
装修公司说今天签才有优惠，要不要签？
```

AI 回复模板：

```text
不建议因为限时优惠仓促签。签合同前至少要看清：

1. 报价项目是否完整。
2. 材料品牌、型号、规格是否明确。
3. 水电和增项怎么计费。
4. 付款节点是否绑定验收。
5. 工期延误责任怎么写。
6. 保修范围和联系人是否明确。

优惠可以谈，但合同不清楚，后期代价往往比优惠更高。
```

## 七、模板 3：签合同具体步骤

用户问：

```text
签合同具体如何做？
```

AI 回复模板：

```text
签装修合同不要只看总价和优惠，建议按“资料准备、条款核对、附件确认、付款留证”这四步走。真正能保护你的不是一句承诺，而是合同正文、报价单、图纸、材料清单和补充协议能互相对上。

你可以照这个顺序操作：

1. 签前先准备资料
   把户型图、设计图、报价单、材料清单、施工范围、付款节点、工期安排都拿到手。没有明细报价、没有材料规格、没有施工范围的合同，先不要急着签。

2. 核对合同主体和收款账户
   看合同甲乙方名称、统一社会信用代码、公章、门店名称、收款账户是否一致。付款尽量打到合同主体的公司账户，不建议直接转给销售、设计师或个人工长。

3. 把报价单作为合同附件
   报价单要写清项目名称、工程量、单位、单价、总价、施工工艺、包含项和不包含项。口头说“都含了”没用，要落到附件里。

4. 核对施工范围
   明确拆除、砌墙、水电、防水、瓦工、木工、油工、安装、垃圾清运、成品保护、管理费、远程费是否包含。没有写的项目，后期很容易变成增项。

5. 核对材料品牌和规格
   主材、辅材至少写到品牌、系列或型号、规格、环保等级、颜色、数量、使用位置。只写“知名品牌”“同档次材料”“环保材料”都太模糊。

6. 核对水电和增项规则
   水电是按点位、按米还是一口价，要写清楚。增项必须先报价、先确认、再施工，未经书面确认的增项不要默认付款。

7. 核对付款节点
   不建议一开始付太多。付款最好和节点验收绑定，例如开工、隐蔽工程验收、瓦木油阶段验收、竣工验收。每次付款前先验收、拍照、确认整改。

8. 核对工期和延期责任
   写清开工日期、竣工日期、延期原因、延期通知方式、延期责任。不要只写“按实际情况顺延”，否则后期很难追责。

9. 核对验收和整改
   写清水电、防水、瓦工、木工、油工、安装、竣工这些节点怎么验收，发现问题多久整改，整改后是否复验，复验前是否可以暂缓对应款项。

10. 核对保修和售后
    写清保修范围、保修期限、联系人、响应时间、维修责任。尤其是防水、管线、墙面开裂、瓷砖空鼓、柜体安装这些常见售后点。

11. 把口头承诺写成补充协议
    赠品、优惠、免费升级、增项减免、设计师承诺、工长承诺，都要写进补充协议或报价备注，并让对方盖章或在微信里明确确认。

12. 签字付款后留证
    合同、报价单、图纸、材料清单、补充协议每页拍照或扫描保存。付款保留转账记录、收据或发票，聊天记录不要删。

签约当天可以直接问对方这几句话：

1. “这个总价包含哪些项目，哪些一定不包含？”
2. “水电后期怎么计价，增项必须我书面确认后才能做，对吗？”
3. “报价单和材料清单能不能作为合同附件盖章？”
4. “每个付款节点对应哪个验收结果？”
5. “如果延期、材料换型号、验收不合格，合同里按哪条处理？”

如果出现这些情况，建议先别签：

1. 只有总价，没有详细报价单。
2. 材料只写品牌，不写型号、规格、等级。
3. 口头承诺很多，但不愿写进合同。
4. 要求当天交大额定金或首款，否则优惠作废。
5. 水电、拆改、防水、垃圾清运、管理费等关键费用说不清。
6. 合同主体、盖章公司和收款账户不一致。

如果你已经签了但发现漏项，先不要只靠口头沟通。把漏项整理成清单，要求对方出补充协议或书面确认，写清价格、施工范围、材料和完成时间，再决定是否继续施工或付款。
```

### 重点打标：后期优化

1. 后期优化 Agent 时，用户问“签合同具体怎么做”“签合同当天检查什么”“装修合同怎么签才不踩坑”，必须优先输出步骤清单，不能只讲原则。
2. 这类问题应同时召回合同签订、报价单审核、付款方式、装修公司合同套路和报价合同风险识别规则。
3. 如果用户明确说“详细”“具体”“一步一步”“清单”，回答可以超过默认短回答长度。
4. 输出必须包含：合同附件、材料规格、增项规则、付款节点、验收整改、保修售后、证据留存。
5. 输出必须标出“先别签”的高风险信号。

## 八、需要追问的信息

1. 是否已经签约。
2. 是否支付定金或首款。
3. 合同有没有报价附件。
4. 口头承诺是否有聊天记录。
5. 争议金额或争议内容是什么。

## 九、禁用表达

1. 你一定能赢。
2. 这个合同无效。
3. 直接起诉。
4. 对方肯定违法。
