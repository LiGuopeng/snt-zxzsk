# 风险提醒类问答模板

## 一、适用场景

适用于高风险施工、漏水、用电、结构、燃气、空气质量、合同纠纷、尾款争议、材料不符等需要提醒用户谨慎处理的问题。

## 二、用户常见问法

1. 这个问题严重吗。
2. 要不要停工。
3. 还能继续住吗。
4. 要不要找专业人员。
5. 这个做法有风险吗。

## 三、调用知识库

1. 01_标准知识库/对应专业模块。
2. 03_装修决策案例库/03-10 高风险问题应急案例。
3. 05_知识规则与风险控制。
4. 02_民间装修知识库/02-10 民间经验可信度分级。

## 四、风险提醒结构

```text
1. 明确风险等级
2. 先说立刻要做什么
3. 再说明可能原因
4. 再说不能做什么
5. 最后给后续排查或维权路径
```

## 五、模板 1：紧急风险

AI 回复模板：

```text
这个情况先按高风险处理。你现在优先做三件事：

1. 先停止使用或暂停施工。
2. 拍照、录像，保留现场证据。
3. 联系物业、施工方或专业人员到场确认。

在原因没有确认前，不建议继续使用、继续施工或自行拆改。等风险排除后，再判断责任和维修方案。
```

## 六、模板 2：中等风险

AI 回复模板：

```text
这个问题不一定马上造成严重后果，但建议不要忽视。你可以先记录现场，再按标准做复核。

重点看三点：

1. 是否持续扩大。
2. 是否影响使用或安装。
3. 是否会被下一道工序覆盖。

如果会被覆盖，建议在进入下一步前先处理，否则后期返工成本会更高。
```

## 七、高风险触发词

| 触发词 | 建议风险等级 |
|---|---|
| 冒火花、焦味、发热、跳闸 | 紧急 |
| 承重墙、梁、柱、楼板 | 紧急 |
| 楼下漏水、持续渗水 | 高 |
| 燃气、排烟、热水器废气 | 高 |
| 大面积空鼓、高处墙砖松动 | 高 |
| 甲醛超标、孕妇儿童入住 | 高 |
| 尾款付清但不整改 | 中到高 |

## 八、禁用表达

1. 没事。
2. 问题不大。
3. 先住着看看。
4. 你自己拆开看看。
5. 直接找人私下修掉。
