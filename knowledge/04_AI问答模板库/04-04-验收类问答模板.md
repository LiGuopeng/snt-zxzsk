# 验收类问答模板

## 一、适用场景

适用于水电、防水、瓦工、木工、油工、安装、竣工等阶段验收问题，尤其是用户问“能不能付款”“算不算合格”“要不要整改”。

## 二、用户常见问法

1. 这样算合格吗。
2. 可以付款了吗。
3. 要不要返工。
4. 验收要看什么。
5. 装修公司催我验收怎么办。

## 三、调用知识库

1. 01_标准知识库/09_验收标准。
2. 01_标准知识库/对应施工模块。
3. 03_装修决策案例库/03-03 验收判断决策案例。
4. 02_民间装修知识库/02-03 施工现场真实问题。

## 四、标准回答结构

```text
1. 不只看表面现象
2. 列出该阶段核心验收项
3. 标明必须测试或留档的内容
4. 说明付款前提
5. 给整改复验建议
```

## 五、模板 1：水电验收付款

AI 回复模板：

```text
水电验收不能只看管线整齐。付款前建议至少确认：

1. 点位是否和图纸一致。
2. 强弱电是否分管，间距是否合理。
3. 给水是否做打压测试。
4. 排水是否通畅。
5. 回路、线径、漏保配置是否合理。
6. 封槽前是否拍照留档。

这些都确认后，再支付对应阶段款会更稳妥。
```

## 六、模板 2：竣工验收有问题

AI 回复模板：

```text
如果竣工时还有问题，不建议直接签“全部合格”。你可以先列整改清单，写清每一项问题、整改标准、完成时间和复验方式。

尾款最好和整改复验绑定：整改完成并复验通过后，再支付对应尾款。这样比口头承诺更有约束力。
```

## 七、需要追问的信息

1. 当前验收哪个阶段。
2. 是否有验收单。
3. 是否已经付款。
4. 问题是否影响使用或安全。
5. 是否有整改期限。

## 八、禁用表达

1. 看着没问题就行。
2. 先付了再说。
3. 小问题不用写。
4. 直接拒绝验收。
