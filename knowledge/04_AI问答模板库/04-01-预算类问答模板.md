# 预算类问答模板

## 一、适用场景

适用于装修预算、报价单、增项、低价套餐、水电费用、主材升级、全屋定制加价等问题。

## 二、用户常见问法

1. 装修报价低靠谱吗。
2. 水电增项是不是被坑了。
3. 装修预算怎么做。
4. 半包报价怎么看。
5. 为什么后期又要加钱。

## 三、调用知识库

1. 01_标准知识库/01_装修准备/01-02 装修预算制定。
2. 01_标准知识库/01_装修准备/01-06 装修报价单审核。
3. 01_标准知识库/03_水电工程/03-11 水电报价审核。
4. 02_民间装修知识库/02-02 预算增项与报价避坑。
5. 03_装修决策案例库/03-01 预算合同决策案例。

## 四、标准回答结构

```text
1. 不先判断是不是坑
2. 说明要看报价明细
3. 列出必须核对的项目
4. 区分合理增项和高风险增项
5. 给用户下一步沟通动作
6. 追问缺失信息
```

## 五、模板 1：报价明显偏低

用户问：

```text
这家公司报价比别人低很多，能选吗？
```

AI 回复模板：

```text
报价低不一定就是坑，但不能只看总价。你要重点核对六件事：

1. 施工项目是否完整，有没有漏掉拆改、水电、防水、找平、垃圾清运。
2. 材料是否写清品牌、型号、规格和等级。
3. 工程量怎么算，是预估还是实测。
4. 水电、拆改、瓷砖铺贴是否按实结算。
5. 增项单价和确认流程是否提前写清。
6. 付款节点是否和阶段验收绑定。

如果对方只强调优惠，但不愿意把明细写清楚，风险就比较高。
```

## 六、模板 2：水电增项

用户问：

```text
水电突然增项一万多，合理吗？
```

AI 回复模板：

```text
先别急着判断是不是被坑，要看增项来源。你可以让对方列出明细：新增点位、实际米数、单价、回路、材料和施工位置。

如果是你主动增加点位，且施工前确认过单价和数量，一般属于合理增项；如果施工前没有确认，完工后才告知大额增加，就要重点核对合同、点位图和现场照片。

建议你暂缓支付争议部分，先要求对方把每一项增项写清楚。
```

## 七、需要追问的信息

1. 报价是半包、全包还是整装。
2. 是否有完整报价单。
3. 水电是包干还是按实结算。
4. 是否签过增项确认单。
5. 付款是否已经支付。

## 八、禁用表达

1. 这肯定是坑。
2. 低价一定不能选。
3. 你直接拒付。
4. 装修公司都是这样套路。
