# 追问澄清类问答模板

## 一、适用场景

适用于用户问题信息不足，AI 不能直接判断时。追问澄清不是拖延回答，而是为了避免误判现场、误导用户或给出过度武断结论。

## 二、用户常见模糊问法

1. 这个正常吗。
2. 这样行不行。
3. 要不要返工。
4. 我是不是被坑了。
5. 怎么办。

## 四、追问原则

1. 先给初步方向，再追问。
2. 每次追问 3-5 个关键问题即可。
3. 高风险问题先提示止损，再追问。
4. 追问应围绕判断所需条件，不问无关信息。
5. 如果用户能提供照片、合同、报价、验收单，应明确说明。

## 五、模板 1：现场问题信息不足

AI 回复模板：

```text
这个问题要看现场条件，先不能直接判断是否合格。你可以先补充这几个信息：

1. 发生在哪个空间。
2. 当前处于哪个施工阶段。
3. 问题面积或范围大概多大。
4. 是否已经被下一道工序覆盖。
5. 是否有照片、视频或验收记录。

如果涉及漏水、用电、承重墙或燃气，建议先暂停使用或施工，再确认原因。
```

## 六、模板 2：是否被坑信息不足

AI 回复模板：

```text
现在还不能直接判断是不是被坑，要先看明细和证据。你可以补充：

1. 合同或报价单怎么写。
2. 对方新增费用的具体项目。
3. 是否提前告知并让你确认。
4. 是否已经付款。
5. 有没有聊天记录或变更单。

有了这些信息，才能区分合理增项和高风险增项。
```

## 七、按问题类型追问字段

| 问题类型 | 必问字段 |
|---|---|
| 瓷砖空鼓 | 墙砖/地砖、面积、位置、是否潮湿区、是否打孔挂件 |
| 漏水渗水 | 位置、是否扩大、楼下情况、是否闭水、是否打压 |
| 报价增项 | 合同计价方式、增项明细、是否确认、是否付款 |
| 全屋定制 | 报价方式、板材、五金、是否复尺、是否下单 |
| 售后维权 | 质保期、合同、证据、尾款、对方回应 |
| 墙面开裂 | 位置、宽度、是否扩大、是否新旧墙、是否质保期 |

## 八、禁用表达

1. 信息不够，我没法回答。
2. 你自己看现场。
3. 发图再说。
4. 这个要问专业人士。

更好的表达是：

```text
我先给你一个判断方向，但要更准确，需要补充几个关键信息。
```
