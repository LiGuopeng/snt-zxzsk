# 施工类问答模板

## 一、适用场景

适用于拆改、水电、防水、瓦工、木工、油工、安装阶段的施工标准、现场争议和师傅说法校正。

## 二、用户常见问法

1. 师傅说这样没事，可信吗。
2. 水电一定要横平竖直吗。
3. 防水刷完能不能马上贴砖。
4. 这个施工是不是不规范。
5. 要不要返工。

1. 01_标准知识库/对应施工模块。
2. 01_标准知识库/09_验收标准。
3. 02_民间装修知识库/02-03 施工现场真实问题。
4. 02_民间装修知识库/02-09 师傅工长经验说法。
5. 03_装修决策案例库/03-02 施工现场决策案例。

## 四、标准回答结构

```text
1. 先说明这个说法是否常见
2. 再说明标准判断依据
3. 列出适用条件和不适用条件
4. 给现场检查动作
5. 告诉用户是否应暂停、整改或复验
```

## 五、模板 1：师傅说没事

AI 回复模板：

```text
“师傅说没事”不能直接当结论，要看它是否符合施工标准和现场条件。

你可以先按这几步判断：

1. 这个问题是否涉及结构、防水、用电、燃气或隐蔽工程。
2. 是否已经进入下一道工序，后期返工成本高不高。
3. 是否有验收标准可以核对。
4. 是否有照片、视频、测试记录。
5. 是否影响后期安装、使用或保修。

如果涉及安全、漏水、用电或隐蔽工程，不建议只听口头解释，最好要求现场复核并保留记录。
```

## 六、模板 2：防水赶工

AI 回复模板：

```text
防水不能只看“表面干了没有”。比较稳妥的判断是：基层是否处理好、管根和阴阳角是否加强、防水是否按要求涂刷、是否完成闭水试验、楼下是否检查无渗漏。

如果卫生间地面还没做闭水，不建议直接贴砖。防水一旦被砖覆盖，后期维修成本会很高。
```

## 七、需要追问的信息

1. 当前处于哪个施工阶段。
2. 问题发生在哪个空间。
3. 是否已经验收或付款。
4. 是否有现场照片或视频。
5. 是否涉及隐蔽工程。
