# 全屋定制类问答模板

## 一、适用场景

适用于全屋定制报价、板材、封边、五金、投影面积、展开面积、一门到顶、安装验收和后期增项。

## 二、用户常见问法

1. 投影面积报价靠谱吗。
2. 全屋定制怎么避坑。
3. 一门到顶会不会变形。
4. 封边重要吗。
5. 定制柜安装怎么验收。

1. 01_标准知识库/06_木工工程/06-04 定制柜基础知识。

5. 03_装修决策案例库/03-06 全屋定制决策案例。

## 四、标准回答结构

```text
1. 先判断用户处于报价、下单、安装还是售后阶段
2. 拆配置，不只看单价
3. 列出必须写清的项目
4. 提醒高风险增项
5. 给下单前或验收前清单
```

## 五、模板 1：投影面积报价

AI 回复模板：

```text
投影面积报价不是不能用，但不能只看单价。你要让商家写清这些内容：

1. 板材品牌、环保等级、厚度。
2. 门板、柜体、背板是否同材。
3. 五金品牌和数量。
4. 抽屉、拉篮、拉直器、灯带、玻璃门是否另算。
5. 见光板、收口条、异形柜、超高柜是否加价。
6. 安装、运输、上楼、改尺是否包含。

低单价如果后面大量另算，最终不一定便宜。
```

## 六、模板 2：一门到顶

AI 回复模板：

```text
一门到顶不是不能做，但要看条件。重点看门板高度、板材厚度、拉直器、铰链承重、柜体垂直度和售后质保。

如果只是追求极简效果，但没有拉直器、五金承重不足、墙地顶不平，后期变形和缝隙不齐的风险会比较高。预算有限时，可以考虑局部一门到顶或分段门。
```

## 七、需要追问的信息

1. 当前是报价、复尺、下单、安装还是售后。
2. 报价方式是投影还是展开。
3. 板材和五金品牌是什么。
4. 是否有配置明细表。
5. 是否已经支付定金。

## 八、禁用表达

1. 投影面积一定坑。
2. 展开面积一定更透明。
3. 一门到顶一定会变形。
4. 某板材一定环保。

## 九、RAG 拆分建议

1. 投影面积报价模板。
2. 一门到顶判断模板。
3. 定制柜验收模板。
