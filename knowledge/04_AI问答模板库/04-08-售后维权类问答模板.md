# 售后维权类问答模板

## 一、适用场景

适用于装修公司不维修、售后拖延、质量争议、材料不符、尾款争议、质保期问题、投诉和沟通话术。

## 二、用户常见问法

1. 装修公司不维修怎么办。
2. 还有问题要不要付尾款。
3. 材料和合同不一致怎么办。
4. 质保期内出问题找谁。
5. 投诉前要准备什么。

## 三、调用知识库

1. 01_标准知识库/11_售后保修。
2. 01_标准知识库/09_验收标准/09-10 竣工交付与整改复验。
3. 02_民间装修知识库/02-08 售后维权真实经验。
4. 03_装修决策案例库/03-08 售后维权决策案例。
5. 05_知识规则与风险控制/责任判断与证据规则。

## 四、标准回答结构

```text
1. 先判断是否需要止损
2. 整理证据
3. 明确责任对象
4. 给书面沟通话术
5. 给整改期限和复验方式
6. 必要时说明升级路径
```

## 五、模板 1：不维修

AI 回复模板：

```text
先别只靠电话催，建议你把问题变成书面证据和整改要求。

你可以先整理：

1. 合同、报价单、付款记录。
2. 问题照片和视频。
3. 验收记录和维修沟通记录。
4. 问题出现时间和发展过程。

然后用微信或书面方式通知对方：问题是什么、要求什么时候到场、什么时候给维修方案、什么时候整改完成。对方继续拖延时，再考虑平台、消协、市场监管、住建或法律途径。
```

## 六、模板 2：尾款争议

AI 回复模板：

```text
如果还有未整改问题，不建议直接付清尾款。更稳妥的做法是列整改清单，写明每项问题、整改标准、完成时间、复验方式和尾款支付条件。

你不是单纯拒付，而是把尾款和整改复验绑定。整改完成并复验通过后，再支付对应款项，这样沟通更有依据。
```

## 七、需要追问的信息

1. 是否还在质保期。
2. 是否有合同和报价单。
3. 是否还有尾款。
4. 问题是否影响安全和使用。
5. 对方是否有书面回应。

## 八、禁用表达

1. 直接去闹。
2. 一分钱都别给。
3. 你一定能赔到钱。
4. 对方肯定违法。

## 九、RAG 拆分建议

1. 不维修沟通模板。
2. 尾款绑定整改模板。
3. 投诉前证据整理模板。

## 十、关键词

装修售后、装修维权、不维修、尾款、质保、投诉、证据留存、整改复验
