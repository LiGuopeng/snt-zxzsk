# 软装类问答模板

## 一、适用场景

适用于家具尺寸、窗帘报价、床垫沙发选择、灯光氛围、收纳补充、软装环保、入住后使用便利性等问题。

## 二、用户常见问法

1. 沙发尺寸怎么选。
2. 窗帘报价怎么看。
3. 床垫越硬越好吗。
4. 家具买多大合适。
5. 哪些软装容易后悔。

1. 01_标准知识库/10_软装家具。
2. 02_民间装修知识库/02-07 入住后真实后悔清单。

## 四、标准回答结构

```text
1. 先确认空间和使用需求
2. 给尺寸或参数判断
3. 提醒动线、清洁、维护和环保
4. 给下单前核对清单
5. 追问关键尺寸
```

## 五、模板 1：沙发尺寸

AI 回复模板：

```text
沙发不能只看款式，先看尺寸和动线。建议你先量客厅净宽、电视墙距离、阳台门位置和通道宽度，再把沙发尺寸用胶带贴在地面上模拟。

重点确认：

1. 通道会不会被压缩。
2. 茶几、电视柜、边几还能不能正常摆。
3. 电梯、楼道、入户门能不能搬进去。
4. 是否支持退换或改尺寸。

家具买大是入住后很常见的后悔点。
```

## 六、模板 2：窗帘报价

AI 回复模板：

```text
窗帘报价不能只看每米布价。你要让商家把布、纱、褶皱倍数、轨道、辅料、定型和安装分别列出来，再按每个窗户核算总价。

很多窗帘费用不是贵在布，而是贵在倍数、轨道、辅料和安装。只报低布价但辅料很高，就容易后期超预算。
```

## 七、需要追问的信息

1. 空间尺寸是多少。
2. 家具具体尺寸是多少。
3. 是否已经下单。
4. 是否支持退换。
5. 家里居住成员和使用习惯。

## 八、禁用表达

1. 好看就可以买。
2. 大一点更舒服。
3. 这个尺寸肯定合适。
4. 窗帘报价贵就是被坑。
